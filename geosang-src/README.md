# 팔도 특산물 대상인 (거상식 지도 무역 게임) — 소스 · 빌드 · 연동

> 초등 4학년 사회(우리 국토 17개 시·도 + 지역 간 경제 교류) 학습용.
> 전국 지도를 여행하며 산지에서 싸게 사서 멀리서 비싸게 파는 시뮬레이션.
> 마블(`marble-src/`)과 같은 방식으로 소스와 배포물이 분리된다.

- **소스 위치**: `geosang-src/` (이 폴더) — React + Vite(JavaScript), 상태는 useReducer
- **배포물 위치**: `public/geosang/` — 빌드 결과 (직접 수정 금지, 빌드로만 갱신)
- **지도**: Leaflet + 시·도 경계 GeoJSON (`src/geo/provinces.json`, 타일·API 키 없음 — seoul-heritage 방식)
  - 데이터 출처: southkorea/southkorea-maps 저장소, 통계청 2013 시·도 경계 (143KB)
- **화폐**: 원(₩). 시작 자금 50,000원, 육로 여비 3,000원/지역, 제주 뱃길 8,000원

## 수정 → 반영 흐름

```
cd geosang-src
npm install            # 처음 한 번만
npm run dev            # 로컬 확인
npm run build          # → ../public/geosang/ 로 자동 출력
```

## 파일 구조 (src/)

| 파일 | 역할 |
|------|------|
| `data.js` | 데이터 전부 — 17개 시·도(이웃·뱃길·좌표·소개·marketBonus), 특산물 42종, 게임 설정(CONFIG) |
| `gameLogic.js` | 게임 규칙(순수 리듀서) — BFS 경로 탐색(travelPlan), 가격/이동/퀘스트/이벤트 |
| `components/TravelMap.jsx` | 시·도 경계 지도 — 지역 색(주황=내 위치/연두=방문/베이지=미방문), 클릭 시 onSelect |
| `components/RegionPreview.jsx` | 지역 정보 창 — 특산물·내 물건 예상 판매가·가는 길·[이동하기] 확인 버튼 |
| `App.jsx` | 화면 조립 — 상태 막대, 지도, 퀘스트(산지 안내), 시장/수레, 도감, 장사 기록 |

이동 규칙: 아무 지역이나 눌러 바로 갈 수 있고, 거쳐 가는 지역 수만큼 날짜·여비가 든다
(경유지도 방문 처리). 마지막 날 도착하면 남은 물건은 그 지역 시세로 자동 정산.

## 개발 단계

- [x] 1단계: 17개 시·도 지도 + 클릭 이동 + 여비/날짜
- [x] 2단계: 특산물 시장 사고팔기 — 마블 특산물 40종을 시·도로 매핑 + 경남 2종(굴·단감) 추가 = 42종.
      가격 규칙: 산지 매입 ×0.8, 판매 = 기준가 × (0.9 + 0.25×이동거리) × 대도시 배수(marketBonus)
- [x] 3단계: 수레 4단계(지게6→손수레10→달구지16→트럭26칸), 이익/손해 표시, 최종 정산 + 칭호 5단계
- [x] 4단계: 배달 퀘스트(완료 시 새 퀘스트), 특산물 도감(42종), 도착 이벤트(축제/풍년/통행료/횡재, 35%)
- [x] 학습 확장(A단계, 2026-07-21): 특산물 55종(전 품목 desc), 특산물 학습 카드(왜 유명한지 +
      TOP3 판매처 자동 계산 + 백과사전 검색 링크, CONFIG.searchLinkEnabled 로 on/off),
      오늘의 뉴스(매일 한 지역이 한 특산물을 1.5배로 사줌, sellPrice에 반영)
- [ ] B단계: 학급코드(교사 임의 등록, 중복 금지) + 닉네임 간편 로그인, 학급/전국 랭킹,
      교사 관리 모드(링크 스위치·닉네임 삭제), 총관리자 — **firestore.rules 변경 사전 확인 필수**
