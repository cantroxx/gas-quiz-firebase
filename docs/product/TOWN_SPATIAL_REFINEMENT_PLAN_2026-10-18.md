# 공간형 UI 후속 보완·배포 계획

## 요청 범위
사용자 1~7번 피드백에 따른 수정. 긍정 평가한 맵·화풍과 기존 기능을 유지한다. 하보 명예의 전당과 컨셉퀴즈는 학생 화면·진입 경로에서 제거하며 운영 데이터 삭제는 하지 않는다.

## 실행 단계 (순서 준수)
1. [x] 관련 렌더러·학교 라우팅·보상 수령·저장 코디 API 확인. 코디 status는 읽기 전용이며 기존 미리보기 렌더러로 저장한 의상·염색을 표시할 수 있다. 방향별 걷기 프레임은 없으므로 정지 코디 이미지의 부드러운 위치 이동으로 구현한다.
2. [x] 시작 스냅샷 보존 후 UI 보완: 명예 전체 표시, 하보 링크 제거, 컨셉 입구·탭 제거, 보상 있을 때만 작은 드롭다운 표시. 학교 원화의 컨셉 문만 장식으로 수정.
3. [x] 토끼 대신 저장 아바타 표시. 소유·저장된 코디만 사용, 무료 미리보기 제외. 계정 변경·로그아웃·늦은 응답·실패 처리. 반복 뜀 제거, 이동 속도 조정.
4. [x] 실제 렌더러 통합 검사·모바일·키보드·0/1/수령완료 보상·아바타 계정 분리·학교 제거 경로 검사. npm run check 통과.
5. [x] 현재 운영본과 대조하여 이번 변경만 후보 구성, 후보 검사 후 Hosting 배포. 운영 해시·공개 화면 확인 및 결과 보고.

## 보존
오늘의 퀘스트 유지. 재화·랭킹 초기화, Functions/Rules 배포, 운영 데이터 삭제 없음. 다른 작업의 로컬 변경을 배포하지 않는다.
