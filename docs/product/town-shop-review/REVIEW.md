# 마을 보물상점 제작 — 2026-09-17

사용자 요청에 따라 하보와 내 집·상점 입구를 분리하고 기존 DJ코인 상점 화면을 개편했다. 로컬 제작 상태이며 아직 배포하지 않았다.

## 반영

- 내 집은 기존 `나의 마을 수첩`으로 연결하며 하보 이동 버튼을 제거했다. 상점은 `showShopView`로 연결한다.
- 상점을 `마을 보물상점`으로 구성하고 모든 보물·프로필 꾸미기·내 집 테마·수집 도감으로 분류했다.
- 기존 상품은 기존 구매 경로를 사용한다. 프로필 장착 경로는 유지하고 보유 배경·아바타·칭호 프레임은 기존 내 집 적용/해제 함수로 연결했다.
- 상품 미리보기와 부족한 코인 안내, 페이지 내 찜 기능을 추가했다. 찜은 메모리에만 유지하고 회원이 바뀌면 비운다.
- 바닷속·별 여행 테마와 여우·곰·토끼 스티커는 출시 준비 상품으로 표시한다. 예정 가격을 표시하며 구매·적용은 비활성이다. 수집 도감은 상품 진열 시안으로, 보유 도감·완성 보상은 아직 구현하지 않았다.
- 실제 상품 등록, 학생 잔액·구매 기록 변경, 하보 데이터 삭제, Functions·규칙 변경은 하지 않았다. 기존 하보 직접 URL 및 랭킹의 명예의 전당은 이번 내 집·상점 입구 분리 범위에 포함하지 않았다.

## 검증

`npm run check:static`, 기존 shop domain/usecases 및 home usecases/controller 검사 통과.

`scripts/smoke/town-shop-browser.js`: 분야 전환, 미리보기, 부족 코인, 회원별 찜 초기화, 기존 구매 요청 전달, 보유 아이템 적용, 시안 구매 차단, 모바일 가로 넘침, 브라우저 오류 없음 검사 통과. 실제 코인 차감은 실행하지 않았다.

스크린샷 `shop-desktop.png`, `collection-desktop.png`, `shop-mobile.png`는 실제 로컬 화면과 합성 잔액·상품·보유 데이터를 사용했다. 운영 데이터 캡처가 아니다.

배포 전 전체 `npm run check`와 최신 운영본 기준 변경 분리가 필요하다.
