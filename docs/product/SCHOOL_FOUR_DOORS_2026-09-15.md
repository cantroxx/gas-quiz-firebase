# 학교 네 문 재구성

- 빨간 문: 과목 퀴즈. 국어·수학·사회·과학 선택 후 기존 과목관 이동.
- 파란 문: 학습 퀴즈. 기존 외부 퀴즈 링크가 기본 학습 분류로 표시됨.
- 초록 문: 기존 인기 퀴즈 연결. 이용 시간·접근 제한 유지.
- 노란 문: 컨셉 퀴즈. 관리자 설정에 따라 `경제`처럼 주제 단어만 표시하고 활성 컨셉 링크 목록을 열음.
- 우리 교실·게임 아지트 입구 유지. 선택 목록은 닫기·Escape로 학교 복귀.

## 관리자 설정

기존 외부 퀴즈 탭을 **학습·컨셉 퀴즈**로 변경했다. 컨셉 월(1~12), 주제(40자 이내), 각 링크의 학습/컨셉 분류를 설정한다. 기존 HTTPS 링크·이름·설명·활성 필드는 유지한다. 총 12개 링크 제한도 유지한다. 컨셉은 자동 월별 전환이 아닌 관리자 지정 값이다. 주제가 비어 있으면 준비 중으로 표시한다.

`appSettings/externalQuizzes`의 기존 `items`에 `group: learning | concept`, 문서에 `concept: { month, theme }`을 추가했다. 분류가 없는 기존 링크는 학습으로 취급하며 운영 데이터 마이그레이션은 없다. 기존 관리자 callable과 권한을 재사용한다. 기능 끄기로 링크 활성 해제 시 컨셉 월·주제는 보존한다.

## 검증과 배포

전체 `npm run check` 통과. 전용 `scripts/smoke/school-hubs-browser.js`는 로컬 서버 5328을 사용하며 운영 요청 없이 실제 렌더러·컨트롤러로 과목 경로, 인기 접근 제한, 학습/컨셉 분류, 비활성 링크, 기능 차단, 빈 컨셉, 관리자 폼 왕복, 모바일·키보드, 서버 정규화·기능 끄기 시 컨셉 보존을 확인한다.

사용자 배포 요청으로 운영 반영했다. Hosting 파일 10개와 `adminGetExternalQuizzes`, `adminUpdateExternalQuizzes`, `adminUpdateFeatureFlags` 3개를 선택 배포했다. 운영 설정 저장은 하지 않았으며 화면 캡처의 경제 주제는 테스트 예시다. 보안 규칙·학생 데이터는 변경하지 않았다.

- 이전 Hosting 버전: `edb33551d1b2e157`
- 배포 버전: `1e65c95765ab1eec`
- 릴리스: `1789451342527000`
- 배포 전 전체 검사와 학교 전용 smoke 통과. 나머지 운영 파일 해시 보존 확인.
- 배포 후 공개 화면 smoke와 운영 파일 10개 내용 일치 확인.
