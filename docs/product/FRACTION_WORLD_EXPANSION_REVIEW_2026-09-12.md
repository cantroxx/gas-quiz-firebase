## 먼저 볼 내용

### 사용자 요청으로 반영할 방향

1. 현재 무기보다 종류를 늘리고, 처음 선택한 무기를 탐험 중 강화한다.
2. 결정에 무기 성장·상점 구매라는 구체적인 메리트를 준다.
3. 유물 종류와 조합을 늘리고, 실제 공격 모습과 플레이 방식이 달라지게 한다.
4. 1~24번 방 일렬 표시를 지역별 분기 지도로 교체한다.
5. 현재 지역에서 아래로 진행하며 다음 방 3개 중 하나를 선택하고, 보스를 처치하면 다음 지역으로 이동한다.
6. **지도를 이미지로 생성하고, 그 위에 실제로 누를 수 있는 스테이지 버튼을 배치한다.**
7. 오답은 같은 문제를 정답까지 반복시키기보다 풀이 확인 후 진행하고, 게임 안의 불이익과 연결한다.

## 1. 한 번의 탐험 흐름

시작 무기와 기본/심화 난이도를 선택한다. 현재 지역의 그림 지도를 보고 다음 방을 선택한다. 전투·보물·정비·사건을 거치며 결정과 유물을 모은다. 시작 무기를 강화하고, 상점에서 개조를 구매하며, 속성 조합을 완성한다. 지역 보스를 처치하면 다음 지역의 지도로 넘어간다. 네 번째 지역 보스를 처치하면 탐험을 완료한다.

- 기본 공격은 자동. 태블릿에서는 이동·회피·고유 기술을 직접 조작한다.
- 키보드의 이동·회피·기술 조작도 유지한다.
- 문제 풀이와 상세 설명 확인 중에는 전투가 멈춘다.
- 학생이 현재 목표를 알 수 있도록 지도에 다음 강화 비용, 조합 부족 수량, 도달 가능한 상점·회복 위치를 표시한다.

## 2. 이미지 지도 위 스테이지 버튼 — 신규 핵심 요구

### 2.1 지도 구성

**지역별로 생성한 배경 그림을 깔고, 그 위에 연결 경로와 스테이지 버튼을 겹쳐 배치한다.** 지도 한 장을 통째로 클릭하는 방식이 아니라 각 방이 독립적인 버튼이어야 한다.

| 화면 층 | 구성 |
|---|---|
| 배경 그림 | 지역의 지형·건물·숲·절벽·폐허·보스 거점. 글자나 버튼은 그림에 넣지 않음 |
| 경로 | 노드 좌표에 맞춰 그리는 연결선. 지나온 길·이동 가능한 길·막힌 길 구분 |
| 스테이지 버튼 | 방 종류 이미지, 이름, 주요 보상, 현재 상태를 표시하는 실제 버튼 |
| 현재 위치 | 캐릭터 말, 빛, 짧은 이동 연출 |
| 방 정보 패널 | 선택한 방의 적 강도·예상 보상·비용과 ‘이 길로 이동’ 버튼 |
| 고정 정보 | 체력, 결정, 무기 강화 단계, 조합 진행도, 지역 이름 |

배경 그림에는 특정 연결선을 확정해서 그리지 않는다. 이미지에 그려진 길과 실제 이동 경로가 어긋나는 것을 피하기 위해, 버튼 사이의 이동 가능 경로는 화면에서 별도로 그린다.

### 2.2 네 지역의 미술 방향

| 지역 | 지도 이미지 방향 | 보스 위치 표현 |
|---|---|---|
| 이끼빛 폐허 | 숲속 석조 유적, 덩굴, 작은 물길, 무너진 다리 | 아래쪽의 거대한 뿌리 성문 |
| 유리 사막 | 수정 모래, 오아시스, 부서진 탑, 모래시계 유적 | 아래쪽의 모래시계 신전 |
| 푸른 잿불 성채 | 푸른 불꽃, 성벽, 쇠다리, 대장간 구역 | 아래쪽의 기사 성문 |
| 별 없는 왕좌 | 공중 섬, 별자리 파편, 검은 수정, 균열 | 아래쪽의 공허 왕좌 |

- 기존 게임의 캐릭터·지도·UI를 복제하지 않고 분수 월드의 기존 미술과 맞춘다.
- 첫 제작은 지역별 기본 지도 4장과 재사용 가능한 노드 아이콘으로 구성한다.
- 노드를 배치할 공간은 장식과 대비가 과하지 않게 확보한다.
- 지도는 세로로 진행하되, 태블릿 가로 화면에서는 옆에 정보 패널을 배치한다.
- 무작위 지도는 배경과 맞는 미리 정한 배치 틀 안에서 방 종류·연결을 바꾸는 방식으로 시작한다.

### 2.3 버튼 상태와 조작

- **현재 위치:** 캐릭터 말과 강조 테두리.
- **선택 가능:** 연결선과 버튼 강조. 종류·보상 확인 가능.
- **방문 완료:** 체크 표시와 지나온 길 표시.
- **아직 도달하지 않음:** 미리보기 가능, 이동 불가.
- **선택하지 않아 닫힌 경로:** 흐리게 표시, 이동 불가.
- **보스:** 다른 방보다 큰 전용 초상·문 이미지.
- **숨겨진 방:** 조건이 드러나기 전에는 물음표·봉인된 흔적. 세부 보상은 숨김.

버튼 터치 → 방 정보 확인 → ‘이 길로 이동’으로 확정한다. 지도 스크롤이나 드래그 중에는 입장이 확정되지 않는다. 키보드 Tab·Enter와 명확한 초점 표시도 제공한다. 색뿐 아니라 모양·문구로 상태를 구분한다.

터치 영역은 최소 48px을 확보하고 실제 태블릿에서 간격을 검증한다. 지도 축소 때문에 버튼이 작아지면 전체를 무리하게 한 화면에 넣지 않고 세로 스크롤을 사용한다. 화면 회전·크기 변경 후에도 이미지와 버튼 좌표가 일치해야 한다.

## 3. 지역별 분기 구조

### 추천 기본안: 지역당 5단계 + 보스

- 한 지역에서 실제로 방문하는 기본 방은 일반 진행 5개와 보스 1개다.
- 네 지역을 완료하면 기본 경로상 총 24개 방을 방문한다. **24개 모두 전투라는 뜻은 아니다.**
- 일반 진행 중 연결된 다음 방 3개를 고른다. 보스 진입은 하나의 보스 방으로 합류하는 예외다.
- 각 지역의 일반 진행 5개 중 최소 3개는 일반/정예 전투가 되도록 경로를 검증한다.
- 지도에는 방문하지 않을 후보 방도 함께 보인다. 후보 노드 수와 실제 방문 방 수는 다르다.
- 앞으로 연결된 방 종류를 볼 수 있게 하되, 모든 후보 방을 방문할 수는 없다.
- 보스 처치 후 지역 완료 연출과 획득·성장 요약을 보여주고 다음 지도를 공개한다.

### 지도 생성 조건

1. 모든 허용 경로가 보스까지 이어진다.
2. 일반 단계에서는 서로 구별되는 다음 방 선택지 3개를 제공한다. 보스 합류는 예외다.
3. 세 선택지가 같은 종류로만 채워지지 않는다.
4. 지역마다 상점·회복·대장간에 도달할 기회를 제공한다. 모든 경로에서 전부 방문할 수 있다는 뜻은 아니다.
5. 불가피하게 정예 전투만 연속 선택해야 하는 경로를 만들지 않는다.
6. 보스 직전 단계에서는 회복·정비 중 적어도 하나를 선택할 수 있게 한다.
7. 지도 구조·방 보상·상점 재고는 탐험 저장에 포함해 새로고침으로 다시 추첨되지 않게 한다.

## 4. 방 종류와 경로 선택의 이유

| 방 | 내용 | 기대하는 선택 이유 |
|---|---|---|
| 일반 전투 | 전투 후 결정 18개와 유물 3택1 | 안정적인 장비·재화 확보 |
| 정예 전투 | 적 수·체력 증가, 결정 30개와 유물 3택1 | 추가 결정 12개로 강화 앞당기기 |
| 속성 보물방 | 표시된 속성의 유물 후보 중 선택 | 부족한 조합 완성 |
| 대장간 | 무기 고단계 강화·유물 강화 | 결정을 전투력으로 전환 |
| 일반 상점 | 유물·무기 개조·기술 개조·구조 부적 | 필요한 효과 직접 구매 |
| 샘터 | 회복 또는 작은 축복 선택 | 생존 준비 또는 다른 보너스 선택 |
| 사건방 | 대가와 보상을 확인하고 선택 | 미래 기회에 투자하거나 위험 감수 |
| 보스방 | 지역 최종 전투와 보상 | 다음 지역 진입 |

- 보물방·무료 회복·사건 보상은 출현 제한과 경로 검증을 통해 조절한다.
- 샘터의 축복 종류와 회복 비용은 기존 ‘결정 25개로 최대 40 회복’을 기준으로 세부 설계한다. 아직 무료 회복으로 확정한 것이 아니다.
- 상점·대장간·샘터를 방문했다는 이유만으로 일반 전투 보상 18개를 지급하지 않는다.
- 정예와 일반의 유물 후보 수·기본 획득 확률은 동일하게 유지하는 초안이다.
- 사건방에는 선택 전 비용·불이익을 표시한다. 구조 부적이나 열쇠 등 보상도 실제 보유 상태로 연결한다.

## 5. 시작 무기 6종 → 12종

| 무기 | 기본 전투 | 성장 방향 예시 |
|---|---|---|
| 별빛 지팡이 | 균형 잡힌 별탄 | 추적 별탄 / 다중 방향 발사 |
| 유성 활 | 빠른 관통 사격 | 관통 후 분열 / 집중 저격 |
| 달의 부채 | 펼쳐졌다 돌아오는 달날 | 왕복 공격 / 주변 공전 |
| 서리 보주 | 냉각하는 관통탄 | 얼음 폭발 / 지속 냉각 지대 |
| 번개 바늘 | 초고속 연사 | 연쇄 번개 / 누적 방전 |
| 혜성 대포 | 느린 폭발탄 | 파편 확산 / 집중 포격 |
| 쌍검 — 신규 | 근거리 연속 공격 | 회피 후 기습 / 연속 타격 강화 |
| 수정 창 — 신규 | 긴 직선 찌르기 | 충격파 / 거리 유지 강화 |
| 대지 망치 — 신규 | 범위 타격과 밀치기 | 지면 균열 / 충격 누적 폭발 |
| 사슬낫 — 신규 | 중거리 휘두르기와 회수 | 끌어당기기 / 넓은 회전 공격 |
| 수호 방패 — 신규 | 밀치기와 방어 | 반사 / 돌진 |
| 소환서 — 신규 | 소환수 공격 | 다수 소환 / 강한 수호수 |

- 각 무기에 구별되는 기본 공격, 고유 기술, 유리한 거리, 공격 효과를 설계한다.
- 근접 무기는 자동 공격 범위와 밀치기 등을 명확히 해 접근 위험에 상응하는 장점을 준다.
- ‘12종’은 이름과 수치만 바꾸는 것이 아니라 실제 공격 동작까지 구현하는 범위다.
- 상세 수치는 기존 무기와 비교한 전투 검증 후 결정한다.

## 6. 시작 무기 강화·분기·각성

| 단계 | 비용 초안 | 변화 | 사용 장소 |
|---|---:|---|---|
| +1 | 결정 15개 | 무기별 기본 성능 강화 | 전투 후 정비 또는 대장간 |
| +2 | 25개 | 공격 범위·속도·관통 등 장점 강화 | 전투 후 정비 또는 대장간 |
| +3 | 40개 | 두 성장 계열 중 하나 선택 | 대장간 |
| +4 | 60개 | 선택한 계열 강화 | 대장간 |
| +5 | 85개 | 최종 각성, 외형·공격·기술 변화 | 대장간 |

- 총 비용 초안: 225개. +3 분기와 +5 각성에 별도 진화 비용을 추가하지 않는다.
- 추천: +3의 두 계열을 각각 +5에서 완성한다. 아직 계열별로 다시 두 갈래로 나누는 추가 분기는 넣지 않는다.
- 예: 지팡이 추적 계열은 처치 후 다음 적을 추적, 다중 계열은 파동에서 추가 별탄 방출.
- 현재→강화 후 수치, 새로 생기는 효과, 짧은 시연을 구매 전에 표시한다.
- 주력 무기는 계속 성장시키되 무기 개조·기술 개조는 각각 별도 1칸으로 제한한다.
- 장착 무기를 탐험 중 다른 시작 무기로 교체하는 시스템은 이번 기본안에 포함하지 않는다.

## 7. 유물 24종 → 40종과 조합 15종

속성은 불꽃·서리·폭풍·숲·별 5개를 유지하고 각 8종으로 맞춘다. 공격 외에도 이동·회피·기술·회복·방어·소환수와 관계있는 효과를 설계한다. 기존 24종의 속성과 효과는 가능한 한 유지한다.

### 속성 집중 조합 5종

같은 속성의 서로 다른 유물 3개로 활성화한다. 현행 효과를 기준으로 검증한다.

| 속성 | 집중 조합 효과 |
|---|---|
| 불꽃 | 공격력 +20% |
| 서리 | 냉각된 적의 공격 준비 속도 30% 감소 |
| 폭풍 | 회피 대기시간 -20% |
| 숲 | 최대 체력 +20 |
| 별 | 고유 기술 위력 +30% |

### 혼합 조합 10종

두 속성을 각각 2개씩 장착하면 발동하는 초안이다. 아래는 효과 방향이며 발동 주기·피해량은 미정이다.

| 속성 짝 | 효과 방향 |
|---|---|
| 불꽃 + 서리 | 냉각된 적 공격 시 열충격 폭발 |
| 불꽃 + 폭풍 | 회피한 자리에 불길 생성 |
| 불꽃 + 숲 | 피격 시 가시불꽃 반격 |
| 불꽃 + 별 | 기술 적중 지점에 작은 운석 |
| 서리 + 폭풍 | 회피 경로에 냉각 흔적 |
| 서리 + 숲 | 일정 시간마다 얼음 보호막 |
| 서리 + 별 | 기술에 짧은 빙결 추가 |
| 폭풍 + 숲 | 이동으로 충전하는 보호막 |
| 폭풍 + 별 | 일정 횟수 공격마다 연쇄 번개 |
| 숲 + 별 | 전투를 돕는 정령 소환 |

- 가방 8칸 유지. 같은 유물이 집중 조합과 혼합 조합 양쪽 조건에 기여할 수 있다.
- 2+2+2+2 구성에서는 여러 혼합 조합이 동시에 가능하므로 효과별 발동 간격과 전체 추가 효과량을 검증한다.
- 추가 효과가 다른 추가 효과를 무한 재발동시키지 않도록 발생 원인과 중복 규칙을 정의한다.
- 현재 유물 강화 +1~+3, 비용 20/35/50은 별도 시스템으로 유지하는 초안이다. 강화 단계는 조합 개수로 세지 않는다.
- 카드에는 이미지·단독 효과·속성·조합 변화·능력치 변화를 표시한다. 활성 효과는 전투 모습에서도 구별돼야 한다.

## 8. 결정 경제와 구매 목표

결정의 역할은 주력 무기 성장, 유물 보강, 상점 구매, 회복이다. 당장 살 수 있는 것과 다음 목표를 함께 보여준다.

예: ‘현재 45개 → 정예 완료 후 75개 → 무기 +4 강화 60개 구매 가능’. 대장간에 가야 하는 강화라면 ‘대장간에서 구매 가능’도 함께 표시한다.

### 분기 지도 도입에 따른 수입 재계산

이전 24회 전투 구조의 540~780개를 새 지도의 고정 수입으로 사용하면 안 된다.

- 지역당 일반 전투 최소 3회 + 보스 1회라면, 네 지역의 전투 보상은 일반 경로 기준 최소 `12×18 + 4×45 = 396개`다.
- 일반 진행 5개가 전부 전투라면 일반 경로 기준 `20×18 + 4×45 = 540개`다.
- 해당 일반 전투를 모두 정예로 고르면 각각 540개, 780개다. 실제 지도에서 그 경로를 모두 허용한다는 뜻은 아니다.
- 유물 대신 결정 받기, 나침반, 사건 보상, 히든 방의 수입은 위 금액에 포함하지 않는다.
- 무기 강화 225개와 상점 개조 55개, 유물 구매 40개, 회복 비용이 경쟁한다. 가장 적게 버는 허용 경로도 합리적으로 완주할 수 있는지 검증한다.

평균적인 선택에서 핵심 무기 성장을 경험하되, 모든 상품과 모든 강화를 살 수는 없는 예산을 목표로 한다. 상점·대장간을 방문하는 데 쓰는 방 기회도 비용으로 고려한다.

## 9. 일반 상점과 히든 상점

### 일반 상점

지도에 위치를 공개한다. 지역마다 접근 기회를 제공하며 구매를 강제하지 않는다. 입장 전 대표 상품과 가격을 볼 수 있다. 재고는 최초 생성 후 저장한다.

| 상품 | 비용 초안 | 역할 |
|---|---:|---|
| 원하는 속성의 유물 | 40개 | 조합 완성 |
| 현재 무기 전용 개조 | 55개 | 특별한 공격 효과 추가 |
| 고유 기술 개조 | 55개 | 파동 재폭발·운석 잔류 지대 등 |
| 구조 부적 | 45개 | 치명적 피해를 한 번 버팀 |

추천: 상품 3개 제시, 방문당 최대 1개 구매. 기존 개조를 교체할 때는 사라지는 효과를 구매 전에 보여준다.

### 히든 상점

일반 상점과 별개인 추가 기회다. 지도에 봉인된 문·수상한 흔적으로 표시하고 조건을 충족하면 공개한다.

| 조건 예시 | 선택의 의미 |
|---|---|
| 사건에서 낡은 열쇠 획득 | 즉시 보상 대신 미래 기회 |
| 해당 지역 정예 전투 2회 완료 | 어려운 경로의 보상 |
| 특정 속성 조합 완성 | 장비 구성에 따른 발견 |
| 전투 후 비밀 표식 조사 | 탐색 보상 |

- 현재 무기 전용 상품 또는 할인 상품을 배치한다.
- 무오답·계산 속도만으로 발견을 제한하지 않는다.
- 추천: 발견한 방에서 잠시 들어갔다 나오는 추가 방문으로 처리한다. 기본 24방 단계나 전투 출제 횟수를 소모하지 않는다.
- 지역당 최대 1회, 같은 문·상품을 반복 이용할 수 없게 저장한다.
- 필수 성장 기회는 일반 상점·대장간에 둔다. 발견하지 못해도 완주 가능해야 한다.

## 10. 문제 풀이와 오답 불이익

### 한 번 제출하고 풀이 확인

1. 문제마다 답을 한 번 제출한다.
2. 정답은 결과를 확인하고 다음 문제로 이동한다.
3. 오답은 정답·분수 그림·핵심 풀이를 보여준다. 확인 버튼 후 다음 문제로 이동한다.
4. 동일 문제 재입력을 강제하지 않는다.
5. 최초 응답을 정오답으로 기록하고, 틀린 유형의 다른 문제를 이후 우선 출제한다.

학습 기록은 ‘응답한 문제 수’와 ‘최초 정답 수’를 구분한다. 풀이를 본 문제를 스스로 맞힌 문제로 집계하지 않는다. 계산 제한 시간은 두지 않는다.

### 탑 입장 문제: 불안정한 룬

| 난이도 | 오답 1개 | 3문제 묶음 최대 |
|---|---|---|
| 기본 | 다음 전투 균열 몬스터 1마리 | 3마리 |
| 심화 | 다음 전투 균열 몬스터 2마리 | 6마리 |

- 다음 **실제 전투** 한 번에만 적용한다. 그 전에 상점·샘터를 방문하면 룬이 유지된다.
- 적은 구별되는 외형과 출현 예고를 갖고, 한꺼번에 플레이어 위치에 생성하지 않는다.
- 추가 적에 별도 결정·유물 보상을 주지 않아 고의 오답을 수입원으로 만들지 않는다.
- 이미 획득한 결정·무기 강화는 빼앗지 않는다.
- 추천 보스 제한: 기본 최대 1마리, 심화 최대 2마리. 남은 룬은 해당 전투에서 정산하고 다음 지역으로 중복 이월하지 않는다.

### 목표 학습량: 완주 32문제 유지 추천

분기 지도에서 상점 방문 수에 따라 문제 수가 크게 달라지지 않게 한다.

- 지역의 첫 번째 전투 진입: 3문제.
- 지역의 세 번째 전투 진입: 3문제.
- 지역 보스 보물: 2문제.
- 지역당 8문제 × 4지역 = 32문제. 일반 진행에 최소 3전투를 보장하는 지도 조건과 연결된다.
- 추가 전투·히든 상점은 자동으로 문제 수를 늘리지 않는다.
- 보스 보물은 정답당 추가 결정 3개. 오답이어도 기본 보상과 유물 선택은 유지한다.

### 스튜디오 오답안 — 별도 결정 필요

오답당 당일 보컬·댄스·표현 성장량 5% 감소, 최대 15%. 휴식 회복·자금 수입은 유지한다. 추천: 이번에는 탑부터 적용하고 스튜디오 적용 여부는 따로 결정한다.

## 11. 보스 준비와 난이도

- 보스 노드를 누르면 대표 공격, 회피 방법, 유용한 준비 수단을 미리 볼 수 있다.
- 현재 무기 단계·조합·회복 가능 위치와 연결한다.
- 특정 속성을 반드시 가져야만 통과하는 보스는 만들지 않는다.
- 기본/심화는 전투 강도를 나누며, 무기 종류·분수 연습 범위와 별개다.
- 무기 각성과 혼합 조합으로 플레이어가 강해지는 만큼 보스 체력만 올리지 않고 패턴과 안전 공간을 함께 조정한다.
- 무오답·모든 정예 선택·특정 무기 없이도 기본 난이도 완주가 가능해야 한다. 심화도 실제 허용 경로로 클리어 가능성을 검증한다.

## 12. 인게임 미술·연출 제작 범위

| 묶음 | 산출물 범위 |
|---|---|
| 지역 지도 | 생성 배경 4장, 노드 배치 안전 영역, 지역 진입·완료 표현 |
| 방 버튼 | 일반·정예·보물·대장간·상점·샘터·사건·보스·히든의 아이콘과 상태 표현 |
| 신규 무기 | 신규 6종 장비 원화, 손에 든 모습, 기본 공격·기술 표현 |
| 무기 성장 | 12무기의 +3 두 계열, +5 각성을 구별하는 외형·효과 |
| 유물 | 신규 16종 아이콘, 기존 24종과 미술 통일, 속성 배지 |
| 혼합 조합 | 10종 발동 효과, 설명용 짧은 시연 |
| 상점·대장간 | 상인·시설 그림, 상품 카드, 구매·강화 연출 |
| 오답 룬 | 불안정한 룬과 추가 적 출현 예고, 명확한 정산 표시 |

기존 배경·보스·주인공·무기·유물 이미지는 품질에 맞춰 재사용한다. 지도 위의 텍스트·숫자·버튼 상태는 이미지에 굽지 않는다. 전투 중 피해 범위와 공격 예고를 가리는 장식은 줄이고, 움직임 감소 설정과 이미지 로딩 실패 대체 표시를 유지한다.

모든 각성 단계를 별도 대형 원화로 만들어야 한다는 뜻은 아니다. 기본 원화·부착 장식·색·발사체·효과를 조합하되 실제 차이가 명확해야 한다. 필요한 프레임·이미지 수는 무기별 동작 설계 후 산정한다.

## 13. 저장·복원·운영 경계

저장해야 할 상태: 지역 지도 생성 정보, 노드 연결, 현재 위치, 완료·폐쇄 경로, 무기 강화·분기·각성, 개조, 유물, 상점 재고와 구매 여부, 비밀 문 조건, 다음 전투 오답 룬, 문제 응답, 전투 진행.

- 구매·보상·강화·보스 완료는 한 번만 반영한다.
- 새로고침으로 무료 회복·상품 재추첨·오답 룬 삭제가 가능해지지 않게 한다.
- 예전 저장 파일을 새 지도에 무조건 덮어쓰거나 삭제하지 않는다.
- 추천 전환: 진행 중인 기존 탐험은 기존 규칙으로 완료할 수 있게 유지하고, 새 탐험부터 새 지도를 사용한다. 저장 버전과 두 진행 방식의 분기 비용을 구현 전에 검토한다.
- 장기 능력치 계승은 아직 미확정. 기본 추천은 현재처럼 탐험마다 초기화하고 도감·학습·클리어 기록을 보존하는 방식이다.
- DJ코인, 학생 Firebase 데이터, 랭킹, 보안 규칙과 연결하는 변경은 이 문서 범위에 포함하지 않는다.
- 플레이 관찰은 기기 내 기록·내려받기부터 사용한다. 학생 데이터를 새 서버로 자동 전송하는 기능을 전제하지 않는다.

## 14. 제작 순서와 완료 기준

| 단계 | 작업 | 완료 판단 |
|---|---|---|
| A | 결정 항목 확정, 지도·저장·경제 규칙 설계 | 기존 제안의 충돌 해소, 경로·학습·재화 규칙 확정 |
| B | 생성 지도 4장과 스테이지 버튼·연결 경로 | 태블릿 회전·스크롤에서도 정확히 누를 수 있고 보스까지 이동 가능 |
| C | 방 종류, 일반/히든 상점, 대장간, 회복·사건 | 비용·보상 예고, 저장 복원, 중복 거래 방지 |
| D | 기존 6무기 +5 성장·분기·각성 | 각 무기를 처음부터 최종 성장까지 실제 플레이 가능 |
| E | 신규 6무기, 유물 40종, 조합 15종 | 모든 효과 실제 작동, 가방 조합·교체 계산 일치 |
| F | 오답 진행, 룬, 재출제, 학습 기록 | 오답으로 진행이 막히지 않고 정확히 한 전투에 적용 |
| G | 연출 통합·난이도·태블릿 검증 | 4지역 완주, 저장·죽음·재도전, 기본/심화·경로별 예산 검증 |
| H | 승인된 범위 배포, 학생 플레이 후 조정 | 운영 파일 일치 확인, 실제 학생 피드백 수집 |

### 꼭 확인할 시나리오

- 허용된 모든 경로의 보스 도달, 3개 선택지와 잠긴 길 구분.
- 지도 확대·축소·화면 회전·스크롤에서 버튼과 그림 정렬, 실수 입장 방지.
- 최소 전투 경로와 정예 중심 경로의 재화·회복·강화 기회.
- 12무기의 일반 공격·기술·분기·각성·개조 상호작용.
- 집중 조합과 여러 혼합 조합 동시 발동 시 성능과 무한 연쇄 방지.
- 상점 구매·히든 발견·보스 보상 직전과 직후 새로고침.
- 오답 0~3개, 비전투 방 경유, 보스 제한, 룬 정산과 학습 기록.
- 오래된 저장·손상 저장·여러 저장 칸, 이미지 로딩 실패.
- 배포 전 프로젝트 필수 `npm run check`와 변경 기능의 실제 브라우저 검증.

실제 태블릿의 프레임 속도와 학생 체감 난이도는 데스크톱 자동 검사로 대신하지 않는다. 학생 플레이 후 무기 선택률, 사망 구간, 결정 잔액, 상점 구매율, 첫 시도 정답률을 확인한다.

## 15. 사용자가 결정할 항목

다음 네 가지는 범위·학습량·장기 성장에 영향을 주므로 종합 작업 요청 전에 선택하면 좋다. 현재는 아래 추천안을 임시 기준으로 문서를 작성했다.

| 번호 | 결정할 내용 | 추천안 | 다른 선택을 할 경우 |
|---|---|---|---|
| D1 | 지역 크기와 목표 문제 수 | 지역당 5단계+보스, 총 기본 24방 방문·32문제 | 지역당 7단계+보스로 늘리면 상점·사건 선택이 풍부해지지만 총 32방 방문. 수업 소요 시간·출제량 재설계 필요 |
| D2 | 탐험 종료 후 무기 성장 계승 | 무기 강화·결정은 탐험마다 초기화. 도감·학습·클리어 기록 보존 | 영구 무기 강화 도입 시 장기 육성은 강해지지만 초회/누적 플레이 간 난이도 차이와 별도 경제 설계 필요 |
| D3 | 신규 무기 선택권 | 12종 모두 처음부터 선택 가능 | 일부는 보스 처치 등으로 해금하면 수집 목표가 생기지만 학생별 사용 가능 무기가 달라짐 |
| D4 | 스튜디오에도 오답 페널티 적용 | 이번에는 탑만 적용, 스튜디오는 후속으로 분리 | 함께 적용하면 스튜디오 성장 계산·공연 목표·도움말까지 별도 검증 필요 |

### 별도 결정을 요구하지 않는 세부 초안

강화 가격, 상점 상품 가격, 추가 적 수, 히든 방 출현 조건의 세부 수치, 혼합 조합 발동 주기는 위 방향을 기준으로 구현 시 검증하며 조정할 수 있다. 모든 숫자에 개별 승인을 요청하기보다, 핵심 방향을 바꾸는 변경이 생기면 이유와 영향을 설명한다.

### 이번 문서에 포함하지 않은 확장

온라인 협동·대전 규칙 개편, DJ코인 연동, 학생 간 아이템 거래, 스튜디오 전체 육성 개편, 무기 영구 성장, 모든 의상의 신규 원화는 별도 요청이 있어야 범위에 포함한다.
