# 마블 진행 배속

요청: 게임 진행에 배속 기능 추가. 구현·빌드 후 사용자 “배포진행” 승인에 따라 2026-09-17 14:03 KST 운영 Hosting 반영 완료.

- 게임 화면 상단 배속 버튼: 1× → 1.5× → 2× → 1×. 모바일에서는 짧게 `1×`만 표시한다. 접근성 이름에는 진행 배속과 현재 값이 포함된다.
- 주사위, 칸 이동, 비행, 건설, 감정 연출에 적용한다. 연습 모드의 봇 생각 시간과 주사위 입력 후 짧은 대기도 배속에 맞춰 줄인다.
- 브라우저 저장소에 설정을 저장하고 새 게임/새로고침 때 유지한다. 유효하지 않은 저장값이나 저장소 차단 환경에서는 기본 1×로 동작한다.
- 3D 연출에는 게임 판정 시간과 독립된 가상 시계를 사용한다. 배속 변경 순간까지의 시간을 보존해 진행 중인 이동을 되감거나 처음부터 재생하지 않는다. 실제 프레임 측정은 배속을 곱하지 않아 자동 품질 조절을 방해하지 않는다.
- WebGL 대체 화면에서는 Web Animations playbackRate를 적용한다. 모션 감소 설정은 유지한다.
- 서버 주사위, 턴 순서, 45초 제한, 20/30분 경기 종료, 랭킹 집계에는 영향을 주지 않는다. Functions·Rules·학생 데이터 변경 없음.

검증: 게임/네트워크 19개 테스트, 배속 실제 브라우저 비교, 감정 연출 회귀 검사. 고정 두 칸 이동에서 1× 약 2.20초, 2× 약 1.14초를 확인했다. 이는 로컬 연출 시간이며 학교 통신 지연 측정값이 아니다. 저장 설정, 게임 상태/마감 시각 불변, WebGL 대체 화면, 360px 배속 버튼도 확인했다. 자동 검사는 `tests/speed-smoke.js`, 통합 명령은 `npm run check:town-marble`이다.

최종 검사에서 이동 도중 1.5×→2× 변경 후 목적지·서버 상태가 유지됨을 확인했다. 6개 화면 크기·54개 상태의 HUD·도시명 배치 검사 및 소스 포맷 검사도 통과했다.

배포 전 `npm run check` 전체 검사 통과. 최신 운영 버전을 기반으로 `/town-marble/`의 빌드 파일 8개만 반영하고 나머지 402개 파일은 보존했다. Functions·Rules 배포나 학생 데이터 변경은 없다. Hosting 버전: `d7322468856d59f3`.

운영 검증(2026-09-17 14:11 KST): 공개 파일 8개가 빌드 결과와 일치했다. 대전 목록 진입·Firebase 초기화·비로그인 접근 제한, 1×→1.5×→2× 전환·설정 저장, 연습 주사위·이동·도착 감정, 모바일 버튼·가로 넘침 없음, 브라우저 오류 없음을 확인했다. 현재 메인 랭킹은 `hideout-ranking-plaza.js?v=3`의 `town-marble-rank`/`townMarbleRanking` 연결을 확인했다. 이전 독립 랭킹 스크립트 경로를 가정한 검증 조건을 현재 운영 구조에 맞췄으며, 대전 목록 전체 리소스 로딩 지연 1회 후 DOM 준비 기준 재검증은 통과했다. 학생 계정으로 실제 대전·랭킹 기록을 쓰지는 않았다.
