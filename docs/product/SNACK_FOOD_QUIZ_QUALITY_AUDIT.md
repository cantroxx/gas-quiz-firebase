# 간식 퀴즈 100문항 품질 분석 및 수정 제안

작성일: 2026-06-23

## 결론

간식 퀴즈는 현재 100문항 모두 이미지가 나오고 로딩 최적화도 적용되어 있지만, 문제 품질 기준으로는 그대로 100문항을 유지하기 어렵다.

핵심 문제는 세 가지다.

1. 제품명이 포장 전면 여러 곳에 반복되어 블러 좌표만으로 정답 노출을 완전히 막기 어려운 문항이 있다.
2. 껌류, 초콜릿류 일부는 제품 형태 단서가 약해서 글자를 가리면 정답을 유추하기 어렵다.
3. 정답명이 너무 세부적이거나 실제 이미지와 어긋나는 문항이 있다.

가장 좋은 문항 유형은 도리토스, 월드콘처럼 포장 실루엣이나 상품 형태가 뚜렷하고, 제품명 일부만 가려도 보기와 비교해 맞힐 수 있는 문제다.

## 추천 작업 순서

1. 정답명 오류부터 수정한다.
2. 과하게 어렵거나 식별 단서가 약한 껌류/초콜릿류를 교체 후보로 분리한다.
3. 사용자가 지적한 이미지 5개를 우선 마스크 보정한다.
4. 남길 문항은 "상품 형태 단서가 살아 있는 이미지"로 교체하거나 좌표를 다시 잡는다.
5. 최종 목표는 100문항을 억지로 유지하기보다, 70~80개 고품질 문항을 먼저 안정화하고 이후 검증된 상품으로 보충하는 것이다.

## 권장 교체 규모

현재 100문항 중 바로 유지 가능한 문항은 약 55~65개 수준이다. 나머지는 아래처럼 처리하는 것이 좋다.

| 처리 | 예상 문항 수 | 설명 |
|---|---:|---|
| 유지 | 55~65 | 라면류, 대표 과자, 대표 아이스크림 |
| 마스크 수정 후 유지 | 5~8 | 신라면 블랙, 칙촉, 찰떡아이스, 애니타임 등 |
| 정답명 수정 | 2 | 제로, 자일리톨 판 |
| 교체/삭제 | 25~35 | 껌류, 초콜릿 세부 상품, 인지도 낮은 상품 |

## 교체 후보 상품 방향

새 문항은 아래 조건을 만족해야 한다.

1. 제품명 없이도 포장색, 형태, 실물 이미지로 어느 정도 구분된다.
2. 초등학생에게 익숙한 상품이다.
3. 정답이 너무 세부 상품명이 아니라 보편적으로 부르는 이름이다.
4. 제품명 텍스트가 한두 곳에만 있어 마스크가 쉽다.

추천 보강 후보 예시는 다음과 같다.

| 분야 | 후보 |
|---|---|
| 라면 | 왕뚜껑, 새우탕, 튀김우동, 오징어짬뽕, 팔도비빔면 |
| 과자 | 포카칩, 새우깡, 양파링, 홈런볼, 오레오, 초코송이, 고래밥, 자갈치 |
| 아이스크림 | 부라보콘, 수박바, 죠스바, 스크류바, 돼지콘, 구구콘 |
| 젤리/캔디 | 마이쮸, 새콤달콤, 하리보, 멘토스 |

## 제안 작업안

1차 작업은 "품질 안정화"로 잡는다.

1. 제로 정답을 제로 초코파이로 수정한다.
2. 자일리톨 판은 삭제하거나 자일리톨로 통합한다.
3. 스피아민트, 후레쉬민트, 쥬시후레쉬, 후라보노, 이브, 자일리톨 알파, 아이디, 아라비카 커피껌, 왓따, 졸음번쩍껌은 교체 후보로 둔다.
4. 칙촉, 찰떡아이스, 애니타임은 우선 마스크 보정이 가능하지만, 더 좋은 이미지가 있으면 교체가 낫다.
5. 도리토스, 월드콘, 바나나킥, 돼지바, 메로나, 빼빼로, 몽쉘, 초코파이, 카스타드 같은 기준 문항을 중심으로 새 후보를 맞춘다.

2차 작업은 "100문항 복구"로 잡는다.

1. 교체 후보 25~35개를 제거한다.
2. 대중성과 이미지 단서가 좋은 새 상품을 같은 수만큼 추가한다.
3. 추가 후 전체 문항을 다시 눈검수한다.
4. 최종 배포 전 연습전 객관식, 랭킹전 주관식 양쪽에서 20문항 이상 플레이 검증한다.
