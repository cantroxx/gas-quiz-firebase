# 분수 월드 — 생존 액션과 아이돌 육성

## 확정된 방향

사용자 요청: 4학년 2학기 분수의 덧셈과 뺄셈을 충분히 연습하는 두 개의 독립적인 큰 게임. 태블릿 터치를 기본으로 하며 부착형 키보드도 지원한다. 작은 시범판에서 멈추지 않고, 처음부터 종료와 재도전까지 구성한다. 게임 자체는 쉽게 클리어할 수 없게 만들고 학생 플레이 후 조정한다.

구현 진입점은 `/fraction-world/`. 퀴즈타운 `/battle/` 게임 광장에 연결한다. 기존 수학서바이버·워드배틀과 별개다.

## 공통 학습

- 같은 분모 3~12, 음수가 나오지 않는 덧셈·뺄셈을 생성한다.
- 진분수 덧셈, 진분수 뺄셈, 1을 넘는 덧셈, 대분수 덧셈, 대분수 뺄셈, 받아내림 뺄셈의 6유형.
- 진분수 기초 / 대분수 연습 / 전체(받아내림 포함)를 학습 설정에서 선택한다.
- 게임 도전 강도와 학습 설정은 독립적이다.
- 자연수·분자 칸, 고정 분모, 큰 숫자 패드. 키보드 숫자·좌우 화살표·Backspace·Enter 지원.
- 가분수와 대분수의 동치를 정수 산술로 판정한다. 소수 반올림 오차가 없다.
- 힌트는 받아내림 설명과 처음 양의 분수 막대. 2회 오답 이후 자동 힌트.
- 계산에는 제한 시간이 없고 전투가 정지한다. 오답으로 능력치를 차감하지 않는다.
- 첫 시도 정답률, 해결 문제 수를 유형별로 기록한다. 일부 문제는 상대적으로 약한 유형을 우선한다.
- 독립 10문제 연습과 학습 수첩 JSON 내려받기 제공. 내려받기는 저장 파일 복원 기능이 아니다.

## 균열의 탑

- 4지역 × 6방 = 24방. 각 지역 마지막 방은 보스전.
- 지역: 이끼빛 폐허, 유리 사막, 푸른 잿불 성채, 별 없는 왕좌.
- 6무기: 지팡이, 활, 부채, 보주, 바늘, 대포. 공격 간격·위력·탄속·발사체 수·관통이 다르다.
- 24유물, 최대 8개 장착, 보상 3택1, 가방이 찼을 때 교체 선택.
- 5속성 공명: 같은 속성 3개로 추가 효과. 발사체 증가, 냉각, 치명타, 흡수, 반격, 회피·특수 기술 단축 등이 실제 전투에 적용된다.
- 적: 추격, 원거리, 돌진, 분열, 선회, 회복과 보스. 지형 장애물에 이동·투사체 충돌.
- 보스: 뿌리 돌진, 마녀 원형 탄막, 기사 돌진+탄막, 심장 탄막+소환. 체력 절반 이후 공격 빈도/탄 수 증가.
- 일반 / 위험 / 회복 경로. 회복에는 탐험 결정이 필요하고 반복 구매할 수 없다.
- 이동 패드 또는 WASD/방향키, 자동 공격, 회피(Space), 별 폭발(E). 특수 기술은 가까운 탄막도 제거한다.
- 도전자 / 균열의 지배자. 후자는 적 피해 35% 증가 및 보스 탄막 강화.
- 입장 4문제 + 보물 2문제 × 24방 = 완주에 기본 144문제. 재시도 문제는 추가된다.
- 방/선택/학습 시 저장, 전투 10초 체크포인트, 로비 이동·백그라운드·페이지 종료 시 전투 스냅샷 저장.
- 실패 시 탐험의 장비는 종료되지만 발견 도감과 학습 기록은 유지된다. 누적 능력치로 난이도가 사라지지 않는다.
- 최종 클리어 트로피, 종료 기록, 다른 무기·강도로 재도전.

## 스타라이트 스튜디오

- 8명 중 3명을 선택. 멤버별 초기 보컬·댄스·표현과 성장/휴식/팀워크 특성이 다르다.
- 28일 시즌. 매일 오전·오후·저녁 3활동을 계획하고 분수 6문제로 실행한다.
- 12활동: 보컬, 안무, 표현, 합동 연습, 리허설, 휴식, 소풍, 라디오, 거리 공연, 곡 연구, 워크숍, 팬 만남.
- 실력·컨디션·팀워크·자금·팬·곡별 숙련도를 관리한다. 비용은 활동 순서대로 계산하므로 오전 수입을 오후 훈련에 사용할 수 있다.
- 체력 45 미만이면 실력 성장 75%, 25 미만이면 45%. 피로를 방치하면 훈련 효율이 낮아진다.
- 9곡, 3콘셉트, 곡별 보컬·댄스·표현 가중치. 곡마다 숙련도가 따로 저장된다. 상위 곡은 시즌 진행으로 해금된다.
- 12의상: 곡 콘셉트 일치 시 점수 보너스. 자유 콘셉트도 존재한다.
- 6시설 × 3단계: 각 훈련 성장, 휴식, 팬 증가, 무대 점수에 영향.
- 선택형 이벤트 8종. 선택 전 자원 변화를 공개한다.
- 7/14/21/28일 공연. 무대 점수·팀워크·컨디션·팬 4조건을 동시에 충족해야 성공.
- 점수 = 가중 실력 × 0.65 + 숙련 × 0.18 + 팀워크 × 0.12 + 시설 + 의상 + 곡 콘셉트 보정 + 곡 등급 보정. 화면은 반올림된 예상 점수와 목표를 공개한다.
- 공연 실패에도 참가 보상과 시즌 진행은 유지한다. 28일 최종 공연 성공이 시즌 클리어 조건이다.
- 도전 기획사 / 전설의 프로듀서. 후자는 무대·팀워크·팬 요구량 12% 증가.
- 일정 168문제 + 공연 16문제 = 시즌당 기본 184문제.
- 멤버, 음악/의상, 시설, 달력, 공연 기록을 탭으로 확인한다. 일정 실행 중 구매/변경은 제한된다.
- 다음 시즌은 초기 능력·예산으로 시작한다. 이전 결과에 멤버·보유 의상 목록·공연 성공 수가 기록된다.

## 저장과 운영 경계

- 자체 `localStorage` 키 `dj48.fraction-world.v1`, 모험가 저장 칸 3개.
- 두 게임 진행·재화는 독립, 같은 저장 칸의 학습 수첩은 공유.
- 다른 기기 자동 동기화 없음. 브라우저 데이터 삭제 시 진행이 사라진다는 안내를 로비/도움말에 표시한다.
- 손상된 게임 진행은 해당 부분만 제외하고 읽을 수 있는 학습·다른 칸 기록을 유지한다. 저장 실패는 사용자에게 표시한다.
- 개인정보 입력, Firebase 데이터 쓰기, DJ코인 지급, 랭킹 쓰기, 새 보안 규칙은 없다.
- 세피리아의 장르적 구조를 참고했으나 이름·캐릭터·환경·그림·코드는 자체 제작이다. 외부 게임 에셋/음악을 복제하지 않았다.
- 코드 네이티브 SVG/Canvas 그림, 기기 폰트, 선택적 Web Audio 효과음. 외부 CDN/폰트/그림 의존 없음.

## 학생 플레이 후 조정할 항목

실제 학생 난이도·재미·수업 소요 시간은 아직 측정하지 않았다. 자동 검증은 클리어 가능성과 상태 전이의 근거이며, 학생의 체감 난이도나 실제 태블릿 성능을 대신하지 않는다.

첫 피드백에서 보스별 도달 방, 실패 원인, 첫 시도 정답률, 받아내림 오답, 체력/예산 관리 이해, 손가락으로 패드와 회피를 함께 쓰기 편한지를 확인한다. 학생 개인 정보 없이 수업 관찰과 기기 내 학습 수첩으로 시작할 수 있다.
