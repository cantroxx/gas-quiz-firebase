### 확인한 공식 자료

- 국어: [경기도교육청 2025 초등 3~4학년 수업·평가 계획 예시자료](https://www.goe.go.kr/resource/goe/na/bbs_2675/2025/07/f4c15fac-ae7b-46aa-8e16-b8d86b710d44.pdf), 인쇄 10~12쪽 성취기준·단원 연결표를 이미지로 확인했다. 국어 교과서 작품을 복제하지 않고 자체 짧은 글을 사용한다.
- 수학: [아이스크림 4-1](https://text.i-scream.co.kr/user/introduce/introduceDetail.do?subject=math4_1), [4-2](https://text.i-scream.co.kr/user/introduce/introduceDetail.do?subject=math4_2)의 공개 교과서 목차 이미지. 4-1 마지막 단원은 구판의 명칭 대신 **규칙과 관계**다.
- 사회: 비상 교과서에 대응하는 공식 자습서의 목차 탭 [4-1](https://book.visang.com/books/info/5601), [4-2](https://book.visang.com/books/info/5770).
- 과학: 비상 공식 자습서의 목차 탭 [4-1](https://book.visang.com/books/info/5603), [4-2](https://book.visang.com/books/info/5778). 4-2는 밤하늘 관찰 / 생물과 환경 / 여러 가지 기체 / 기후변화와 우리 생활이다.

## 생성 방식과 품질 관리

- 수학: 수·조건을 매번 생성하고 같은 계산식에서 정답·해설·도식을 만든다. 소수는 정수 단위로 계산한 뒤 표시한다. 분수는 문제에서 같은 분모 표현을 요구하여 동치인 보기가 동시에 정답이 되는 것을 피한다.
- 국어: 자체 상황·짧은 글, 의견과 근거, 관찰 보고, 감각 표현, 높임·배려, 원인과 결과, 매체 출처 판단을 단원 목표에 연결한다. 맞춤법은 검토한 초등 범위 표현을 조합한다.
- 사회·과학: 개념·정의·사례의 관계에서 사례 분류, 설명 선택, 연결 판단 문제를 만든다. 방위, 예산, 투표, 자석의 극, 상태 변화, 먹이 관계, 기체 실험 등은 조건을 바꿔 출제한다.
- 역사: 시대별 사실·관계·순서를 바꿔 묻는다. 시대 시작을 편의상 숫자로 표현한 내부 연도는 정확한 연도 맞히기 문제로 노출하지 않는다. 동년 사건끼리는 앞뒤 순서를 묻지 않는다.
- 생성 결과는 보기 4개가 서로 다르고 정답이 하나인지 검사한다. 서버가 최근 문항의 질문·정답 지문을 기록해 같은 판의 즉시 반복을 줄인다.
- 현재 모든 문항은 객관식으로 구현했다. 서술형·자유 감상·논쟁적 판단은 자동 랭킹 채점 대상이 아니다.

고정된 100문항을 모두 풀고 같은 목록을 재시작하는 제한을 제거했다. **학습 개념과 사실 자체가 무한한 것은 아니다.** 단원별 대표 개념을 다루는 초기 생성기이며, 해당 단원의 모든 수행평가·성취기준을 완전히 대체한다는 의미는 아니다. 내용 확대는 완성 문제 DB를 쌓기보다 학습 목표별 생성 규칙·사례·오답 유형을 추가하는 방식으로 진행한다.

### 내용 수정 절차

1. curriculum에서 해당 단원을 찾고 generator/language/knowledge의 연결 규칙을 수정한다.
2. 개념·사실을 바꿀 때 공식 교과서/교육청 자료 또는 해당 분야의 신뢰할 수 있는 출처와 대조한다. 교과서 지문·삽화를 그대로 저장하지 않는다.
3. `npm run test:subject`로 모든 단원의 생성 결과와 계산·보기 중복·정답 비노출을 검사한다.
4. 실제 보기와 해설을 함께 읽고 복수 정답·논리적으로 가능한 오답·학년 밖 개념을 점검한다. 자동 구조 검사는 교육적 내용 검토를 대체하지 않는다.
5. 문제 의미가 바뀌면 서버 코드와 생성 버전을 함께 관리한다. 기존 판 도중 배포로 문제 의미가 달라지지 않도록 판에는 생성된 현재 문항을 저장한다.

## 확정된 랭킹 정책

- 단원은 출제 범위를 고르는 용도이며 별도의 단원 랭킹을 만들지 않는다.
- 과목별 통합 누적, 정답 1개 = 1점. 최고 기록 갱신 방식이 아니다.
- 각 판은 하트 3개, 서버 기준 300초. 오답은 하트 1개 감소, 0개 또는 시간 만료 시 종료.
- 해설을 읽는 시간, 네트워크 대기, 다른 탭에 머문 시간도 5분에 포함된다.
- 제출이 서버에 도착했을 때 시간이 만료되었으면 점수를 더하지 않는다. 이미 인정한 정답은 중간 종료·연결 끊김에도 남는다.
- 같은 과목의 재도전·다른 학기·단원·맞춤법 점수를 계속 합산한다. 국어 17 + 20 + 22 = 59점.
- 연습 정답은 랭킹에 포함하지 않는다. 개인 단원별 풀이/정답 통계는 별도로 유지한다.
- 점수는 서버의 단일 트랜잭션에서 채점·누적한다. 동일 문제의 재시도는 한 번만 인정한다. 한 계정에서 여러 판을 동시에 시작하지 못한다.
- 새 버전 `subject-2022-v1`부터 0점으로 시작한다. 구형 과목 랭킹과 종합 랭킹 기여분은 조회에서 제외하고 원본은 보존한다. 인기 퀴즈 기록·기존 코인·획득 뱃지는 유지한다.
