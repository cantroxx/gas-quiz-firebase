# 맵 단순화와 중복 UI 정리 계획

사용자 추가 요청 1~5번. 아래 단계를 순서대로 완료한다.

1. [x] 현 상태 보존, 중복 토글/제목·보유아이템/하보 진입·아바타 대체 표시·접속/새소식/내상태 경로 확인.
2. [x] 타운용 사람·확성기·손드는 토끼 아이콘 제작. 맵 내부 좌상단 접속/새소식, 우상단 내상태 배치. 위아래 설명·빠른 이동 제목·알림판/이용안내 버튼 제거. 실제 새 소식 상태에만 강조 표시.
3. [x] 퀘스트 창 중복 토글 및 유사 중복 정리. 보유아이템/하보 꾸미기의 학생 진입만 제거하고 기능·데이터 보존. 노란 점 표시 원인 구분 및 확인된 아바타 문제 수정.
4. [x] 실제 기능 연결·계정 분리·새소식 강조·키보드·모바일·정리 항목 회귀 검사, npm run check 통과.
5. [x] 현재 운영본에 이번 차이만 적용한 후보 검증 후 Hosting 배포, 운영 파일/화면 확인·보고.

## 범위
오늘의 퀘스트와 보상 유지. 독립 housing 기능·데이터는 삭제하지 않는다. 학생 데이터 변경, Functions/Rules 배포, 재화 초기화, Git 커밋/푸시는 하지 않는다.

## 확인 근거
Safari의 현재 계정 상점에서 보유 1개, 선택한 아이템 영역의 “아직 착용한 아이템이 없어요.” 확인. 구매·장착·염색은 실행하지 않고 타운으로 복귀했다. 현재 노란 점은 장착 코디가 없는 상태와 로딩 실패를 같은 표식으로 표현하는 기존 처리다. 원인을 상태별로 구분한다.
