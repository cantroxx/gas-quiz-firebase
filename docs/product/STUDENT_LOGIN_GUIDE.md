# 학생 로그인 안내

## 사이트 주소

```text
https://dj48-quiztown-firebase.web.app
```

## 처음 들어오는 학생

1. 사이트에 접속한다.
2. `내 집`으로 들어간다.
3. 학교, 학년, 반, 번호를 입력한다.
4. `기존 닉네임`에 원래 퀴즈 사이트에서 쓰던 닉네임을 입력한다.
5. 새 비밀번호를 만든다.
   - 4자리 이상
   - 숫자만 써도 가능
   - 너무 쉬운 값은 사용할 수 없음
6. `처음 비밀번호 만들기`를 누른다.
7. 로그인이 되면 퀴즈, 상점, 내 집을 사용할 수 있다.

## 이미 비밀번호를 만든 학생

1. 사이트에 접속한다.
2. `내 집`으로 들어간다.
3. 학교, 학년, 반, 번호, 비밀번호를 입력한다.
4. `로그인`을 누른다.

## 비밀번호를 잊은 학생

선생님에게 비밀번호 초기화를 요청한다.

초기화 후 임시 비밀번호는 기본적으로 `학년 + 반 + 두자리 번호`이다.

예시:

- 4학년 8반 22번: `4822`
- 4학년 8반 5번: `4805`

임시 비밀번호로 로그인하면 새 비밀번호를 다시 설정해야 한다.

## 학생에게 알려줄 주의사항

- 다른 친구 번호로 로그인하지 않는다.
- 비밀번호를 친구에게 알려주지 않는다.
- 로그인이 안 되면 학교, 학년, 반, 번호를 먼저 확인한다.
- 처음 비밀번호 만들기가 안 되면 기존 닉네임을 정확히 입력했는지 확인한다.
- 그래도 안 되면 선생님에게 문의한다.

## 선생님 확인 기준

- 학생이 최초 비밀번호 설정에 성공하면 `users/{memberUserId}.authUid`가 연결된다.
- 이후 로그인은 비밀번호 검증 후 같은 회원 문서에 다시 연결된다.
- 비밀번호 초기화가 필요한 경우 `scripts/maintenance/reset-member-password.js`를 사용한다.
- 최초 비밀번호 설정 기간은 2026-06-17 23:59:59 KST까지 열려 있다.
