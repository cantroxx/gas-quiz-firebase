## 2. 공개 랜딩 UI 특징

그라운드 랜딩은 `사회정서 + 학급 경제`를 첫 화면의 가장 큰 가치 제안으로 둔다.

주요 특징:

- 상단 고정 내비게이션: 로고, 이용관련, 커뮤니티, 요금제 안내, 가입하기, 로그인
- 첫 화면: 대형 브랜드 타이틀, 성장 플랫폼 카피, 시작하기 CTA
- 신뢰 지표: 선생님 수, 학급 수, 학생 수를 숫자로 노출
- 기능 설명은 교육 가치 축과 실제 기능 축을 분리해 설명
- 최신 업데이트와 인증 스쿨을 하단 신뢰 요소로 배치
- 학교 예산/도입 문의 배너를 최상단에 별도 노출

DJ48 반영 포인트:

- `우리 교실` 첫 화면에 기능 설명보다 운영 상태와 오늘 할 일을 먼저 보여주는 편이 낫다.
- 랜딩식 대형 히어로는 DJ48 앱 내부에는 과하다. 대신 교실 진입 전 안내에는 `퀴즈타운 활동과 교실 경제가 분리된다`는 핵심을 짧게 줄 수 있다.
- 신뢰 지표 방식은 운영 대시보드에 `학생 수`, `대기 작업`, `이번 달 베리 흐름`으로 변환 가능하다.

## 3. 로그인 UI

교사 로그인:

- 이메일 입력
- 비밀번호 입력
- 로그인 버튼
- 학생 로그인 전환 버튼
- 비밀번호 재설정, 회원가입 링크

학생 로그인:

- 클래스 닉네임
- 본인 이름
- 4자리 코드 입력
- 선생님 로그인 전환 링크

DJ48 반영 포인트:

- DJ48의 학년/반/번호/비밀번호 방식은 관리에는 명확하지만 학생 입장에서는 입력 필드가 많다.
- 장기적으로는 `학급 코드 또는 교실 닉네임 + 이름 + 개인 코드` 방식이 학생 UX에는 더 가볍다.
- 현재 DJ48은 운영 회원 구조가 학년/반/번호에 강하게 묶여 있으므로 즉시 변경보다는 교실 입장 UX에서만 간소화하는 방향이 안전하다.

## 4. 공개 가이드 IA

그라운드 가이드는 좌측 사이드바와 중앙 문서형 본문으로 구성되어 있다.

상위 분류:

- 그라운드 기본 가이드
- 멀티클래스 관리
- 부가 기능들
- 메타그라운드
- 요금제 및 문의
- 개발자 문서
- 그라운드 유니버스
- 경제 정책 설계 가이드

핵심 기능 분류:

- 기본 화면 안내
- 카드 모드
- 텃밭 은행 모드
- 마켓 모드
- 케이브 모드
- 젬스톤 모드
- 직업 모드
- 클래스 알림
- 학급 미션
- 정서 관리
- 관찰 기록
- 포인트 현황
- 퀘스트
- 성장 루틴
- 퀘스트 리더보드
- 교실 배치도
- 리포트

DJ48 반영 포인트:

- DJ48 `우리 교실`은 현재 탭이 기능 단위로 나뉘어 있지만, 교사용 관점의 `운영`, 학생 관점의 `내 활동` 분리가 약하다.
- 그라운드식 IA를 참고하면 DJ48 교실은 다음처럼 묶는 것이 자연스럽다.
  - 학생: 오늘 할 일, 내 베리, 내 직업, 내 젬/뱃지, 내 쿠폰
  - 교사: 운영 요약, 퀘스트 관리, 직업 관리, 상점 관리, 학생 현황, 리포트

## 5. 기능별 UI 관찰

### 5.1 기본 화면

공개 가이드 기준 그라운드는 4가지 주요 뷰 모드를 상단 버튼으로 전환한다.

- 카드
- 텃밭 은행
- 마켓
- 케이브

가이드에는 젬스톤과 직업도 모드형 기능으로 이어진다.

DJ48 현재 상태:

- `우리 교실` 내부 탭: 퀘스트, 학생카드, 젬스톤, 직업, 교실상점, 성장루틴
- 최근 추가: 담임 전용 교실 운영 요약

업데이트 제안:

- 학생 화면에는 탭을 줄이고 `오늘`, `내 성장`, `상점` 정도로 묶는다.
- 교사 화면에는 탭을 유지하되 대시보드에서 각 관리 화면으로 바로 이동하는 버튼을 둔다.

### 5.2 마켓

공개 가이드 기준 마켓은 학생 카드에서 구매 창으로 이어지고, 다음 구조를 가진다.

- 학생별 상품 구매
- 학생별 최대 보유량 제한
- 상품 사용하기
- 교사의 상품 선물하기
- 공동구매
- 이용 히스토리
- 마켓 상품 관리

DJ48 현재 상태:

- 교사가 상품 생성
- 학생이 베리로 구매
- `shopPurchases` 기록 생성
- 사용 요청/사용 완료 UI는 아직 없음

업데이트 제안:

1. 보유 쿠폰 목록
2. 사용 요청 버튼
3. 담임 사용 승인/완료 처리
4. 구매/사용 히스토리
5. 1인 보유 한도 또는 상품별 구매 제한
6. 공동구매는 후순위

### 5.3 퀘스트

공개 가이드 기준 그라운드 퀘스트는 다음 유형을 제공한다.

- 완료형
- 상중하
- 문자입력
- 체크리스트

운영 기능:

- 노출형/비노출형
- 특정 학생 대상 퀘스트
- 카테고리
- 엑셀 다운로드
- 알림장 형태 전체보기
- 목록 배열, 복제, 참여 링크 복사
- 반복 복제 스케줄링

DJ48 현재 상태:

- 자동 지급형
- 담임 확인형
- 퀴즈 달성형 설정값
- 퀘스트 생성
- 젬 연동
- 담임 승인/반려

업데이트 제안:

1. 퀘스트 수정/비활성화
2. 노출/비노출
3. 반복 가능/하루 1회 제한
4. 대상 학생 지정
5. 체크리스트형
6. 문자 제출형
7. 퀘스트 카테고리
8. 참여 현황 다운로드는 후순위

### 5.4 젬스톤

공개 가이드 기준 젬스톤은 퀘스트와 연동되는 성취형 게이미피케이션이다.

구조:

- 교사가 젬스톤 생성
- 퀘스트 생성 시 젬스톤 연동
- 학생이 조건 횟수만큼 퀘스트 달성
- 젬스톤을 뱃지성 보상으로 획득

DJ48 현재 상태:

- 퀘스트 생성 폼에서 젬 이름, xp, 목표 xp, 보상 베리 설정
- 완료 시 `studentGemProgress` 누적
- 완료 젬을 대표 뱃지로 선택

업데이트 제안:

- 젬스톤 관리 전용 화면 추가
- 젬별 연결 퀘스트 목록 표시
- 학생별 젬 진행도 표
- 젬 획득자 목록
- 대표 뱃지와 캠페인 뱃지 구분 표시

### 5.5 직업

공개 가이드 기준 직업 모드는 학급 역할 카드 중심이다.

구조:

- 교사가 직무와 해야 할 일을 설정
- 학생이 직업 카드에 지원
- 정원 이상 지원 시 추첨 방식 배정
- 학생은 최대 2개 직업 참여 가능
- 교사가 원하는 시점에 월급 지급
- 월급은 하트베리로 지급
- 소득세를 차감하고 기금으로 축적
- 소득세 비율 설정 가능

DJ48 현재 상태:

- 직업 생성
- 학생 지원
- 교사 배정
- 배정 해제
- 월급 지급
- 현재 구현은 학생 1인 1직업에 가깝다.

업데이트 제안:

1. 급여 주기/명칭을 월급으로 정리
2. 직업 정원 설정
3. 지원자 목록과 배정 방식 개선
4. 복수 직업 허용 여부 정책화
5. 소득세/학급 기금은 후순위
6. 직업 수행 체크는 중간 우선순위

## 6. DJ48 UI 업데이트 우선순위

### 1순위: 학생용 교실 홈

현재 DJ48은 기능 탭이 먼저 보인다. 학생에게는 오늘 해야 할 일 중심이 더 적합하다.

권장 구성:

- 내 베리
- 오늘 할 퀘스트
- 오늘 체크할 성장루틴
- 내 직업
- 내 보유 쿠폰
- 내 젬/대표 뱃지

### 2순위: 교사용 운영 홈 강화

최근 추가한 `교실 운영 요약`을 확장한다.

추가 카드:

- 사용 요청 쿠폰
- 미제출/미참여 학생
- 이번 달 지급 베리
- 이번 달 사용 베리
- 직업 미배정 학생

### 3순위: 퀘스트 관리 화면

그라운드 대비 가장 큰 차이는 퀘스트 운영 도구의 깊이다.

필요한 UI:

- 퀘스트 목록 관리
- 수정
- 비활성화
- 복제
- 대상 학생 지정
- 반복 설정
- 제출/완료 현황

### 4순위: 교실 상점 후속 흐름

구매 이후 흐름을 완성한다.

필요한 UI:

- 구매 내역
- 보유 쿠폰
- 사용 요청
- 사용 승인
- 사용 완료
- 히스토리

### 5순위: 젬/직업 관리 화면 분리

현재는 퀘스트 생성 폼과 직업 탭에 흩어져 있다.

필요한 UI:

- 젬스톤 관리
- 직업 관리
- 학생별 진행 표
- 획득/배정 이력

## 7. 디자인 톤 비교

그라운드:

- 밝은 배경
- 큰 브랜드 타이틀
- 부드러운 카드와 둥근 버튼
- 교육/성장/경제를 한 화면에서 설명
- 가이드 문서는 문서형 사이드바 IA
- 기능 화면은 모드형 접근을 강조

DJ48:

- 퀴즈타운 지도 기반 진입
- 앱 내부 기능 탭 중심
- 카드형 UI와 학급 경제 기능은 이미 있음
- 교사용/학생용 정보 구조 분리가 아직 약함

DJ48 적용 방향:

- 랜딩 페이지처럼 키우기보다 앱 내부 운영 도구답게 밀도 있게 개선한다.
- 학생용은 `오늘 할 일`과 `내 상태`를 첫 화면에 둔다.
- 교사용은 관리 탭보다 `대기 작업`과 `학생 상태`를 먼저 둔다.
- 그라운드의 텃밭/케이브/메타버스 같은 세계관 요소는 DJ48의 퀴즈타운 지도와 연결할 때만 선택적으로 가져온다.
