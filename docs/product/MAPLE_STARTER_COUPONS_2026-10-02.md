운영 `coordiShopAction` 및 Hosting 7개 파일에 무료화를 반영했다. Hosting 버전 `819a9f8531608d0f`, 릴리스 `1790900505069000`. 기존 운영본을 복제하여 다른 파일과 설정을 보존했다.

9-9-99 실계정 테스트는 로그인 화면의 기본 비밀번호 안내에 따른 한 차례 시도에서 ‘회원 연결 중 문제가 생겼어요’로 실패했다. 사용자에게 학교/현재 비밀번호 확인 또는 직접 로그인을 요청했다. 실제 로그인 테스트 성공으로 보고하지 않는다.

## 후속 수정: 구매 쿠폰 20장 (현재 로컬 사양)

사용자 수정 요청으로 아래 부위별 첫 선택 무료 정책을 폐지했다. 계정당 구매 쿠폰 20장을 한 번 제공하고 구매 시 `coin` 또는 `coupon`을 명시적으로 선택한다. 쿠폰은 미보유 아이템 1개당 1장, 가격·부위 제한 없이 사용한다. 잔액 부족 시 결제를 거부하며 코인으로 자동 전환하지 않는다. 기존 보유 상품과 이미 받은 첫 염색 혜택은 보존하고 신규 구매로 첫 염색 혜택을 추가하지 않는다.

기존·신규 계정 모두 `purchaseCouponGrant=welcome-20-v1`와 `purchaseCoupons`로 관리한다. 미지급 계정은 조회 시 20장 권리가 표시되고, 첫 성공 거래에서 지급 표식과 잔액을 원자적으로 기록한다. 재접속·새 요청 ID·동시 결제로 재지급되지 않는다. 기존 하우징의 주간 쿠폰과는 별개다. 데이터 일괄 수정 없음.

정적 검사, 20장 지급·중복 방지·소진 경합·실패 롤백 Emulator 검사, 코인/쿠폰 버튼·잔액 표시·부족 방지·모바일 및 기존 염색 브라우저 검사 통과.

## 구현 범위

- 상점 진입 시 메이플 코디 iframe을 즉시 연다. 종전 코디 상점/드레스룸 선택 화면을 생략하며 무료 입어보기 모드는 코디 내부에서 유지한다.
- 기존 보유 아이템·코인·하우징 자료는 삭제하지 않는다.
- 14개 판매 부위(헤어·성형·피부·모자·얼굴장식·눈장식·귀고리·상의·한벌옷·하의·신발·장갑·망토·무기)에 각각 1개 무료 선택권을 제공한다. 투명 아이템은 해당 실제 부위 쿠폰을 사용한다. 상하의와 한벌옷 쿠폰은 별개이며 기존 동시 장착 제한을 유지한다.
- 가입일에 관계없이 아직 사용하지 않은 계정에 적용한다. 신규 가입/매주 지급이 아닌 계정당 부위별 1회 혜택이다.
- 무료로 선택한 아이템에는 첫 유효 염색 1회가 포함된다(성형 제외). 원색 복원·같은 색 재저장은 무료이고 쿠폰을 소모하지 않는다. 이후 염색은 50 DJ코인이다.
- 헤어는 8색 선택, 의상·피부는 기존 색조/채도/명도 조절을 사용한다. 구매 전에는 미리보기만 가능하고 보유 후 저장한다.

## 데이터와 검증

기존 `coordiProfiles`에 `starterClaims`(부위→무료 아이템 ID), `starterDyes`(사용한 아이템 ID→true)를 추가한다. 미사용 쿠폰은 판매 부위와 사용 내역에서 계산하므로 상태 조회/무료 미리보기에는 쓰기가 없다. 쿠폰 사용은 구매/염색의 기존 서버 트랜잭션 안에서만 저장한다. `prisms`에서 헤어는 `{hairColor:0..7}`로 저장하고 미리보기 요청의 헤어 코드에 반영한다. 운영 데이터 마이그레이션, Rules 수정 없음.

- 정적 검사 통과.
- `tests/coordi-shop/starter-emulator.test.js`: 별도 demo Firebase Emulator에서 14개 쿠폰, 중복 요청, 동시 구매, 무료/유료 염색, 원색 복원, 잘못된 색·미보유 아이템 거부, 실패 시 롤백, 상점 잠금 검증 통과.
- `scripts/smoke/coordi-entry-browser.js`: 바로 진입·잠금·관리자 예외 통과.
- `scripts/smoke/coordi-starter-browser.js`: 모의 API로 쿠폰 가격·구매·헤어 미리보기 요청·무료/유료 저장·재접속·모바일 넘침 검증 통과.
- 기존 `coordi-commerce-browser.js`, preview/catalog 테스트 통과.

## 남은 확인과 배포

헤어 색상은 헤어 코드의 색상 자리로 전달한다. 기존 외부 렌더 서비스 연결이 `ECONNREFUSED`로 실패해 실제 이미지를 통한 헤어 색상 확인은 미완료다. 모의 이미지 검증을 실제 색상 렌더 검증으로 간주하지 않는다. 미리보기 실패 시 염색 적용 버튼은 비활성화된다.
