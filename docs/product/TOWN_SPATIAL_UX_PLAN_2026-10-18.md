# 퀴즈타운 공간형 UI 실행 계획 — 2026-10-18

## 목표와 고정 범위

로그인 → 마을 산책 → 건물 입장 → 가구·게시판 선택 → 실제 기능 이용 → 공간으로 돌아오기의 흐름을 구현한다. 이전 배너·색상 개선과 구분하여 **새로 생성한 장면 자체가 기능의 입구**가 되게 한다. 옛 어린이 웹게임의 친근한 탐험 감각을 참고하되 기존 서비스의 캐릭터·원화를 복제하지 않는다.

- 타운: 다섯 목적지가 보이는 새 지도, 산책 도우미 이동, 건물 입장, 빠른 이동.
- 로그인: 같은 마을 세계관의 입구. 실제 로그인 폼·오류·계정 흐름 유지.
- 내 집: 내 정보 책상, 기록장, 수집장, 방 꾸미기로 연결하는 가구.
- 학교: 여섯 출입구를 실제 교실·퀴즈 분류와 연결하는 새 로비.
- 상점: 진열대와 거울에서 실제 코디 상점·옷장 열기. 기존 구매 확인과 재화 검증 유지.
- 이벤트 광장: 퀘스트 게시판과 보상 기능. **오늘의 퀘스트 유지**, 오늘의 퀴즈·시즌 이벤트 입구 없음.
- 랭킹 광장: 기록 게시판과 트로피에서 실제 순위·명예 기록 열기. 랭킹전 단일화에 맞춰 중립적인 입구 문구 사용.
- 모든 기능은 키보드·터치로 접근 가능. 이동 애니메이션 생략 설정 존중. 작은 화면에서 전체 페이지 가로 넘침 금지.
- 관리자, 교실 내부 업무, 독립 게임, Functions/Rules, 운영 데이터, 재화·랭킹 하드리셋은 범위 밖. 랭킹 모드 데이터 변경은 별도 작업.
