전체 고유 상품은 751 → 1,762종, 남녀 표시 행은 2,926개다. 신규 1,016종을 추가하고 투명 변형 5종을 제외했다. 마스터 라벨 91종·스페셜 라벨 186종을 우선 노출하며 같은 우선순위 안에서는 최근 30일 사용량 순이다. 기수 설명은 화면에 표시하지 않는다.

상의·하의는 기존 원본 카탈로그와 9월 29일 수집한 최근 30일 순위 자료 양쪽에서 cash=true로 확인되는 후보 전체를 선정했다. 기타 의상은 남녀별 인기 목록을 확대하고 기존 검증 상품을 유지했다. 따라서 게임 내 모든 캐시 상품을 수집했다는 의미는 아니다. 기존 비캐시·마이스터 심볼·검토된 이벤트 보상·방패 제외 규칙을 유지한다. 모든 캐시 상품의 획득 경로 전수 검토는 여전히 별도 범위다.

검증된 공개 원본: [사용량 분석](https://meaegi.com/analysis/coordi), [마스터 라벨](https://meaegi.com/labels/master), [스페셜 라벨](https://meaegi.com/labels/special). 부위별 조회 URL은 verified-top50.json의 catalogReview.expansion.rankingSources에 보존했다.

## 어비스 헤어

첨부 화면은 로컬 서버가 실행되지 않아 로컬 썸네일과 공식 렌더 요청이 실패한 상태였다. 서버 복구 후 어비스 헤어 67680의 썸네일·공식 착용 이미지를 실제 화면에서 확인했다.

이전 실패 처리는 GMS 255 보조 렌더로 전환해 최신 KMS 헤어가 빠진 모습을 표시했다. 이를 제거하고 실패 안내 및 재시도 버튼을 추가했다. 이미지가 없을 때 다른 코디를 정상 미리보기처럼 보여주지 않는다. 로컬 확인 서버는 http://127.0.0.1:5381/ 이며 테스트 지갑만 메모리에 저장한다. 공개 이미지 서비스 연결은 필요하다.

## 검증

- 신규 남녀별 착용 이미지 1,747개에 대해 공식 렌더 응답·PNG 형식·파일 크기 확인, 서로 다른 해시 1,747개. 대표 24개 이미지 육안 확인.
- 전체 1,762개 상품의 성별, 가격, 표시 순서, 제외 정책, 이미지 파일과 구매 카탈로그 일치 검사 통과.
- `npm run test:growth`, `npm run check:static`, `node scripts/smoke/coordi-commerce-browser.js` 통과.
- 브라우저 검사: 남녀 모든 부위 목록, 투명 8종, 어비스 렌더 실패 시 잘못된 대체 이미지 차단, 재시도, 구매·장착·보유 필터·염색·복원.
- 실제 로컬 화면에서 어비스 헤어와 추가 상의 착용 확인.

재생성 도구: scripts/maintenance/expand-coordi-catalog.js. `--ranking FILE --labels FILE`은 계획만 출력하고, `--write --cache DIR`을 추가하면 공개 이미지 검증 후 로컬 파일을 반영한다. 운영 Firebase 연결은 없다.
