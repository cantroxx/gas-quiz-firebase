# 인기 퀴즈 전면 재구성 · 2026-10-18

최신 사용자 지시대로 인기 퀴즈의 **연습전은 기존 공통 XP·코인 지급 규칙을 따른다.** 이전 보상 미지급 제안은 폐기했다. 구현과 검증 후 사용자 배포 지시에 따라 2026-10-18 운영에 반영했다. 기존 학생 데이터 직접 수정, 보안 규칙 변경, 커밋·푸시는 하지 않았다. 배포 내역은 [운영 배포 보고서](../operations/POPULAR_QUIZ_DEPLOY_2026-10-18.md)를 따른다. 작업 시작 전부터 존재하던 다른 기능의 수정은 유지했다.

최신 직접 진입·20문제 완료 보상과 배포 결과는 [후속 변경 보고서](../operations/POPULAR_QUIZ_COMPLETION_REWARD_2026-10-18.md)를 함께 참고한다.

## 게임 구성

| 분야 | 자료 | 연습전 | 랭킹전 |
|---|---|---|---|
| 국기 | 기존 `quizQuestions/flag-country/questions` | 전체 통합 | 전체 통합 |
| 아이돌 | 공식 출처의 개인 210명 + 그룹 15팀 | 개인 15문제 + 그룹 5문제 | 같은 구성 |
| 애니 | 31개 작품의 캐릭터 326개 | 작품 선택 없이 통합 | 같은 구성 |
| 티니핑 | 기존 `quizQuestions/tiniping/questions` | 전체 통합 | 전체 통합 |
| 포켓몬 | 기존 `quizQuestions/pokemon-gen1..9/questions` | 세대 하나 선택 | 서로 다른 세대 3개 이상 선택 |

- 한 판 20문제, 4지선다. 문제·세션·일일 이용 시간 제한 없음. 연습전은 오답을 대기 목록 뒤에 넣어 다시 출제하며 서로 다른 20문제를 모두 해결해야 완료한다. 랭킹전은 하트 3개를 사용한다.
- 랭킹전은 정답 수 우선, 동점이면 풀이 시간으로 비교한다. 시간은 동점 정렬에만 쓰며 자동 종료하지 않는다. 중도 종료한 판은 랭킹에 올리지 않는다.
- 포켓몬은 선택한 세대를 고르게 출제한다. 세대별 문항 수 차이는 최대 1이며 선택한 세대의 자료가 없거나 부족하면 시작하지 않는다. 랭킹 화면은 같은 세대 조합끼리 비교한다.
- 애니 수량은 작품 326편이 아닌 **캐릭터 326개**다. 확인한 작품·버전의 한국 등급 전체/7세/12세/15세만 허용하고 19세·청불·등급 미확인은 제외한다. 작품당 한 판 최대 2문제다.
- 아이돌·애니의 학생용 그룹/작품 필터는 없다. 선정 검토 화면의 필터는 자료 검토용이다.
- 완료 전에 그만두면 보상을 지급하지 않는다. 기존 문제별 보상 규칙으로 시작한 미완료 연습판은 다음 접근 때 종료 안내를 보여 주고 새 판으로 시작하며, 이미 지급된 보상은 보존한다.
- 새로고침 후 이어 풀기, 저장 응답 유실 시 재시도, 사진 로딩 실패 시 답안 잠금과 재시도를 지원한다.

## 공통 연습 보상

`functions/index.js`의 기존 `grantPracticeRewardInTransaction`을 서버에서 정답 확인 후 호출한다. 기존 정책 상수를 응답으로 전달하므로 안내 화면도 같은 값을 사용한다.

- 최신 후속 지시에 따라 **연습 20문제 모두 해결한 완료당 XP 2, 코인 1을 한 번 지급**한다. 문제별 보상은 없다. 다른 연습전과 **하루 XP 20·코인 50 한도를 공유**한다. 남은 XP 한도가 1이면 1만 지급한다.
- 기존 지급 활성화 설정, 주간 XP 한도, 레벨 처리와 보상 로그를 그대로 따른다.
- 마지막 정답으로 20개를 모두 해결하는 진행과 완료 보상 지급을 같은 Firestore 트랜잭션에서 처리한다. 중복 요청·동시 제출·응답 유실 후 재시도로 추가 지급되지 않는다.
- 랭킹전에는 연습전 정답 보상을 지급하지 않는다. 별도의 인기 퀴즈 포인트 경제를 추가하지 않았다.

## 연결과 저장

- 새 게임: `public/popular-quiz/`. 학교의 인기 퀴즈 입구와 학교 내부 인기 퀴즈 탭에서 중간 목록 없이 같은 탭으로 이 화면을 바로 연다. 돌아가기는 학교 화면으로 연결한다. 오래된 포켓몬 세대 링크도 새 선택 화면으로 연결한다.
- 서버: `functions/popular-quiz/`, callable `popularQuizAction`. 출제·채점·보상·랭킹을 서버가 처리하며 다음 문제의 정답을 클라이언트에 공개하지 않는다.
- 진행 상태: `popularQuizPlayers`, `popularQuizRuns`, `popularQuizProgress`. 기존 규칙의 기본 거부에 따라 클라이언트 직접 읽기·쓰기를 막고 인증된 callable만 사용한다.
- 랭킹: 기존 `rankingRecords`, `userRankingSummary`, `quizKingSummary`를 유지한다. 새 `popular-v2-*` 분류와 서버 기록 식별자를 사용한다. 기존 기록을 삭제하지 않으며 새 화면에서 과거 난이도·시간 제한 기록과 혼합하지 않는다. 포켓몬 세대 조합을 바꿔도 종합 요약에서는 포켓몬 한 분야의 최고 기록만 반영한다.
- 기존 `getRankingModeOptionsForQuiz`, `getSupportedRankingModeForQuiz`, `getRankingTargetForQuiz`와 저장·조회 경로를 확인했다. 새 게임 진입은 일반 모드만 제공하고, 새 서버의 `domain.target`이 실제 새 기록 분류를 결정한다. 기존 게임용 처리와 데이터는 보존한다.
- 기존 인기 퀴즈 일일 이용 제한은 새 진입/플레이 경로에서 사용하지 않는다. 기존 이용 기록을 삭제하거나 초기화하지 않는다.

## 이미지와 갱신

- 선정 정본: [이미지 선정 보고서](popular-image-selection-2026-10-18/README.md), 같은 폴더 `selection.json`.
- 아이돌·애니 551개 원본을 해시 이름으로 `public/popular-quiz/assets/`에 준비했다. 다운로드 원본과 SHA-256이 일치하며 이미지를 변형하지 않았다. 전체 약 385 MB이며 한 번에 현재 문제의 사진만 요청한다.
- `scripts/build-popular-quiz.js --check`가 이미지 해시와 서버 카탈로그 일치를 검사한다. 새 팩은 선정 메타데이터와 검증된 원본을 갱신한 뒤 이 빌드 스크립트로 생성한다.
- 월별 `auditPopularQuizSources` 예약 함수 코드를 추가했다. 배포 시 매월 1일 04:00 한국 시간에 기존 공식 이미지·소개 페이지를 확인하고 `popularQuizSourceAudits/latest`와 날짜 문서에 결과를 남긴다. 2026-10-18 배포 후 예약 작업의 활성화 상태와 시간대를 확인했다.
- 이미지 해시 변경·접속 실패·소개 페이지 변경은 검토 후보로만 기록한다. 신인이나 새 캐릭터를 자동 선정하는 검색기는 아니며, 새 사진·이름·등급을 무검토로 교체하지 않는다. 검토 후 선정 정본과 팩을 갱신한다. 실패해도 현재 게임 이미지는 유지된다.
- 출처 기록과 공개 서비스 이용 권한 확인은 별개다. 선정 기록의 이용 권한 검토 상태는 그대로 유지했다.

## 검증과 확인 범위

- `npm run check`: 전체 프로젝트 검사 통과. 기존 과목퀴즈의 2,502개 화면 검사와 재접속 검사도 통과했다.
- `npm run check:static`: 마지막 보완 후 정적 검사 및 앱 번들 재생성.
- `npm run test:popular`: 551개 원본 해시, 카탈로그 일치, 인물/그룹 비율, 애니 분산, 포켓몬 균등 출제, 보기 중복, 요약 보존, 출처 변경 후보 처리.
- `npm run check:popular-online`: 실제 공통 지급 함수와 에뮬레이터를 사용해 한도 공유, 한도 경계, 동시 제출·중복 요청, 보상 실패 롤백, 계정 격리, 장시간 이어 풀기, 랭킹 저장·조합 분리, 기본 거부 규칙 검증. 실제 callable에 연결한 브라우저로 사진 오류, 응답 유실, 보상 안내, 모바일과 데스크톱을 검증했다.
- `scripts/smoke/school-hubs-browser.js`: 인기 퀴즈 5개 카드, 10개 연습/랭킹 링크, 이전 시간 제한 패널 제거와 진입 동작 확인.
- 마지막 보완으로 선택한 포켓몬 세대의 자료가 완전히 빈 경우도 시작을 거부하도록 하고 서버 검증에 추가했다.
- 배포 단계에서 Firebase CLI의 인증된 읽기 전용 경로로 운영 문제 1,425개를 확인했다. 국기 249개, 티니핑 151개, 포켓몬 1~9세대 1,025개이며 각 분야의 실제 자료로 20문제·서로 다른 보기 출제가 가능했다. 이미지 표본 22개는 모두 HTTP 200 및 이미지 형식으로 응답했다. 학생 계정으로 정답 제출·보상 지급을 발생시키는 운영 테스트는 하지 않았다.
