## 확정 방향

- 로그인부터 타운, 학교, 내 집, 상점, 이벤트 광장, 랭킹 광장과 공통 보조 메뉴를 점검한다.
- 현재의 따뜻한 그림책 화풍을 유지하고 생성 이미지를 실제 UI에 적용한다.
- 랭킹은 이후 `랭킹전` 단일 모드가 된다. 모드별 신규 그래픽·설명을 추가하지 않는다.
- 시즌 이벤트와 오늘의 퀴즈는 제거 예정이다. 새 학생 UI에서 홍보·진입을 제거한다.
- **오늘의 퀘스트는 유지한다.** 사용자 2026-10-18 명시 답변.
- DJ코인 등 재화와 랭킹 하드리셋은 오늘 별도 진행될 작업이다. 이번 작업은 UI 개편이며 운영 데이터 초기화를 실행하지 않는다.
- 이미지에 버튼 글자·학생 이름·잔액·순위를 구워 넣지 않는다. 실제 HTML 컨트롤과 데이터를 유지한다.
- 모바일에서 그래픽 때문에 핵심 기능이 가려지거나 페이지 전체가 가로로 넘치지 않게 한다.

## 범위와 변경 통제

- 기존 작업 트리에 다수의 미커밋 변경이 있다. 시작 상태를 보존하고 이번 변경만 구분해 기록한다.
- 별도 진행될 랭킹·재화 데이터 변경과 충돌하지 않도록 Functions, Rules, 컬렉션, 지급·구매·순위 계산 정책은 변경하지 않는다.
- 랭킹 단일화가 아직 구현되지 않은 경우, 스타일만 바꾸고 기존 모드 데이터를 단일 순위인 것처럼 합치거나 표시하지 않는다. 통합 의존성을 최종 기록한다.
- 시즌 이벤트 기능의 서버 삭제와 과거 데이터 삭제는 별도 작업이다. 이번 UI에서는 노출을 제외하되 다른 작업이 사용할 내부 계약을 임의로 삭제하지 않는다.
- 운영 배포·Git commit·push는 이번 요청 범위에 포함하지 않는다.
- 독립 게임 전체를 재디자인하지 않는다. 타운 내부 진입·주요 탭·보조 메뉴를 점검하고 기존 게임과 교실의 별도 최근 작업은 보존한다.

- `public/index.html`, 전용 CSS, home/event/ranking 렌더러, 코디 iframe, player-status-shortcut를 확인했다. 보조 메뉴가 상태 버튼의 Shadow DOM slot으로 이동하면서 지도 하단과 겹치는 구조다.
- 오늘의 퀴즈는 내 집 카드·알림판·드롭 알림·이용안내에 노출된다. 관리자 설정과 보상 로직은 별도 기능 제거 작업에 맡긴다.
- 수정 경계: 새 전용 UI CSS, app shell의 표시 문구/구조, 공통 상태 바로가기의 타운 내 배치, 내 집의 오늘 퀴즈 표시, 코디 내부 CSS 연결.
- 기존 검증: public-shell fixture, plaza-storybook, home-loading, player-status, school-hubs, coordi commerce/starter. 시즌 이벤트 클릭 검증은 제거된 UI 계약을 가정하므로 새 UI smoke에서 유지되는 퀘스트 동작을 검증한다.
