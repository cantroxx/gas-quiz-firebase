# 인기 퀴즈 이미지 선정 v2 · 2026-10-18

아이돌 개인 210명과 그룹 15팀, 애니 31개 작품의 캐릭터 326개를 선정했다. 총 551개 문항이다. 이미지 선정과 검토 미리보기의 정본이다. 후속 작업에서 로컬 연습전·랭킹전 구현에 연결했다. 2026-10-18 사용자 지시로 운영 배포했다. 현재 게임 규칙과 검증 결과는 [전면 재구성 보고서](../POPULAR_QUIZ_REBUILD_2026-10-18.md)를 따른다.

## 확인 방법

- `review.html`을 브라우저에서 열면 이름/그룹/작품 검색, 출처 확인, 20문제 미리보기를 사용할 수 있다.
- 같은 폴더의 CSS, JS, `v2-*.png`를 함께 유지해야 한다. 미리보기는 외부 이미지 요청 없이 동작한다.
- `selection.json`이 선정 메타데이터 정본이다. 원본 URL, 출처, 별칭, 다운로드 검증 해시, 이미지 검토 상태와 애니 등급 근거를 기록했다.
- `preview-index.json`은 검토용 이미지 모음에서 사진 영역만 표시하기 위한 좌표다. 정답 이름이 적힌 카드 하단은 퀴즈에 표시하지 않는다.
- `selected-*.png`는 이전 v1 검토 기록이고, `v2-*.png`가 이번 최종 선정 모음이다.

## 반영한 기준

- 아이돌 개인 200~300명 범위를 충족하며, 그룹 문항 15개는 개인 수에 포함하지 않는다. 개인 사진 문항은 그룹 멤버도 포함한다.
- 아이돌 한 판: 개인 15문제 + 그룹 5문제, 순서 섞기. 애니 한 판: 20문제, 작품당 최대 2문제. 현재 31개 작품이 있어 미리보기는 우선 서로 다른 20개 작품에서 한 문제씩 고른다.
- 개인·그룹/작품별 세부 선택 없이 통합 출제한다. 검토 목록의 필터는 관리자 검토 편의를 위한 기능이다.
- 애니는 작품 수가 아니라 캐릭터 수를 300~400개로 맞췄다. 한국 등급 근거가 확인된 전체·7세·12세·15세를 허용하고 19세·청불·미확인은 제외한다. 등급은 확인한 영화/TV 버전에만 적용한다.
- 아이돌·애니는 Drive에서 가져오지 않았다. 공식 소속사/아티스트/제작사 캐릭터 소개 및 스틸 이미지를 기준으로 선정했다.
- 티니핑과 포켓몬 자료는 유지한다. 포켓몬 세대별 연습, 랭킹전 3개 이상 세대 선택 및 균등 출제, 시간 제한 없음 규칙을 반영했다. 최신 사용자 지시에 따라 실제 연습전은 공통 XP·코인 지급 규칙을 따른다. 이전 미지급 제안은 폐기했다. 이번 미리보기는 아이돌·애니만 포함한다.

## 제외 및 운영 연결 전 남은 일

- 보류 63개와 다운로드/크기 검증 실패 1개는 출제하지 않는다. 이미지 내부 정답 노출, 다른 인물 중심 사진, 대상 식별 어려움 등이 보류 사유이며 개별 기록은 JSON에 남겼다.
- 모든 선정 원본의 다운로드와 이미지 디코딩, SHA-256 일치를 확인했고 이미지 모음으로 시각 검토했다. 공개 서비스 내 이미지 이용 권한은 별도 확인 대상이다.
- 원피스 원본은 공식 페이지 Referer로 다운로드를 검증했다. 외부 직접 표시가 차단될 수 있으므로 로컬 게임은 SHA-256을 확인한 원본을 같은 사이트의 `/popular-quiz/assets/`에서 제공하도록 구현했다. 검토용 미리보기는 로컬 모음으로 표시한다.
- 국내 정답 이름과 별칭은 출처 인물명에 수동 대응했다. 더빙명/번역명 추가는 행별 별칭으로 확장할 수 있다. 공식 프로필에서 확인한 멤버만 선정했으므로 그룹의 전체 역대 구성원 수를 뜻하지 않는다.
- 나의 히어로 아카데미아: 유어 넥스트의 국내 12세 등급 근거는 Koreafilm 영화 소개의 검색 색인 개봉 정보다. 그 외 등급 출처는 각 행에 기록했다.
- 월 1회 기존 공식 이미지·소개 페이지의 변경을 확인하는 예약 함수 코드를 추가했다. 2026-10-18 배포하여 월별 예약을 활성화했다. 첫 예약 실행은 아직 도래하지 않았다. 변경은 검토 후보로만 기록하며 신규 인물 자동 선정이나 무검토 이미지 교체는 하지 않는다. 새 이미지·이름·등급은 재검토 후 반영하고 수집 실패 시 기존 팩을 유지한다.
- 후속 로컬 구현에서 게임 진입, 연습전/랭킹전 저장, 시간 제한 제거와 공통 보상 연동을 완료했다. 이미지 호스팅과 게임을 2026-10-18 운영에 배포했다. 기존 학생 데이터는 직접 변경하지 않았다.

## 검증

- `python3 scripts/audit/check-popular-image-selection.py`: 수량, 필수 메타데이터, 중복 이미지, 출처, 허용 등급, 출제 규칙 통과.
- `python3 scripts/audit/build-popular-image-review.py`: 선정 JSON과 미리보기 좌표로 `review-data.js` 재생성.
- `node --check docs/product/popular-image-selection-2026-10-18/review.js`: 문법 검사 통과.
- 브라우저 검증: 개인/그룹 필터와 검색, 아이돌 15+5 구성, 애니 작품 분산, 20문제 중복 없음, 정답·오답 처리, 결과 집계, 외부 요청 없는 동작, 390px 모바일 가로 넘침 없음.
- 551개 원본 파일과 선정 SHA-256 전수 일치. 후속 구현에서 전체 앱 검증과 인기 퀴즈 전용 에뮬레이터·브라우저 검증을 수행했다. 운영 배포 및 공개 파일 검증은 후속 배포 보고서에 기록한다.
