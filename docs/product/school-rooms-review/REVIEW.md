# 학교 내부 화면 개편 — 검토 및 배포

2026-09-17. 로컬 수정과 검증 결과를 먼저 보고한 뒤, 사용자의 “배포해봐” 승인에 따라 운영 Hosting에 배포했다.

## 화면과 동선

| 공간 | 변경 |
| --- | --- |
| 과목 퀴즈 | 국어·수학·사회·과학 탭, 카드에서 연습 바로 시작, 지원하는 랭킹 모드만 펼쳐 선택 |
| 학습 퀴즈 | 활동 설명과 새 탭 안내를 갖춘 체험 카드, 최근 열어본 활동, 목록 새로고침 |
| 인기 퀴즈 | 전체·캐릭터·그림/이모지·상식/말놀이 분류, 기존 이용 시간 및 접근 제한 유지 |
| 컨셉 퀴즈 | 관리자 설정의 주제 제목과 해당 활동 카드, 미등록·빈 목록 안내 |
| 게임 아지트 | 여섯 게임 카드, 혼자/함께 분류, 이용 인원과 지원하는 아지트 랭킹 표시 |

다섯 공간 모두 학교 내부의 전용 화면으로 열리며 공통 공간 메뉴와 학교 복귀 버튼을 갖는다. 기존 팝업 방식은 현재 앱에서 사용하지 않는다. 국어·과학 등은 초록, 학습은 청록, 인기는 황갈색, 컨셉은 보라, 아지트는 파랑으로 구분했다. 별도 대형 이미지 다운로드 없이 CSS 장식과 기존 아이콘을 사용했다.

독서·이모지·포켓몬은 작품/종류/난이도를 고르는 기존 선택 화면을 유지한다. 일반 문제는 기존 퀴즈 실행 함수를 호출하므로 접근 검사·랭킹 모드·저장·보상 계산은 기존 경로를 따른다.

외부 활동과 게임은 새 탭으로 열며 원래 목록 탭이 남는다. 새 탭임을 버튼과 안내에 표시한다. 최근 활동은 해당 회원이 현재 페이지에서 직접 연 항목만 기록하며 새로고침 시 지워지는 메모리 상태다. 진행도나 이어하기 상태를 새로 만들지 않는다. 분류와 목록 스크롤은 공간 재진입 시 복원한다.

기존 `/battle/` 직접 주소는 호환을 위해 유지했다. 학교의 게임 아지트 문은 새 공통 화면을 사용한다.

## 검토 화면

실제 구현을 로컬 브라우저에서 촬영했다. 과목·게임은 저장소의 목록을 사용했다. **학습·컨셉 활동과 인기 이용 시간은 검증용 예시 데이터**이며 운영 설정을 바꾸지 않았다. 운영에서는 기존 관리자 등록 목록과 이용 시간을 사용한다.

## 구현 위치

- `public/js/school-rooms.js`: 공간 화면, 과목/인기/게임 분류, 활동 링크, 최근 활동, 설정 캐시·재시도.
- `public/school-rooms.css`: 공통 카드와 공간별 색상, 데스크톱/모바일 레이아웃.
- `public/index.html`: 전용 뷰 등록, 기존 화면 이동·전체 새로고침 연결, 리소스 버전.
- `public/js/features/quiz-render.js`, `public/js/battle-hub.js`: 학교 입구 연결.
- `scripts/smoke/school-hubs-browser.js`: 기존 설정 변환 검사와 새 공간의 브라우저 검사·캡처.

## 확인

전용 브라우저 검사 통과: 다섯 공간, 키보드 입장, 과목 전환, 연습/랭킹 바로 시작, 지원 모드, 랭킹 비활성화, 인기 접근 차단, 외부 링크의 비활성/URL 필터, 설정 캐시, 실패 재시도, 컨셉 미설정, 게임 분류, 회원별 최근 활동 분리, 관리자 설정 왕복, 휴대폰 가로 넘침.

전체 `npm run check`도 독립 포트 복사본에서 통과했다. 최초 시도는 복사본의 분수 레거시 fixture 누락으로 중단됐고, 해당 fixture를 복사한 뒤 전체 검사를 다시 통과했다. 공개 화면 검사는 현재 운영 로그인 화면을, 전용 브라우저 검사는 새 로컬 학교 화면을 대상으로 했다.

이 작업은 학생 데이터·Functions·보안 규칙·보상 정책을 변경하지 않는다. 다른 작업의 변경이 함께 있는 작업 폴더이므로 실제 배포 시 최신 운영본을 기준으로 이 화면 관련 변경만 분리해야 한다.

## 배포 결과 (2026-09-17)

- Hosting 버전: `8790d503d60f75ba`, 릴리스: `1789613544479000`.
- 직전 운영 버전 `6a11d31c1a8602f8`을 복제해 화면 관련 6개 파일만 반영했고, 나머지 400개 파일과 Hosting 설정을 보존했다.
- 변경 파일: `index.html`, `js/app.bundle.js`, `js/features/quiz-render.js`, `js/battle-hub.js`, `js/school-rooms.js`, `school-rooms.css`.
- 실제 배포 후보 대상으로 전용 브라우저 검사를 다시 통과했다. 학생 데이터, Functions, 보안 규칙 배포는 수행하지 않았다.
- 배포 후 운영 6개 파일의 SHA-256이 후보와 모두 일치했고, 운영 공개 화면 브라우저 검사도 통과했다. 로그인 후 공간 동작은 배포 후보에서 검증용 데이터로 확인했다.
