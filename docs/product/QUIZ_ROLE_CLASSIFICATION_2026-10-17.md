# 퀴즈 분류와 메뉴 역할 정리

2026-10-17 기준. 학습퀴즈·과목퀴즈·인기퀴즈 개편의 1단계다. 기존 목록과 기록을 유지하면서 각 활동을 어디에 두고 무엇부터 보완할지 정했다. 학생 화면에는 활동 성격을 표시하며, 관리용 유지·보완·보관 판정은 이 문서에서 관리한다.

## 메뉴 역할

| 메뉴 | 역할 | 학생에게 안내할 내용 |
| --- | --- | --- |
| 과목 퀴즈 | 배운 내용을 익히고 관심을 넓히는 연습 교실 | 기초 연습, 어휘 넓히기, 독서, 확장 읽기·탐구, 생활 탐구 |
| 학습 퀴즈 | 직접 해 보는 학습 탐험 | 별도 사이트의 체험 활동. 새 탭에서 열며 입장·저장 안내는 해당 활동에서 확인 |
| 인기 퀴즈 | 좋아하는 주제로 즐기는 동아리방 | 인물·캐릭터 알아보기, 그림 관찰·추리, 말놀이. 기존 이용 시간과 랭킹 방식 유지 |

기존 메뉴 이름은 유지하고 제목 위 보조 이름과 안내를 바꾼다. 메뉴 간 이동, 퀴즈 ID, 순서, 문제, 보상, 랭킹 정책은 바꾸지 않는다. 외부 링크 방문을 학습 완료로 취급하지 않는다.

## 판정 기준

- 유지: 현재 메뉴에서 역할이 분명하다. 정기 문항 검수 대상이며 문항 품질의 보증을 의미하지 않는다.
- 보완: 현재 공개 상태를 유지하되, 아래 명시한 개선을 우선한다.
- 보관 후보: 중복되거나 준비가 완료되지 않아 목록 정리 검토가 필요한 항목이다. 이번에는 숨김·삭제하지 않는다.
- 기존 비노출 유지: 앞선 승인으로 목록에서 제외한 항목을 복원하지 않는다. 파일과 기록은 보존한다.

운영 공개 카탈로그와 `appSettings/externalQuizzes`, `appSettings/featureFlags`를 읽어 목록을 대조했다. 외부 활동은 7개 모두 활성, 분류 값이 없는 기존 항목은 학습으로 처리된다. `disabledQuizIds`는 비어 있다. 문항 전체의 정확성·학년 적합성 및 실제 학습 성과는 이번 판정에 포함하지 않았다.

## 학습 퀴즈의 운영 등록 7개

이름·설명·URL은 현재 등록값을 유지한다. 아래 역할은 등록된 설명과 기존 프로젝트 인벤토리에 따른 편집 분류다. 실제 수업 목표나 소요 시간은 확인 후 추가한다.

| 현재 이름 | 역할 | 판정 | 다음 관리 작업 |
| --- | --- | --- | --- |
| 문화유산 퀴즈 | 문화유산 탐사 | 유지 | 내부 문화유산 이미지 퀴즈와 구분. 독립 계정·기록 안내를 후속 카드 개선에 반영 |
| 외계인 퇴치 퀴즈 | 사칙연산 체험 | 유지 | 기초 계산을 게임으로 연습하는 역할 유지 |
| 탐정 게임 | 추론·문제 해결 | 유지 | 체험형 추리 역할 유지 |
| 올라타자 게임 | 타자 연습 | 보완 | 퀴즈보다 타자 활동임을 다음 카드 개편에서 명확히 표시 |
| 시장에 가면 게임 | 합리적 선택·장보기 | 유지 | 선택과 소비 체험 역할 유지 |
| 인생 게임 | 진로 선택 체험 | 보완 | 활동 소개와 별도 사이트의 저장 방식을 다음 카드 개편에서 명확히 안내 |
| 수학 방탈출 | 수학 문제 해결 | 유지 | 과목 연습과 구분되는 체험형 문제 해결 역할 유지 |

링크 방문 기록만으로 학습 진도, 완료 여부, DJ코인 지급을 만들지 않는다. 각 활동의 기능·접속 상태 검수는 개별 활동 갱신 시 수행한다.

## 기존 비노출과 보존

- 분수 평가: 1단계 당시 유지했으나 후속 사용자 요청으로 수학 목록과 안내에서 제외했다. 독립 페이지·평가 기록은 유지한다.
- 삼각형 건축왕: 현재 과목 목록에 없음. 운영 카탈로그에는 없고 로컬에만 남은 메타데이터가 있어 이번에 공개하지 않는다.
- 우주탐사대: 2026-10-17 앞선 과목 목록 정리 배포로 제외. 메타데이터·독립 게임 파일은 보존하고 목록에 복원하지 않는다.
- `multiplication_division`: 별도 신규 퀴즈가 아니라 `random-basic`으로 정규화되는 호환 ID다. 삭제하거나 새 카드로 추가하지 않는다.

## 이번 화면 반영과 후속 순서

1단계 반영은 세 메뉴의 보조 이름·목적 안내, 과목별 학습 안내, 카드의 활동 성격 표시다. 관리용 판정을 학생 카드에 노출하지 않는다. 이후 사용자 요청으로 분수 평가의 수학 목록 항목과 안내를 제외했다. 문제 수정, 기능 설정 변경, 문항 ID 교체, DJ코인·랭킹·학생 기록 변경은 없다.

다음 2단계는 맞춤법·국기의 공통 풀이 화면과 학습활동 카드 한 개를 시범 개편한다. 시범 결과를 기준으로 확대하고, 짧은 학습 묶음·오답 복습은 별도 단계에서 기록과 보상 영향을 검토한다.

월 1회 추천·노출 순서와 링크를 확인하고, 한두 묶음의 문항을 검수한다. 검수 시 정답·보기·별칭·힌트·해설·이미지 출처·정답 노출을 확인한다. 기존 관리자 품질 검사의 빈 답안·이미지 참조 누락·중복 ID 확인을 재사용한다.
