# 장소 공통 UI·내 상태·프로필·훈장 개편

사용자 요청 1~10을 순차적으로 수행한다. 수정 중인 인기 퀴즈 구현은 이번 작업에서 변경하거나 배포하지 않는다.

- [x] 1. 공통 장소 도구/상태/프로필/뱃지 집계/훈장 소스 및 운영 차이 조사, 초기화 보존 범위 확정
- [x] 2. 장소 안 공통 아이콘, 불필요한 바깥 설명 제거, 돌아가기/로그아웃 확인/닫기 구현
- [x] 3. 내 상태 요약형 그래픽 UI, 긴 내용 접기, 프로필 업로드 전용 UI 구현
- [x] 4. 마을 스타일 훈장 1~100 그래픽/매핑 및 뱃지 현황 개편 (기존 획득 칭호 보존)
- [x] 5. 모바일/키보드/로그아웃 취소·확인/프로필/상태/훈장/보존 검사 및 npm run check
- [x] 6. 최신 운영본 기반 변경 파일만 후보 구성·검증·배포·운영 확인 및 보고

초기화는 대상 저장 경로와 재집계 동작을 먼저 조사한다. 기존 칭호, 재화, 일반 퀴즈 원본·랭킹을 무단 변경하지 않는다. 레벨 1~100 훈장 이미지는 실제 레벨 경제/상한 변경과 구분하여 다룬다.

## 초기화 사용자 확정
기존 획득 타이틀만 `(구)타이틀`로 분류하여 보존. 연습 기록·뱃지 기록은 전체 초기화. 초기화 전 백업, 코인·XP·랭킹·지급 로그 보존. 새 연습 기록 ID 기준으로 과거 중복 보상 키와 분리한다. 최신 인기 퀴즈 코드 자체는 변경하지 않는다.

초기화 실행은 6단계 배포 직후 수행한다. `reset-town-practice.js`는 대상 allowlist/원본 백업/수정시간 전제조건/칭호 필드 보존/재실행 검증을 포함한다. 대상은 내 집 뱃지·연습 집계 3개 경로이며, 새로운 과목 퀴즈의 문제 배정 이력·랭킹이나 인기 퀴즈 구현은 포함하지 않는다.
