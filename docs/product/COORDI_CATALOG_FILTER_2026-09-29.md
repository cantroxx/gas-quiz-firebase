# 코디 상점 추가 필터 적용

2026-09-29. 로컬 적용·검증 완료. 운영 배포, 설정 변경, 학생 데이터 변경 없음.

후속: [전체 목록·라벨 우선순위 점검](COORDI_LABEL_PRIORITY_AUDIT_2026-09-29.md)에서 라벨 상품 9종을 추가하고 최근 30일 착용 통계를 갱신했다. 현재 로컬 판매 상품은 710개이며 아래 701개는 추가 전 필터 결과다.

## 원인과 적용 기준

9월 20일 캐시 전용 필터는 로컬 목록에만 적용되어 있었다. 마지막 운영 배포 기록은 관리자 체험 버전이며, 비캐시 제외 및 거래 기능은 배포되지 않았다. 현재 로컬의 기존 721개 판매 목록에는 마이스터 심볼과 cash=false 상품이 없었지만 캐시로 분류된 이벤트 지급품은 남아 있었다. 이번에는 캐시 여부와 별도로 확인된 지급품을 제외한다. 운영 화면의 현재 목록은 이번 작업에서 직접 재조회하지 않았다.

- `cash === true` 또는 `cash === 1`만 허용한다. 값 누락·문자열 등 분류 미확인 상품도 제외한다.
- 마이스터 심볼은 원본 캐시 분류 오류에도 제외한다. `심볼`이라는 단어 전체를 차단하지 않는다.
- 확인된 이벤트 보상은 정확한 아이템 코드로 제외한다.
- 부족한 파츠를 50개로 맞추기 위해 미검증 상품을 추가하지 않는다.
- 아직 모든 상품의 지급 경로를 조사한 것은 아니다. 미검토 캐시 상품은 유지되므로 남은 701개를 모두 유료 판매 출신 상품으로 보증하지 않는다.

## 추가 제외 결과

| 분류 | 고유 아이템 수 | 해당 상품 |
|---|---:|---|
| 하이퍼버닝 | 3 | 크라운, 로브, 소드 |
| 버닝 BEYOND | 2 | 버닝 플레임 선글라스, 윙즈 |
| 메이린 격파 보상 | 10 | 운명의 인도자 헤어·얼굴·베일·페이스 페인팅·남녀 예복·남녀 구두·케이프, 운명의 아르카나 카드 |
| 츄츄 이벤트 보상 | 5 | 달달 머리띠, 츄츄 카페 소년, 새콤 슬리퍼, 프룻 리프, 츄릅 매듭팔찌 |

고유 판매 상품 **721 → 701개**. 성별 중복 포함 진열 **1,127 → 1,092개**. 기존 가격은 유지한다. 남은 상품의 원본 착용 순위·착용 수·관측 시점은 그대로 두고 화면 순번과 개수만 갱신했다. 최근 30일 착용 수 자료의 기간 자체를 확장하거나 선호도 통계로 보정한 작업은 아니다.

제외된 35개 성별 행은 `verified-top50.json`의 `selectionExcluded`에 원본 필드와 사유를 보관한다. 원본 전체 카탈로그·PNG·기존 보유품은 삭제하지 않았다. 거래 기능은 마지막 배포 기록상 미배포이며, 향후 운영에서 판매 중단품의 기존 보유자가 존재한다면 장착 허용 정책을 별도 확인해야 한다.

## 유지보수와 검증

- 공통 필터: `public/coordi-shop/catalog-filter.js`. 브라우저가 이전 JSON을 받아도 진열 전에 다시 검사한다.
- 로컬 카탈로그 적용: `node scripts/maintenance/filter-coordi-catalog.js --write`. 네트워크·운영 DB 접근 없음. 제외 내역 보관, 화면/서버 목록 및 성별 일치 유지.
- 일치 검사: `node scripts/maintenance/filter-coordi-catalog.js`. 수정 없이 불일치 시 실패한다. 신규 상품에 서버 가격이 없으면 임의 가격을 부여하지 않고 중단한다.
- `npm run check:static` 통과.
- `npm run test:growth`의 기존 서버·미리보기 검사와 신규 카탈로그 검사 통과. 제외 상품을 정상 상품과 섞어 구매 요청해도 차감·프로필 생성 없이 거절함을 확인했다.
- `node scripts/smoke/coordi-commerce-browser.js` 통과. 이전 이벤트·비캐시·잘못된 cash 값이 섞인 응답에서도 진열 제외, 정상 구매·장착·보유 필터·염색·재진입 복원, JS 오류 없음 확인. 합성 응답과 로컬 파일만 사용했다.
- 전체 `npm run check`는 이번 작업에서 실행하지 않았다. 운영 화면 배포 전 전체 검사를 통과해야 한다.

공유 폴더에는 다른 미배포 변경이 많으므로 전체 일괄 배포를 피하고, 이번 필터 파일·상점 HTML/JS·진열 JSON·서버 카탈로그를 함께 비교해야 한다. 상점 공개나 배포는 별도 사용자 지시 후 진행한다.
