# 타닥타닥 구름탑 프로토타입

2026-09-14 · 요청: 큐플레이 올라타자와 비슷한 타자 게임, 랭킹이 있는 챌린지 모드. 후속 요청: 이미지 생성 기반 전체 아트와 테일즈런너처럼 역동적인 도약 애니메이션.

## 실행

저장소 루트에서 `python3 -m http.server 5314 --bind 127.0.0.1 --directory public` 실행 후 <http://127.0.0.1:5314/cloud-tower/> 접속.

진입점은 `public/cloud-tower/index.html`. 오프라인 연습은 별도 빌드·설치·로그인 없이 실행한다. 퀴즈타운의 온라인 대전 목록(`/battle/`)과 구름탑의 게임 목록 복귀 링크를 연결했다. 후속 요청에 따라 공용 랭킹·2~4인 실시간 레이스·내부 랭킹 탭을 구현하고 Firebase Emulator로 검증했다. 사용자 승인 후 2026-09-14 운영에 배포했다: <https://dj48-quiztown-firebase.web.app/cloud-tower/>. DJ코인 지급은 연결하지 않았다. 최신 운영 적용 범위는 [온라인 기능 인계](../operations/CLOUD_TOWER_ONLINE_2026-09-14.md)를 따른다.

## 첫 Hosting 공개·메뉴 연결 준비 이력 (온라인 확장 전)

- 사용자 문의: 온라인 배포와 기존 온라인 대전 목록 추가 가능 여부.
- 로컬 메뉴: `/battle/` 첫 카드에 ‘타닥타닥 구름탑’, ‘타자로 달리고 점프! 하늘섬 120초 챌린지’, ‘혼자 도전 · 기기 내 랭킹’ 표시.
- 기존 낱말 대전·특산물 마블·팔도 특산물 대상인·분수 월드·퀴즈 서바이버 링크는 유지. 목록 소개 문구를 개인 도전도 포함하도록 보완.
- 공개 후 주소: `https://dj48-quiztown-firebase.web.app/cloud-tower/`. 2026-09-14 확인 시 아직 HTTP 404.
- 운영 `/battle/index.html`을 읽기 전용으로 내려받아 대조한 결과 로컬과의 차이는 이번 구름탑 카드·스타일·소개 문구 추가뿐이다.
- 배포 대상은 `public/battle/index.html` 1개와 `public/cloud-tower/` 10개, 총 11개 정적 파일. Firestore·Storage 데이터·Rules·Functions 변경 없음.
- 다른 게임의 미커밋 변경이 있으므로 작업 디렉터리 전체를 그대로 Hosting 배포하지 않는다. 현재 운영 Hosting 버전을 보존하는 별도 배포 준비본에 위 11개 파일만 반영하고 차이를 검증해야 한다.
- 실제 Hosting 게시 승인 전 상태. 온라인 학급 공용 랭킹·실시간 대전 기능은 별도 구현 범위다.
- 메뉴 왕복·기존 링크 5개·390px 메뉴 화면 검증, 구름탑 브라우저 smoke, `npm run check`, `git diff --check` 통과.

## 구현한 플레이

- 챌린지: 3초 준비 → 120초 고정 코스 → 시간 종료 또는 먹구름 추격으로 종료 → 기기 내 최고 기록 자동 저장.
- 자유 연습: 동일 문장을 시간 제한·먹구름 없이 연습. 마치기 버튼으로 결과 확인. 랭킹 미등록.
- 직접 작성한 30개 한국어 단어·문장을 모든 챌린지에 동일한 순서로 제공. 마지막 문장 다음에는 처음으로 순환한다.
- 문장을 띄어쓰기까지 완성하고 Enter 또는 올라가기 버튼으로 제출하면 한 층 이동. 틀린 문장은 수정해서 재제출할 수 있다.
- 입력 오류가 없는 문장을 3연속 완성할 때마다 두 층 이동. 오타 후 수정한 문장은 층 이동은 가능하지만 무오타 연속 횟수를 초기화한다.
- 한 층 100점 + 완성한 문장 글자당 5점(공백 포함) + 무오타 문장 25점. 슈퍼 점프는 두 층이므로 기본 200점.
- 정확도는 한글 조합 완료 후 입력·교체된 글자 중 해당 위치의 정답 글자 비율. 지우기는 추가 입력으로 세지 않으며, 고치기 전 오타는 정확도에 남는다. 한글 자모 타수 측정 지표가 아니다.
- 한글 조합 중 Enter 제출 방지, 입력 중 정오 표시, 붙여넣기·드롭 차단, 선택적 효과음, 반응형 화면, 모션 감소 설정 지원.
- 챌린지 중 탭 전환으로 시간 정지 불가. 먹구름 도착 시간을 역산하여 백그라운드 프레임 지연으로 생존 시간이 늘어나지 않게 처리한다.
- v2 캐릭터·구름·발판·배경은 built-in image_gen으로 만든 래스터 아트를 Canvas에서 합성한다. 프로젝트에 저장한 이미지 3개만 로드하며 외부 폰트·이미지·네트워크 요청 없음.

## v2 이미지 아트·러너 연출

외부 게임의 캐릭터나 에셋을 복제하지 않고 독자적인 하늘 왕국·탐험가 아트를 생성했다. 실시간 3D 모델이 아닌 투명 스프라이트와 카메라 연출을 사용한 2.5D 러너다.

| 아트 | 최종 저장 경로 | 구성 |
| --- | --- | --- |
| 하늘 왕국 | `public/cloud-tower/assets/sky-kingdom-v2.png` | 1536×1024 파노라마 배경 |
| 탐험가 | `public/cloud-tower/assets/runner-atlas-v2.png` | 1536×1024, 4×2 자세 아틀라스, 실제 alpha 투명도 |
| 섬·먹구름 | `public/cloud-tower/assets/islands-atlas-v2.png` | 1536×1024, 2×2 플랫폼·먹구름 아틀라스, 실제 alpha 투명도 |

생성 방식은 **built-in image_gen**. 최종 프롬프트 세트는 [CLOUD_TOWER_ART_V2_PROMPTS.json](CLOUD_TOWER_ART_V2_PROMPTS.json)에 보존했다. 생성 원본은 `.codex/generated_images`에 그대로 두고 프로젝트에 복사했다. 총 원본 PNG 용량은 약 6MB다.

- 준비·달리기·웅크리기·도약·공중 자세·착지·승리 자세를 사용. 일반 점프는 1.13초, 슈퍼 점프는 1.45초의 연출이다.
- 일반 점프 궤적 높이 180 월드 단위, 슈퍼 점프 250. 슈퍼 점프 중 360도 공중 회전, 무지개 궤적, 확대, 속도선. 착지 시 발판 반동·먼지·약한 화면 흔들림·선택적 효과음.
- 문장 완성에 따라 가로 방향의 다음 하늘섬으로 이동. 카메라는 캐릭터를 추적하고 먼 풍경은 느리게 움직인다.
- 0/10/20/30층에서 바람의 초원/황금빛 하늘섬/별빛 구름바다/무지개 정상으로 아트 색감·발판을 전환한다. 새로운 배경 이미지 4개를 사용한 것은 아니며 같은 배경에 분위기와 전경을 변화시킨다.
- 타자 입력 중 달리기 자세·추진력 게이지, 가까워지는 먹구름, 내 최고 높이 깃발, 지역 진행 표시를 추가했다.
- 시작하면 모드·랭킹 패널을 접고 넓은 플레이 화면으로 전환. 전체 화면 버튼과 항상 접근 가능한 중도 종료 버튼을 제공한다.
- 모션 줄임 옵션은 회전·카메라 흔들림·궤적을 끄고 목적지로 즉시 이동한다. OS 모션 감소 선호를 초기값으로 적용한다. 점프 중 옵션을 켜도 목적지 기록과 화면이 어긋나지 않는다.
- 애니메이션은 별도 `motion.js`에서 처리한다. 점수·120초·랭킹 도메인에는 영향을 주지 않는다. 빠른 연속 정답은 도약 순서대로 표시한다.
- 아트 3개 로드가 완료되어야 시작 가능하다. 실패하면 안내하고 게임 타이머를 시작하지 않는다. 종료 시 짧은 실패/승리 연출 후 결과를 표시한다.

## 오프라인 기기 랭킹 범위

- 저장 키: `dj48-cloud-tower-prototype-v1`, 코스 버전: `cloud-120-v1`.
- 동일 브라우저·동일 origin의 localStorage만 사용. 닉네임별 최고 기록 1개, 최대 50명, 화면 상위 5명. 닉네임이 같으면 같은 탐험가로 간주한다.
- 점수 내림차순 → 정확도 내림차순 → 소요 시간 오름차순. 모든 조건이 같으면 기존 기록 유지.
- 챌린지에서 한 문장 이상 완성하고 시간 종료 또는 먹구름에 잡힌 기록만 등록. 연습·중도 포기·0문장·새로고침으로 중단한 게임은 미등록.
- 브라우저 저장이 막힌 경우 현재 페이지 메모리에서 기록을 표시하고 저장되지 않았음을 결과창에서 안내한다.
- 같은 닉네임의 이전 기록보다 낮으면 최고 기록 유지. 다른 탭에서 기록이 바뀌면 storage 이벤트로 갱신.
- 온라인·학급 전체 랭킹이 아니다. 클라이언트 기록은 수정 가능하므로 공식 순위나 코인 지급 근거로 사용할 수 없다. 실데이터와 기존 랭킹을 조회하지 않는다.

## 기존 랭킹 연동 검토

기존 `getRankingModeOptionsForQuiz`, `getSupportedRankingModeForQuiz`, `getRankingTargetForQuiz`와 `rankingRecords`, `userRankingSummary`, `quizKingSummary`의 저장·조회 경로를 확인했다. 현재 퀴즈 정답 수 기반 저장 경로와 타자 점수 체계가 다르므로 기존 카테고리에 프로토타입 기록을 섞지 않았다.

온라인 확장에서 인증 UID 기반 최고 기록, 코스 버전 경계, 서버 시작 시각, 문장 입력 검증, 재제출 방지, 참가자만 볼 수 있는 방, 활성 연결 계정만 읽는 공용 랭킹을 구현했다. 기존 정답 수 기반 `rankingRecords` 대신 별도 공용 기록 컬렉션을 사용하고 `ct-ranking-plaza.js`가 ‘온라인 대전 → 구름탑’ 하위 탭에서 읽는다. 코인·방 장식 보상은 이번 구현 범위에 없다.

## 검증

- `node tests/cloud-tower/domain.test.js`: 점수, 오타 수정, IME 중복 입력 방지, 연속 보너스, 고정 코스, 시간·먹구름 종료, 연습/포기 제외, 최고 기록 유지, 손상·차단 저장소 처리.
- `node tests/cloud-tower/motion.test.js`: 도움닫기/웅크리기/도약/착지 단계, 포물선 높이, 슈퍼 회전, 정확한 목적지 착지, 빠른 연속 정답 큐, 도약 도중 모션 줄임 전환.
- `node scripts/smoke/cloud-tower-browser.js`: 실제 Chrome에서 한글 조합 이벤트, 오답 재시도, 연속 점프, 120초 완주, 먹구름 종료, 다른 닉네임 순위, 새로고침 복원, 재도전, 중도 포기, 무제한 연습, 390/768/1024px 가로 넘침 검사. 외부 요청·pageerror 0건.
- 로비·플레이·결과·모바일 화면 PNG를 `/tmp/cloud-tower-*.png`에 생성해 시각 검토.
- v2 브라우저 smoke는 생성 이미지 로드, 공중 슈퍼 점프 상태, 넓은 플레이 화면, 모바일 플레이, 모션 줄임도 검사한다. 실제 공중 회전 장면과 투명 스프라이트 합성을 캡처해 확인했다.
- 신규 게임 테스트는 위 명령으로 별도 실행한다. 기존 `npm run check`에는 아직 편입하지 않았다.
- 기존 `npm run check` 전체 통과: 정적 검사, 도메인·애플리케이션·인프라·분수월드 테스트, demo 프로젝트 Firestore/Storage Rules 행동 테스트, 운영 공개 로그인 화면 읽기 전용 smoke. `git diff --check`도 통과했다.

기존 분수월드·워드배틀·특산물 마블 관련 미커밋 변경과 `package.json`은 이번 작업에서 수정하지 않았다.
