# Grownd 퀘스트/성장 루틴/젬스톤 실사 분석

## 1. 확인 범위

확인일: 2026-06-23

확인 사이트:

- `https://growndcard.com`

확인 계정:

- 교사 계정으로 로그인 후 교사용 화면 확인
- 학생 계정으로 로그인 후 학생용 화면 확인

확인한 주요 경로:

- 교사 설정 화면
- 교사 그라운드 메인 화면
- 퀘스트 관리
- 퀘스트 생성 모달
- 퀘스트 젬스톤 연결 모달
- 반복 퀘스트 설정 모달
- 성장 루틴 플래너
- 루틴 설정 수정 모달
- 루틴 보상 관리 모달
- 루틴 템플릿 관리 모달
- 학생 메인 화면
- 학생 퀘스트 모달
- 학생 성장 루틴 모달
- 학생 루틴 생성 모달
- 학생 젬스톤 전시 화면

- 이 문서는 Grownd의 실제 UI/기능 흐름을 DJ48 교실 기능 개선 참고자료로 정리한 것이다.

## 2. 전체 구조 요약

Grownd는 기능을 단순히 보상 시스템으로 붙이지 않고, `사회정서 성장 + 학급 경제 + 활동 기록`으로 묶어 설계한다.

주요 축:

- 학생 개인 카드
- 퀘스트
- 성장 루틴
- 젬스톤
- 학급 화폐/은행
- 마켓
- 직업
- 학급 미션
- 관찰 기록
- 리더보드/리포트

DJ48에 참고할 핵심은 다음이다.

- 학생 화면은 `오늘 할 일`과 `내 상태`를 먼저 보여준다.
- 교사 화면은 `학생 카드`와 `처리할 일`을 중심으로 빠르게 관리하게 한다.
- 퀘스트, 루틴, 젬스톤은 서로 연결되지만 학생에게는 복잡한 설정을 보여주지 않는다.
- 교사가 설계하고 학생이 수행하며, 최종 보상/취소/검토 권한은 교사에게 둔다.

## 3. 교사 메인 화면

교사 로그인 후 그라운드 메인 화면은 학생 카드 그리드 중심이다.

학생 카드에서 보이는 정보:

- 학생 번호
- 닉네임
- 레벨
- 보유 베리
- 보유 포인트
- 감정/활동 표시
- 히어로 뱃지 진입 버튼

우측 또는 하단 도구:

- 클래스 알림
- 배경 테마
- 교실 배치도
- 퀘스트 관리
- 학급 미션
- 관찰 기록
- 아뜰리에
- 아케이드

DJ48 반영 포인트:

- 교사 첫 화면은 설정 목록보다 학생 카드와 오늘 처리할 일을 우선해야 한다.
- 학생 카드에는 레벨/타이틀/포인트 줄 정렬이 중요하다.
- 테스트 학생은 카드와 최근 활동에서 제외하되, 교사 기능 자체는 볼 수 있어야 한다.

## 4. 퀘스트 관리

퀘스트 관리 화면은 교사용 운영 화면이다.

상단 요약:

- 퀘스트 생성 한도
- 반복 퀘스트 한도
- 전체 퀘스트 수
- 노출중 퀘스트 수
- 저장 용량 사용량

관리 기능:

- 카테고리 필터
- 카테고리 관리
- 검색
- 정렬
- 노출중만 보기
- 선택
- 아카이브
- 도구함
- 퀘스트 추가

퀘스트 카드 정보:

- 반복 여부
- 카테고리
- 기간 만료 여부
- 보상 포인트
- 완료 인원 수
- 제목
- 설명
- 기간
- 노출 ON/OFF

DJ48 반영 포인트:

- 퀘스트 목록은 단순 테이블보다 카드형 요약이 교사에게 빠르다.
- 퀘스트에는 `노출`, `기간`, `대상 학생`, `카테고리`, `완료 현황`이 기본값으로 필요하다.
- 완료 후 취소 또는 해제 기능은 교사 작업대에서 바로 가능해야 한다.

## 5. 퀘스트 생성 UI

퀘스트 생성 모달의 주요 입력:

- 퀘스트 제목
- 설명
- 학생 노출 여부
- 노출 기간
- 타임어택
- 카테고리
- 유형
- 포인트
- 적용 학생
- 젬스톤
- 반복 설정

적용 학생 선택:

- 학생 목록이 체크박스로 표시된다.
- 전체 학생이 기본 선택된다.
- 전체 해제 후 필요한 학생만 고를 수 있다.

DJ48 반영 포인트:

- 대상 학생을 직접 번호로 입력하는 방식은 폐기하는 편이 낫다.
- 학생 아이콘/닉네임/번호가 보이는 체크 리스트가 필요하다.
- 고급 설정은 항상 펼쳐두기보다 `젬스톤`, `반복 설정`처럼 별도 버튼으로 분리하면 화면 피로도가 줄어든다.

## 6. 퀘스트와 젬스톤 연결

퀘스트 생성 중 `젬스톤` 버튼을 누르면 연결 모달이 열린다.

모달 설명:

- 이 퀘스트 완료 시 선택한 젬스톤의 경험치가 `+1` 된다.

선택 방식:

- 연결 안함
- 독서젬
- 빛나는 독서젬
- 찬란한 독서젬
- 플래너젬
- 맛있는젬
- 백점젬
- 타자젬
- 고수 타자젬
- 빛나는 플래너젬

각 젬스톤은 `달성 조건: N회` 형태로 표시된다.

중요한 설계 특징:

- 젬스톤은 임의 XP 수치를 퀘스트마다 다르게 주는 구조가 아니다.
- 퀘스트 1회 완료가 젬 진행도 1회로 누적된다.
- 상위 젬은 같은 젬의 레벨 값이 아니라 별도 젬 이름으로 분리된다.

DJ48 반영 포인트:

- 현재처럼 `gemXp`, `gemTargetXp`, `gemRewardPoint`를 매번 입력하는 방식은 교사에게 복잡하다.
- 권장 구조는 `젬 선택 -> 퀘스트 완료 시 +1 -> 목표 횟수 달성 시 획득`이다.
- 젬스톤은 보상 포인트와 분리하고, 성취 전시/뱃지 성격을 강화하는 편이 좋다.

## 7. 반복 퀘스트

반복 퀘스트 설정 모달의 핵심 문구:

- 매일 자정에 서버에서 자동으로 퀘스트를 복제 생성

설계 특징:

- 하나의 정적 퀘스트에 매일 완료 상태를 덧붙이는 방식이 아니다.
- 날짜별 퀘스트가 서버에서 복제 생성되는 구조다.
- 반복 퀘스트 한도도 별도로 관리된다.

DJ48 반영 포인트:

- 일일 퀘스트는 날짜별 기록 분리가 명확해야 한다.
- 반복 퀘스트는 `오늘 완료했는가`와 `어제 완료 기록`이 섞이지 않게 설계해야 한다.
- 서버에서 날짜별 인스턴스를 만들거나, 적어도 저장 키를 날짜 단위로 분리해야 한다.

## 8. 성장 루틴 교사 화면

성장 루틴 플래너 상단 요약:

- 학생 수
- 생성 수
- 진행중 수
- 검토 수
- 완료 수

학생 목록:

- 번호와 닉네임을 가진 학생 카드형 버튼
- TODAY 표시
- 페이지 이동

선택 학생 루틴 영역:

- 진행중
- 마감 검토
- 처리 완료

루틴 카드 정보:

- 루틴 이름
- 루틴 방식
- 항목 수
- 기준 보상
- 시작일
- 종료일
- 진행현황
- 설정
- 오늘의 달성률
- 루틴 항목 목록

중요한 문구:

- 일일형은 하루 완료분을 지급한다.
- 목표형은 종료 후 실제 달성률을 검토해 최종 보상을 처리한다.

DJ48 반영 포인트:

- 성장 루틴은 학생이 체크할 때마다 즉시 포인트를 주면 안 된다.
- 루틴은 `학생 체크 -> 교사 검토 -> 보상 지급` 흐름이 맞다.
- 진행중/검토/완료 탭을 분리해야 교사 작업대가 정리된다.

## 9. 성장 루틴 설정

루틴 설정 수정 모달의 주요 입력:

- 루틴 방식
- 루틴 꾸러미 이름
- 기준 보상
- 루틴 시작일
- 목표 종료일
- 반복 요일 설정
- 성장 루틴 항목

루틴 방식:

- 일일 지급 루틴
- 목표일 달성 루틴

일일 지급 루틴 설명:

- 종료일 없이 반복된다.
- 하루를 모두 완료하면 교사가 일 보상을 지급한다.

목표일 달성 루틴 설명:

- 종료일까지 실천한다.
- 교사가 전체 달성률을 검토해 최종 보상을 정한다.

제약:

- 기준 보상 최대 200포인트
- 루틴 항목 최대 10개

DJ48 반영 포인트:

- 학생/교사 모두 루틴을 수정할 수 있어야 한다.
- 보상은 0~20 같은 좁은 범위보다 운영 정책에 맞춰 제한값을 명확히 둔다.
- 루틴 항목은 이름 아래 체크 항목으로 보이게 해야 한다.
- 날짜가 지나면 교사 검토 목록으로 이동해야 한다.

## 10. 루틴 보상 관리

루틴 보상 관리 모달은 보상 대기를 두 갈래로 나눈다.

구분:

- 일일 지급 루틴
- 목표일 달성 루틴

각 구분에서 보여주는 정보:

- 전체 지급 또는 전체 처리
- 대기 인원/건수
- 예상 지급액
- 지급 대기 목록
- 검토 대기 목록

DJ48 반영 포인트:

- 교사 작업대에 `오늘 지급할 루틴`과 `마감 검토 루틴`을 분리해야 한다.
- 학생이 완료 버튼을 눌렀다고 곧바로 포인트가 들어가는 흐름은 루틴에는 맞지 않다.
- 검토 화면에서 달성률, 항목별 체크, 보상 포인트를 확인 후 지급해야 한다.

## 11. 루틴 템플릿

템플릿 관리에는 자주 쓰는 루틴 꾸러미가 카드로 제공된다.

확인한 템플릿 예:

- 성실한 기본 생활
- 완벽한 아침 습관
- 나를 위한 건강/운동 관리
- 스스로 학습 마스터

각 템플릿 정보:

- 템플릿 이름
- 루틴 항목 목록
- 달성 보상

학생 루틴 생성 화면에서도 `템플릿 불러오기`가 제공된다.

DJ48 반영 포인트:

- 성장 루틴을 매번 직접 쓰게 하면 사용성이 떨어진다.
- 초기에는 고정 템플릿 4~6개만 제공해도 충분하다.
- 교사가 템플릿을 관리하고 학생은 불러와 수정하는 흐름이 적합하다.

## 12. 학생 메인 화면

학생 로그인 후 첫 화면에는 다음이 표시된다.

상단 기능:

- 카드
- 텃밭 은행
- 마켓
- 젬스톤
- 직업

학생 카드:

- 번호
- 이름
- 레벨
- 베리
- 포인트
- 포인트 요청
- 역량 카드 요청

오늘 할 일 카드:

- 클래스 알림
- 퀘스트
- 성장 루틴
- 우리반 미션
- 웍스

DJ48 반영 포인트:

- 학생 첫 화면은 설명보다 `오늘 할 일`이 먼저 보여야 한다.
- 퀘스트, 성장 루틴, 미션, 알림은 별도 탭 깊숙한 곳보다 카드형 진입이 좋다.
- 학생 화면에는 교사용 설정 정보가 보이면 안 된다.

## 13. 학생 퀘스트 화면

학생 퀘스트 모달은 단순하다.

확인된 상태:

- 제목: 오늘의 퀘스트
- 안내: 도전 과제를 완수하고 포인트를 획득하세요.
- 오늘 퀘스트가 없으면 `오늘은 퀘스트가 없습니다.` 표시

DJ48 반영 포인트:

- 학생 퀘스트 화면에는 노출 기간, 대상 학생, 젬 연결 같은 관리 정보가 필요 없다.
- 학생에게는 `할 일`, `보상`, `완료 여부`, `제출/완료 버튼`만 보여주면 된다.

## 14. 학생 성장 루틴 화면

학생 루틴 모달의 구조:

- 진행중
- 검토중
- 완료
- 새 루틴 추가

학생에게도 다음 설명이 제공된다.

- 일일형은 매일 체크한다.
- 목표형은 기간 안에 실천한 뒤 종료 후 자기 평가와 함께 검토를 받는다.

학생 루틴 생성 입력:

- 루틴 방식
- 루틴 꾸러미 이름
- 기준 보상
- 시작일
- 종료일
- 반복 요일
- 루틴 항목
- 템플릿 불러오기

DJ48 반영 포인트:

- 학생이 만든 루틴도 수정 가능해야 한다.
- 루틴 완료는 `검토중` 상태를 거쳐야 한다.
- 학생이 보상을 설정하더라도 실제 지급은 교사가 확정해야 한다.

## 15. 젬스톤 전시 화면

학생 젬스톤 화면은 전체 학생의 보유 젬을 카드처럼 보여준다.

카드 정보:

- 학생 번호
- 학생 이름
- 레벨
- 젬스톤 보유 개수
- 보유 젬 이름 목록

젬이 없으면:

- 아직 획득한 스톤이 없어요

DJ48 반영 포인트:

- 젬스톤은 내부 진행률 입력 화면보다 전시 화면이 중요하다.
- 학생별 획득 젬 목록을 한눈에 볼 수 있어야 한다.
- 대표 타이틀/뱃지와 젬스톤 전시는 분리하는 편이 좋다.

## 16. 퀘스트 리더보드

퀘스트 리더보드는 학생별 달성률을 카드로 보여준다.

상단 정보:

- 노출 퀘스트 수
- 참여 학생 수

정렬:

- 번호순
- 순위순

학생 카드 정보:

- 순위
- 학생 이름
- 번호
- 완료 퀘스트 수
- 전체 퀘스트 수
- 달성률

DJ48 반영 포인트:

- 교사 최근 활동은 세부 로그만 나열하면 피로하다.
- `누가 몇 개 완료했는지`, `누가 검토 대기인지`가 먼저 보여야 한다.
- 최근 활동은 최대 10건 또는 유형별 요약이 적합하다.

## 17. 학급 자산 정보

학급 자산 화면은 경제 시스템 전체를 한 번에 보여준다.

확인 정보:

- 학급 총 포인트
- 학급 총 하트베리
- 하트베리 기금
- 복지 포인트 기금
- 환전 비율
- 환전 허용 여부
- 환전 수수료
- 고정 수수료
- 조기 인출 수수료
- 복권 가격
- 복권 당첨금
- 예금 상품
- 직업 시스템
- 소득세율
- 레벨업 보상

DJ48 반영 포인트:

- 환전 은행 UI를 작은 드롭다운 하나로 처리하면 전체 경제 구조와 동떨어져 보인다.
- `내 자산`, `환전`, `적금/예금`, `정책 안내`를 한 화면에 묶는 것이 좋다.
- 적금이 없을 경우에는 `교사가 아직 설정하지 않았습니다`처럼 빈 상태를 명확히 보여야 한다.

## 18. 학급 미션

학급 미션은 개인 보상과 별도로 반 전체 누적 포인트를 목표로 사용한다.

구조:

- 현재 학급 보유 포인트
- 다음 목표
- 진행률
- 등록된 미션
- 목표 포인트
- 달성 혜택
- 달성 완료 여부

DJ48 반영 포인트:

- 퀘스트/루틴은 개인 수행 중심이다.
- 학급 미션은 반 전체 포인트 또는 활동 누적 목표로 분리하는 편이 좋다.
- 공동구매샵이나 학급 목표 보상과 자연스럽게 연결할 수 있다.

## 19. DJ48 개선 우선순위 제안

### 19.1 1단계: 교사 작업대 재정리

목표:

- 교사가 오늘 처리할 일을 한눈에 보게 한다.

구성:

- 오늘 완료 요청
- 루틴 검토 대기
- 퀘스트 완료 취소/해제
- 최근 교실 활동
- 테스트 학생 숨김 처리

필수:

- 최근 활동은 닉네임으로 표시
- 테스트 학생은 활동/카드/랭킹에서 숨김
- 활동은 최대 10건 또는 유형별 요약

### 19.2 2단계: 퀘스트 생성 UI 개선

목표:

- 교사가 번호를 직접 입력하지 않고 선택하게 한다.

구성:

- 제목
- 설명
- 포인트
- 노출 기간
- 카테고리
- 대상 학생 체크 리스트
- 젬스톤 연결
- 반복 설정

필수:

- 전체 선택/전체 해제
- 학생 번호 + 닉네임 표시
- 젬스톤은 이미 생성된 목록에서 선택

### 19.3 3단계: 성장 루틴 구조 전환

목표:

- 학생 체크와 교사 보상을 분리한다.

구성:

- 진행중
- 검토중
- 완료
- 루틴 수정
- 항목별 체크 로그
- 교사 보상 지급

필수:

- 날짜가 지나면 검토 대기로 이동
- 교사가 달성률 확인 후 포인트 지급
- 학생이 루틴 수정 가능

### 19.4 4단계: 젬스톤 단순화

목표:

- 젬스톤을 교사가 이해하기 쉬운 횟수 누적형으로 만든다.

구성:

- 젬 이름
- 달성 조건 횟수
- 연결 퀘스트
- 학생별 진행도
- 획득자 목록

필수:

- 퀘스트 완료 시 연결 젬 +1
- 목표 달성 시 젬 획득
- 젬 보유 현황 전시

### 19.5 5단계: 학생 홈 재구성

목표:

- 학생이 오늘 무엇을 하면 되는지 즉시 알게 한다.

구성:

- 내 카드
- 오늘 퀘스트
- 나의 성장 루틴
- 내 포인트/베리
- 젬스톤 진행
- 학급 미션

필수:

- 학생에게 교사용 설정 노출 금지
- 빈 상태 문구 명확화
- 완료 후 중복 클릭 방지

## 20. 결론

Grownd의 퀘스트/루틴/젬스톤 구조는 기능 수가 많지만 핵심 원칙은 단순하다.

- 교사는 설계하고 검토한다.
- 학생은 오늘 할 일을 수행한다.
- 퀘스트는 직접 보상과 젬 진행도를 만든다.
- 루틴은 즉시 지급보다 검토 후 보상에 가깝다.
- 젬스톤은 복잡한 XP보다 횟수형 성취 전시가 핵심이다.
- 경제 시스템은 포인트, 은행, 직업, 미션을 하나의 운영 체계로 보여준다.

DJ48은 이미 퀴즈타운, 포인트, 타이틀, 교실 기능이 있으므로 Grownd 전체를 복제할 필요는 없다. 다만 교사 작업대, 루틴 검토 흐름, 젬스톤 연결 방식, 학생 홈의 오늘 할 일 구조는 우선 반영할 가치가 높다.
