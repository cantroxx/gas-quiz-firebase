# 코디 상점 전체 목록·라벨 우선순위 점검

2026-09-29. 로컬 구현·검증 완료. 배포·운영 설정·학생 데이터 변경 없음.

후속: [피부·투명 상품 변경](COORDI_SKIN_TRANSPARENT_UPDATE_2026-09-29.md)에 따라 피부 37종 복원, 방패 9종 제외, 투명 상품 13종 추가 및 라벨 설명 제거를 적용했다. 현재 751개이며 아래 710개 및 배지 관련 설명은 이전 점검 시점의 기록이다.

## 점검 결과와 변경

기존 701개, 남녀 진열 1,092칸은 원본의 최근 30일 착용 수 내림차순이었다. 하지만 `verified-top50.json`을 만들면서 스라벨·마라벨 정보가 빠졌고, 화면은 배열을 그대로 표시했다. 이전 정렬 보조 함수에 있던 가중치는 실제 진열 경로에서 사용하지 않았다. 따라서 라벨 우선 진열은 없었다.

9월 29일 공개 스페셜/마스터 라벨 페이지에서 코드 1,321개의 분류를 확인하고, 기존 상품 전체와 대조했다. 14개 판매 파츠의 최근 30일 착용 통계도 같은 조회 작업에서 다시 수집했다. 701개 모두 통계에 존재했고 캐시 분류도 true였다. 기존 인기 후보 목록에서 누락된 라벨 상품 9종을 찾아 15개 남녀 착용 PNG를 새로 검증하고 추가했다.

| 구분 | 이전 | 변경 후 |
|---|---:|---:|
| 스페셜 라벨 | 58 | 66 |
| 마스터 라벨 및 해당 헤어 | 46 | 47 |
| 기타 유지 상품 | 597 | 597 |
| 고유 판매 상품 | 701 | 710 |
| 성별 중복 포함 진열 | 1,092 | 1,107 |

**정렬: 확인된 스라벨·마라벨을 같은 우선 그룹으로 배치 → 각 그룹에서 최근 30일 착용 수 내림차순 → 동률이면 원본 순위와 코드로 정렬.** 마라벨을 스라벨보다 무조건 앞세우거나 최신 기수를 무조건 앞세우지 않는다. 이름 검색과 보유 필터를 적용해도 같은 순서를 유지한다. 라벨 종류·기수를 카드에 표시한다.

인기 지표는 메애기가 집계한 외부 착용 수이며 퀴즈타운 구매 수나 선호도 투표가 아니다. 9월 29일 조회한 고정 스냅샷으로, 자동 실시간 갱신은 구현하지 않았다. 기존 `usedCount`·`rank`·원본 수집 시각은 보존하고 새 관측은 `popularity`와 `catalogReview`에 저장했다. 새로 추가한 상품의 옛 관측 시각은 `originalObservationAt`으로 별도 기록한다.

이번 범위는 현재 상점 전체와 저장된 인기 후보의 누락 점검이다. 전 기수 라벨 1,321개를 모두 판매하는 전수 수집 상점으로 확장한 것은 아니다.
