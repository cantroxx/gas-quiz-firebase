# 공통 개인 상태창 — 2026-09-20

최신 전체 구현·검증·배포 인계: [퀘스트·상태창·상점 일괄 보고](GROWTH_QUEST_SHOP_REPORT_2026-09-20.md).

현재 운영 반영 및 두 숏컷/자동 갱신 구성은 [운영 반영 보고](GROWTH_QUEST_LAUNCH_2026-09-20.md)를 따른다. 아래는 초기 구현 기록이다.

초기 읽기 전용 상태창에서 **일일·주간 퀘스트와 보상 수령까지 가능한 창**으로 확장했다. 온라인 보상·하보 진입 연결 분리·상점 거래도 위 보고서에 정리했다. 변경은 로컬 구현 완료 상태이며 배포하지 않았다.

## 구조

- `public/js/player-status-shortcut.js`: 우측 하단 버튼. 같은 사이트에서는 모달과 지연 로딩 iframe, 외부 사이트에서는 퀴즈타운 상태 페이지 새 창.
- `public/player-status/`: 보유 코인, 누적 XP, 레벨 진행, 출처별 보상 한도, 일일·주간 퀘스트, 오늘 퀘스트 수령액.
- 창 열기·새로고침·로그인 변경 시 조회. 상시 polling 없음. 닫으면 iframe 해제, 로그아웃 시 표시 제거, 부분 실패 별도 안내.
- 게임을 일시정지하지 않는다. 외부 게임에 로그인 토큰이나 회원 정보를 넘기지 않는다.

## 연결

메인 연습전·랭킹전, 아지트, 구름탑, 서바이버, 말폭탄, 기존 낱말대전, 분수 월드/스터디 타운, 우주 탐험, 코디 상점, 두근두근 마블. 별도 KBO 사이트에도 공통 스크립트를 연결했다. 하보 하우징에는 추가하지 않았다.

마블은 `town-marble-src/index.html`을 수정하고 정식 빌드했다. 스터디 타운은 별도 배포용 폴더에 숏컷 스크립트를 포함했다. 외부 게임 연결은 퀴즈타운 상태 페이지를 먼저 배포한 뒤 각 외부 사이트를 배포해야 한다.
