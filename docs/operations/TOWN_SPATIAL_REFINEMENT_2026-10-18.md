# 공간형 타운 UI 후속 보완 배포

2026-10-18 사용자 피드백 1~7번 완료. 계획 `docs/product/TOWN_SPATIAL_REFINEMENT_PLAN_2026-10-18.md`의 1→5단계를 순차 완료했다.

## 반영 결과
- **명예의 전당**: 입장 즉시 모든 분야 1위 카드 표시. 접기 토글과 별도 오늘의 왕 중복 표시 제거.
- **랭킹 광장**: 하보 명예의 전당 링크 제거. 저장된 운영 데이터는 삭제하지 않았다.
- **아바타**: 토끼를 제거하고 현재 인증 계정의 구매·저장 코디(의상·염색)를 읽기 전용 status/preview로 표시. 상점에서 돌아오면 저장 코디를 다시 조회한다. 무료 입어보기의 미저장 코디는 반영하지 않는다.
- **이동**: 반복 점프·회전 제거, 길을 따라 차분하게 이동. 방향별 걷기 프레임이 없는 코디 렌더러이므로 정지 코디 이미지의 위치가 부드럽게 이동한다. 코디가 없거나 불러오기 실패 시 중립 위치 표시 사용. 계정 변경·로그아웃·늦은 응답을 분리 처리.
- **학교**: 컨셉퀴즈 입구·내부 탭·진입 경로 제거. imagegen으로 원화의 해당 문만 책장/화분 장식으로 보완. 우리 교실·과목·학습·인기·게임 아지트의 5개 입구 유지. 기존 컨셉 데이터가 학습 목록에 섞이지 않도록 기존 필터 유지.
- **이벤트 광장**: 미수령 보상이 있을 때만 상단 작은 버튼 표시. 클릭하면 비모달 드롭다운이 열리고 마지막 보상 수령 후 자동 닫힘·버튼 숨김. Escape/밖 클릭/화면 이동 시 닫힘, 초점 복귀. 맵의 항상 표시되던 보상 입구 제거. 오늘의 퀘스트 유지.
- 긍정 평가한 기존 타운 맵·나머지 공간의 화풍은 유지했다.

## 검증
- `npm run check` 종료 0. 정적/도메인/응용/인프라/게임/로컬 Rules 검사, 교실 76개 역할·폭·탭 조합, 과목 49개 단원·404문제 × 3개 폭(1,212개 화면) 통과.
- 실제 렌더러/상점 iframe을 연결한 공간 UI, 보상 조건 0/1/수령완료·수령 위임·새 계정 초기화·키보드·모바일, 제거된 학교 진입, 모든 명예 카드 즉시 노출 검증.
- 아바타: 서버 저장 코디 페이로드 일치, 소유 조건·염색, 캐시, 계정 변경, 늦은 응답, 로그아웃, 실패/재시도, 상점 복귀 검증. 검사에는 합성 계정만 사용했다.
- 동일 검사를 실제 운영본에서 구성한 후보에 적용했다. 배포 후 운영 파일 해시 및 공개 로그인 1440/390/320px, 새 JS/CSS와 학교 이미지 로딩을 확인했다. 실제 학생 계정으로 로그인하거나 학생 데이터를 수정하지 않았다.
