# 스터디 타운 부활 부적 수정·배포

## 원인과 수정

- `combat-expansion.js`에서 독 지속 피해가 구조 부적 검사 전에 기본 피해 처리로 직행하여, 부적을 가지고도 사망했다.
- 독 피해에도 부적을 한 번 소모하여 최대 체력 30% 회복과 2초 보호를 적용한다. 발동 시 남은 독을 제거한다.
- `combat-tactics.js`에서 부적을 발동시킨 독 투사체가 즉시 독을 다시 부여하지 않도록 수정했다.
- 일반 독 피해의 보호막 우회는 유지하며, 난이도별 재도전 횟수는 부적 발동으로 소모하지 않는다.

## 검증

- 수정 전 독 치명타 회귀 테스트 실패를 재현하고 수정 후 통과했다.
- `npm run check` 전체 종료 코드 0. 초기 포트 충돌은 기존 에뮬레이터를 사용자 요청으로 종료한 뒤 해소했다.
- 구매 후 상태 복원, 세 난이도, 보호막 우선 적용, 1회 소모, 실제 Arena의 접촉·독 지속 피해·독 투사체 처리를 검사했다.
- 운영본을 복제한 배포 디렉터리에서도 전투 회귀 테스트가 통과했다.
