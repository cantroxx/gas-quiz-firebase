# 증권소 학생 화면 개선 — 2026-10-18

## 범위

사용자 요청: 증권 및 회사 아이콘 조정, 교실의 다른 탭을 참고한 학생 중심 UI와 쉬운 말 적용.

사용자의 배포 요청에 따라 운영 Hosting에 반영했다. 앞선 C/D 단계의 4-8 교사 시범 배포에 이어진 UI 변경이며, 학생 공개 설정이나 운영 데이터는 변경하지 않았다.

## 변경

- 교실의 그림 중심 메뉴와 부드러운 색감을 참고해 증권소 아이콘을 새로 만들고, 회사 12곳에 하는 일을 나타내는 SVG 아이콘을 추가했다. 재생성 도구: `scripts/maintenance/build-securities-icons.js`.
- 회사 카드에는 그림, 하는 일, 1주 값, 가격 변화, 내 주식 수, `회사 알아보기`를 순서대로 표시한다. 검색은 이름·업종·회사 설명에 적용한다.
- 메뉴: `회사 둘러보기 / 회사 소식 / 내 주식 / 생각 노트`.
- 학생 용어: `매수·매도 → 주식 사기·팔기`, `예수금 → 증권 지갑 코인`, `수수료 → 이용료`. 가격 버전 등 내부 식별자는 학생 화면에서 제거했다.
- 주식 확인 창에는 1주 값, 주식값 합계, 이용료, 거래 후 코인을 표시하고 `이대로 살게요 / 이대로 팔게요`로 마지막 확인을 받는다.
- 코인 화면은 `내 지갑 ↔ 증권 지갑` 두 상자와 `증권 지갑에 넣기 / 내 지갑으로 꺼내기` 버튼으로 방향을 표시한다. 한도와 1코인 미만 잔액 안내는 펼쳐볼 수 있다.
- 모바일 메뉴는 2열, 회사 카드는 1열로 표시한다. 회사 상세에서 부가 정보는 접어두고 회사 소개·가격·내 주식·사기/팔기를 먼저 표시한다.
- 가격 하락과 손해 가능성, 가상 회사 안내, 이용료와 거래 한도는 유지한다. 거래 계산, 서버 권한, DJ코인 처리, 교사 시범 공개 설정은 변경하지 않았다.

## 검증

- `npm run check:static`: 통과.
- `npm run check:securities-emulator`: 통과. 기존 서버 거래·권한·원장·DJ코인 동시성 및 브라우저 재시도/지갑 동기화 검증 포함.
- 브라우저: 회사 아이콘 12개 로딩, 390/768/1440px 가로 넘침 없음, 학생·교사 화면, 주문 두 단계 확인 및 코인 이동 확인.
- `npm run check`: 통과. 증권 단위 테스트 14개, 기존 교실 76개 화면 조합, 권한 규칙, 교실 로딩·일기, 교실 바깥 과목 퀴즈 화면 및 이어 풀기 검증 포함.
- 스크린샷은 합성 학생·합성 코인으로 생성했다. 운영 학생 데이터가 아니다.
