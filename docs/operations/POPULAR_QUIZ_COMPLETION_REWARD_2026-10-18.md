# 인기 퀴즈 직접 진입·연습 완료 보상

사용자 후속 지시와 오답 재도전 방식 선택을 반영했다. 인기 퀴즈의 보상 조건은 이 문서가 이전 문제별 지급 설명보다 우선한다.

## 바뀐 동작

- 학교의 인기 퀴즈 입구와 학교 내부 인기 퀴즈 버튼을 누르면 중간 카드 목록 없이 `/popular-quiz/`의 분야 선택 화면을 같은 탭으로 연다.
- 사진 퀴즈 클럽에서 돌아가면 학교 화면을 연다. 인기 퀴즈로 다시 자동 이동하는 반복은 발생하지 않는다.
- 선택한 분야의 서로 다른 20문제를 연습한다. 맞힌 문제는 대기 목록에서 제거하고, 틀린 문제는 목록 뒤로 보내 다시 출제한다. 시간 제한은 없다.
- 문제별 XP·코인 지급은 없다. **서로 다른 20문제를 모두 맞혀 연습판을 완료한 순간에만 XP 2·코인 1을 한 번 지급**한다. 기존 공통 지급량을 완료 1회의 지급량으로 사용했다.
- 다른 연습전과 공유하는 하루 XP 20·코인 50 한도, 기존 주간 XP 한도와 지급 활성화 설정은 유지한다. 남은 XP 한도가 1이면 완료 시 XP 1만 지급한다.
- 20번 답했어도 틀린 문제가 남으면 완료하지 않는다. 예를 들어 처음 한 문제를 틀리고 나머지 19개를 맞혔다면 19/20 해결 상태로 오답을 다시 풀며, 21번째 답에서 이를 맞히면 완료 보상을 지급한다.
- 중도 종료는 보상이 없다. 완료 전 새로고침은 해결 개수·남은 문제 순서·진행을 유지한다. 완료 요청 재전송, 동시 제출, 완료 응답 유실 후 재시도는 중복 보상을 만들지 않는다.
- 랭킹전의 출제·점수·하트·세대 조건과 기존 기록은 바꾸지 않았다.

## 이전 연습판 처리

기존 문제별 지급 규칙으로 시작된 판에는 각 문항의 해결 여부를 복원할 이력이 충분하지 않다. 이런 미완료 연습판은 사용자가 다음에 이어 풀거나 답안을 보낼 때 종료 안내를 반환하고 새 판으로 시작하게 한다. 기존 보상·기록은 보존하며, 이미 종료된 판에 새 완료 보상을 소급 지급하지 않는다. 운영 데이터 일괄 수정·삭제는 하지 않는다.

## 구현과 검증

- 서버 `functions/popular-quiz/service.js`: 최대 20개 문제 번호로 구성된 대기 목록과 해결 개수를 관리한다. 완료 진행·보상·완료 횟수를 같은 트랜잭션에 저장하며, 공통 보상 기록 키는 판 ID와 고정된 `completion`을 사용한다.
- `public/popular-quiz/app.js`: 해결 개수, 오답 재도전, 완료 지급 조건과 실제 완료 보상을 표시한다.
- `public/js/school-rooms.js`, `public/index.html`: 직접 진입과 학교 복귀를 처리한다.
- 에뮬레이터: 19개 해결 시 미지급, 오답 재출제, 마지막 보상 실패 시 진행 롤백, 최종 동시 제출, 공통 한도 경계, 지급 중지, 중도 종료, 이전 규칙 판 종료, 기존 랭킹 회귀 검증.
- 브라우저: 실제 callable을 연결해 오답 포함 21회 도전으로 완료, 완료 응답 유실·재시도에도 코인 1만 지급, 문제별 보상 표시 없음, 완료 결과 화면, 사진 오류 복구, 이어 풀기, 모바일 검증.
- 학교 화면: 입구 클릭과 내부 메뉴에서 같은 탭으로 직접 이동하며 중간 방을 렌더링하지 않음을 확인했다.

배포 후보는 당시 운영 소스를 기준으로 Hosting 6개 경로와 `popularQuizAction`의 `popular-quiz/service.js`만 변경한다. 이미지 551개, 기존 다른 함수, 보안 규칙·인덱스와 Hosting 설정은 보존한다. 배포 결과와 영수증은 후속 확인 절에 기록한다.
