# 그림책 마을 입구 배포

사용자 요청으로 로그인과 첫 마을을 그림책 스타일로 변경하고 운영 반영했다. 중앙 트로피 광장과 왼쪽 축제 마당에 랭킹·이벤트 클릭 영역을 배치했다. 우리 교실 입구는 마을에서 제거하고 학교 상단에 기존 `data-place="classroom"` 버튼으로 옮겼다. 장소 내부 기능과 인증·데이터 처리는 유지했다.

## 범위와 배포

- `/index.html`: 로그인·마을 마크업, 전용 CSS 링크, 학교 안 교실 입구
- `/town-entry.css`: 로그인·마을 ID로 범위를 제한한 스타일
- `/images/town-storybook-plazas-v2.png`: 수정한 그림책 배경

현재 운영 HTML을 기준으로 위 변경만 구성했으며 결과가 로컬 HTML과 동일함을 확인했다. 운영 버전을 복제하여 위 3개 파일만 추가·교체하고 나머지 파일 해시 보존을 검증했다. Functions·Rules·운영 데이터는 변경하지 않았다.

- 이전 버전: `7a1418b45f77ab15`
- 배포 버전: `edb33551d1b2e157`
- 릴리스: `1789448996120000`

## 검증

- 배포 전 `npm run check` 전체 통과
- PC 1440px·모바일 390px 로그인 입력, 7개 지도 목적지 표시, 지도 가로 스크롤 및 본문 가로 넘침 없음 확인
- 배포 후 공개 화면 smoke 및 HTML·CSS·이미지 응답 내용 일치 확인
- 학생 계정으로 로그인하여 실제 내부 기능을 조작하는 검사는 수행하지 않았다. 기존 장소 이벤트 바인딩을 재사용한다.
