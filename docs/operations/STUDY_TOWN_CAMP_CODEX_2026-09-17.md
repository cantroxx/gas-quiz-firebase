# 스터디 타운 캠프·수집 화면 개편

## 변경

- 스타라이트 스튜디오 실행 화면, 시작 버튼, 전용 설명과 분수 범위 설정 제거. 스튜디오 UI/시뮬레이션 코드는 공개 폴더에서 제거하고 과거 저장 검사용 fixture로 이동. 전용 WebP 4개는 Vercel 배포에서 제외. 기존 탑·학습·해금·랭킹 기록은 초기화하지 않음.
- 캠프 첫 화면은 기존 탑 일러스트와 출발/이어하기, 수첩, 도감으로 정리.
- 준비 과정: 단원 → 모습 → 무기 → 난이도 → 몬스터/출발. 6단원 그림 카드에서 복수 선택, 최소 1개 검증, 이전 선택 기억. 시작 시 tower.studyUnits로 복사하여 진행 중 단원 변경 방지. 랭킹 서버 단원과 같은 출발 설정 사용. 예전 탐험은 저장된 설정으로 계속 지원.
- 모험 수첩: 지역 도장과 모험 발자취, 1/10/30 첫 정답 수학 도장, 오답 책갈피, 자유 서술·교사 피드백. 답안은 12개씩 페이지 이동, 기존 120개/누적 통계·JSON 내보내기 유지.
- 보물 도감: 속성별 유물 진열, 미발견 실루엣, 현재 가방 표시, 무기·외형 해금, 그림 조합표와 개별 상세. 미발견 유물 이름·상세 효과는 발견 뒤 공개.
- 갑옷은 금빛 빛 조각과 파손 조각, 룬 몬스터는 보랏빛 상승 입자, 등장 효과는 소환 입자, 공격 준비는 몸 주변에 모이는 빛. 바닥 공격은 균열/불씨/독 안개로 표현. 피해 반경과 공격 방향, 타이밍·전투 난이도는 그대로.
- 빛 텍스처는 48px 캔버스에 한 번 만들어 재사용. 이미지 네트워크 요청이나 대형 스프라이트 추가 없음. 수첩·도감·캠프에서는 전투 길잡이 줄 숨김.

## 검증

- 기존 분수·저장·탑·48 무기/보스·조작/부활 검사 통과.
- 90문항 실제 브라우저 풀이, 입력·새로고침·서술·교사 검토 흐름 통과.
- 합성 계정 서버 출제/등록/응답 유실/재등록 브라우저 검사 통과.
- 캠프 검사: 스튜디오 미노출·미요청, 단원 고정, 도감/수첩 탭, 잠긴 유물, 390/820/1180px 가로 넘침, 전투 효과 그리기. 태블릿 도감 넘침 수정 후 통과.
- 전체 `npm run check`는 다른 작업의 에뮬레이터와 충돌하지 않는 /tmp/study-validation-20260916에서 종료 코드 0으로 통과. 최신 테스트 복사본을 사용했고 운영 포트/규칙은 변경하지 않음.

스튜디오 과거 저장 필드와 데이터 카탈로그는 이전 저장 칸을 읽기 위해 남아 있으며 플레이 경로나 전용 이미지 로딩은 없다. 랭킹 서버·학생 데이터·Firebase Rules 변경 없음.
