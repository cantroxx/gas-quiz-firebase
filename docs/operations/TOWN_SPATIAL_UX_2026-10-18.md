# 공간형 퀴즈타운 UI — 구현·검증 기록

## 이번 변경의 결과

이전 배포의 배너 중심 화면에서, 새 원화 속 건물·가구·게시판을 눌러 기능을 여는 공간형 화면으로 전환했다. 사용자 배포 요청에 따라 2026-10-18 운영 Hosting에 반영했고 사후 검증까지 완료했다.

| 공간 | 달라진 화면과 실제 동작 |
| --- | --- |
| 로그인 | 새 마을 입구 원화와 기존 로그인·가입 폼 |
| 타운 | 학교·집·상점·퀘스트 광장·랭킹 광장을 새 길로 연결. 바닥 클릭 시 도우미 이동, 건물 클릭 시 이동 후 기존 라우터로 입장. 빠른 이동·키보드는 즉시 입장 |
| 내 집 | 책상 → 내 정보, 기록장 → 내 랭킹 기록, 수집장 → 칭호·뱃지 탭, 상자 → 보유 아이템, 작은 문 → 기존 `/housing/` |
| 학교 | 여섯 문 원화와 기존 교실·과목·학습·인기·컨셉·게임 아지트 연결. 아래 빠른 입장도 동일 컨트롤러 호출 |
| 상점 | 진열대 → 실제 코디 상점, 거울 → 실제 무료 드레스룸. 같은 iframe 유지로 입어본 코디와 기존 구매 확인 흐름 보존 |
| 이벤트 광장 | 게시판 → 오늘의 퀘스트와 실제 수령 버튼, 상자 → 기존 미수령 보상 팝업 |
| 랭킹 광장 | 트로피 → 명예의 전당, 게시판 → 기존 순위 목록·탭. 랭킹 모드 데이터 구조는 변경하지 않음 |

모바일은 전체 그림과 번호형 입구를 먼저 보여준다. 같은 번호의 텍스트 메뉴로 기능을 찾을 수 있고, ‘크게 보기’를 누르면 원래 크기의 이름표와 가로 탐색을 사용한다. 모션 감소 설정에서는 애니메이션 없이 입장한다.

## 구현과 보존 범위

- `public/js/town-spatial.js`: 장면 구성, 클릭 이동, 기존 DOM을 보존하는 기능 패널, 닫기·ESC·포커스 복귀, 기존 외부 팝업 연동, 상점 지연 로딩 모드 처리.
- `public/town-spatial.css`: 새 장면, 원화에 맞춘 클릭 영역, 패널, 모바일 전체/확대 보기.
- `public/index.html`: 새 CSS와 defer 스크립트 두 줄 연결. 이전 작업 이후의 이 작업만의 차이는 검수 폴더 `spatial-index.patch` 참조.
- `public/images/town-spatial-20261018/`: 배포용 WebP 8개, 총 약 1.8MB. 실내 원화는 lazy loading.
- `docs/product/town-spatial-review-2026-10-18/originals/`: 내장 imagegen의 원본 PNG 8개. 도우미는 실제 투명 알파 보존.
- `docs/product/TOWN_SPATIAL_IMAGE_PROMPTS_2026-10-18.json`: 사용한 정확한 프롬프트. CLI/API 우회 사용 없음.
- `scripts/smoke/town-spatial-browser.js`: 기존 렌더러·컨트롤러·실제 코디 iframe에 가상 계정을 연결한 새 통합 검사. 운영 요청 차단.
- `scripts/smoke/school-hubs-browser.js`: 새 공간 모듈과 학교 빠른 입장 회귀 검사 추가.

오늘의 퀘스트는 유지한다. 오늘의 퀴즈·시즌 이벤트 입구는 추가하지 않았다. 기존 미수령 보상 조회는 유지한다. 재화·랭킹 하드리셋, 랭킹전 단일 모드 전환, Functions/Rules, 운영 데이터 수정은 이 작업에 포함하지 않았다.

## 검증 근거

- 공간 검사: 다섯 경로, 이동 중 목적지 변경, 키보드·모션 감소·터치, 모바일 확대, 프로필 입력 유지, 기존 이미지 편집 팝업에서 돌아오기, 홈 외부 탭 진입, 실제 퀘스트 수령 위임·비활성 상태, 순위 표시, 상점 로딩 전 무료 모드 요청·코디 선택 유지, 상점 잠금 안내, 빈 퀘스트·랭킹 검사.
- 기존 학교 검사: 다섯 분류·여섯 입구, 접근 제한, 외부 링크, 필터·캐시·재시도·계정 전환 통과.
- 기존 코디 검사: 코인·쿠폰 구매, 가격·잔액, 무료 모드, 쿠폰 부족, 모바일 통과. 가상 서버 사용.
- 기존 퀘스트 검사: 열기·닫기·수령·미수령 보상·계정 전환·모바일 통과.
- 전체 검사: `npm run check` exit 0. 정적 검사·도메인·애플리케이션·인프라·게임·Rules 에뮬레이터·공개 앱 초기화·교실 76개 반응형 사례·과목 퀴즈 전체 및 재개 검사 통과. `docs/product/town-spatial-review-2026-10-18/full-check.log` 보존.
- 검수 화면: `docs/product/town-spatial-review-2026-10-18/`의 PNG. 1440/390/320px, 가상 닉네임과 재화만 사용. 외부 웹폰트 요청은 차단하므로 스크린샷은 대체 폰트이며 실제 운영에서는 기존 웹폰트를 사용한다.

## 인계·배포 주의점

작업 트리에 다른 작업의 미배포 변경이 다수 존재한다. 배포 전 운영 버전 `170a9325bad778b2`를 대조하고 index 두 줄·새 JS/CSS·WebP 8개만 반영하는 후보를 만들어 검사했다. 전체 작업 트리 대신 현재 운영 버전을 복제하여 필요한 11개 파일만 반영했다. 앱 번들은 변경하지 않았다.

원상 복구는 index의 새 CSS/JS 연결 두 줄을 제거하면 된다. 실제 기능 DOM과 기존 컨트롤러는 유지되어 있다. 별도 Git commit/push는 수행하지 않았다.
