# 연습기록·타이틀·아지트 장식 개편 (배포 완료)

## 확정 기준
- 과목 연습: 정오답 포함 100번 답하기 = 1회 완주. 과목별 100/300/500회에 초보/중수/고수.
- 과목 랭킹: 한 판에서 20연속 정답 달성 시 성공 1판, 판당 최대 1회. 10/20/30판에 달인/마스터/신. 오답은 연속 횟수를 초기화하고 이미 달성한 성공을 취소하지 않는다.
- 인기 연습: 무제한 출제, 정오답 포함 100/200/300회 타이틀. 포켓몬은 세대별 별도 집계. 인기 랭킹은 배포된 문제 수 무제한·하트 3개·이탈 저장을 유지.
- 새 집계 버전 achievements-20261019-v1. 이전 연습·타이틀·랭킹 데이터를 소급하지 않는다. 기존 보유 데이터와 선택 상태는 보존하되, 후속 요청에 따라 보유 목록·전체 목록에서 구 타이틀을 제외하고 신타이틀만 표시.

## 구조
- functions/achievements/catalog.js: 서버 단일 정의, 63종. 공개 목록을 Firestore titleCatalog에서 읽지 않는다.
- achievementProgress/{memberId}: 서버 전용 연습 답안 수·성공 판 수. 기본 거부 규칙을 유지하고 연결 계정 확인 callable로만 조회. 기존 보안 규칙 변경 없음.
- 답안과 집계를 동일 트랜잭션으로 저장. 새 집계 시작 전의 진행 중 판에서 연속 정답을 가져오지 않는다.
- 내 집 진입/칭호 확인에서 syncMemberTitles가 조건 달성 타이틀을 지급. 동시 요청은 트랜잭션으로 중복 생성 방지. 기존 칭호 획득 보상과 레벨업 보상 정책 유지. 보상 로그로 재시도 복구 및 중복 지급 방지.
- 내 집 랭킹은 subjectQuizAction/memberRankings + popularQuizAction/memberRankings만 사용. 인기 서버 원본·현행 버전만 조회하며 과거 포켓몬 난이도 기록을 읽는 클라이언트 경로 제거. 퀴즈왕 서버 집계도 구 quizKingSummary 대신 현행 과목·인기 원본으로 계산.
- 구 칭호 판정 함수(뱃지·분야·세대 수·구랭킹 점수·이모지 합산)와 구 뱃지 완주 보상 callable/클라이언트 호출 삭제. 기존 퀴즈 엔진의 공용 문제·기록 어댑터와 관리자 보존 자료는 유지한다.
