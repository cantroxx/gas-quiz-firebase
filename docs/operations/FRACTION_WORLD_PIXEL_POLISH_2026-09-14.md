# 분수 월드 지도·출제·도트 전투 보완

## 변경

1. 지도에서 버튼 위의 모험가/현재 위치 배지를 제거했다. 지금 선택할 단계의 방들을 민트색 테두리로 묶고, 테두리 왼쪽 위의 별도 영역에 `📍 현재 N단계 · 아래 방 중 하나를 골라요`를 표시한다. 보스 단계는 보스 도전 안내를 표시한다. 층 간격을 220px로 늘려 안내와 버튼 영역을 분리했다.
2. 진분수 뺄셈에서 빼는 분자를 앞 분자보다 작게 뽑는다. 모든 뺄셈 유형의 답이 양수인지 검사한다. 저장된 미완료·미채점 문제도 답이 0인 뺄셈이면 같은 유형의 새 문제로 교체한다. 이미 채점한 풀이와 학습 기록은 소급 삭제하지 않는다. 0 자체는 유효한 수이므로 답 검증기의 수학적 동치 판정은 유지한다.
3. 무기 12종의 기술에 각각 네 단계 도트 이미지를 적용했다. 별빛/얼음/번개/운석, 관통 화살/달날/연속 베기/수정 창, 땅울림/사슬/방패/정령을 구분한다. 기술 설명창도 실제 전투와 같은 잘라낸 프레임을 쓴다. 연속 타격 지대·보호막·정령의 표시도 함께 보완했다.
4. 활은 다른 무기의 공통 회전·반동·발사 섬광에서 분리했다. 준비 → 화살 걸기 → 줄 당기기 → 놓기 네 그림을 공격 간격에 맞춰 표시한다. 각 프레임의 손잡이 위치를 보정했다. 일반 화살은 깃·몸통·촉을 구분한 도트 화살이다. 발사 시작점을 활 위치로 맞추고 그 위치에서 적을 향해 조준한다. 특수 기술 `유성 관통`도 두꺼운 광선 대신 큰 화살로 표현한다.

공격력, 공격 간격, 강화 비용, 적 체력·속도·피해는 변경하지 않았다. 활 조준 시작점은 손잡이와 화살 출발 위치에 맞춰 조정했다.

## 검사

- `npm run check`: 정적·도메인·애플리케이션·인프라·분수·Firebase 에뮬레이터 규칙·운영 공개 셸 검사 통과. 마지막 프레임 경계 보정은 브라우저 검사로 재검증했다.
- 분수 18,000문제와 난수 경계값 검사: 뺄셈 답이 모두 양수.
- `scripts/smoke/fraction-world-pixel-polish.js`: 390/600/820/1180 너비, 두 탐험 길이, 첫 단계·다음 단계·보스 단계 24조합에서 현재 층 표시와 버튼의 비겹침 확인. 저장된 0 뺄셈 교체, 12종 기술의 실제 피해·도트 효과·설명 그림 확인. 렌더러 검토용 스크린샷을 열어 잘림과 모양을 확인했다.
- `scripts/smoke/fraction-world-expedition.js`: 24개 무기 성장 분기의 공격·기술, 24방/32문제 전체 흐름, 해금·강화·상점·저장 복원 통과.
- 활 시작 무기로 `fraction-world-playability.js`의 실제 입력 시나리오도 통과했다. 첫 방 체력 87.9, 두 번째 방 65.8, 총 19마리 처치로 두 방 완료. 이 검사는 체력·적·공격력을 고치지 않고 이동·회피·기술을 사용한다.

스튜디오 전용 기능, 다른 게임, Firebase 운영 데이터와 보안 규칙은 변경하지 않는다.
