# 스터디 타운 조작 및 몬스터 선택 후속 수정

이 문서가 같은 날짜의 Adventure v2 문서 중 조작 키와 시작 단계 설명을 대체한다.

- 이동: WASD 및 방향키, 기존 가상 이동 패드 유지.
- 공격: J 및 화면의 공격 버튼. 초보의 꾹 누르기와 난이도별 자동 공격 정책 유지.
- 기술: E. S는 아래 이동으로 사용. 회피 Space, 상태 I 유지.
- 전투장 바닥을 클릭/터치하면 해당 월드 좌표로 이동. 작은 민트색 목적지 표시. 화면의 카메라 이동과 가로 화면 여백을 반영해 좌표 변환.
- 도착하면 정지. 키보드/패드 이동이 터치 목표보다 우선. 메뉴·일시정지·상태창 복귀 시 이동 목표 제거. 길이 막히면 정지하며 자동 경로 탐색은 하지 않음. 미니맵과 화면 밖 여백은 이동 입력 제외.
- 시작 순서: 내 모습 → 내 무기 → 난이도 → 몬스터. 마지막 독립 화면에서 귀여운/전투형 그림 카드를 선택. 외형만 달라지고 난이도·보상은 같음.
- 게임 설명·길잡이·조작 체험·접근성 조작 안내와 키 라벨도 동기화.
- 새 저장 형식이나 초기화 없음. 스튜디오·Firebase 데이터 변경 없음.

## 검증

- `scripts/smoke/fraction-world-touch-movement.js`: 실제 Chrome touchscreen 이벤트, 카메라 좌표와 목표 도착, 터치에서 공격 미발생, WASD 네 방향, J/E 분리, 수동 제어 우선, 일시정지/벽 정지. 1180×820, 820×1180, 390×844, 844×390 검사.
- `scripts/smoke/fraction-world-adventure-v2.js`: 4단계와 몬스터 선택 저장, 기존 세 난이도·부활·보스·상태창·레이아웃 회귀 검사.
- 운영 배포 전 `npm run check` 전체 검사.
