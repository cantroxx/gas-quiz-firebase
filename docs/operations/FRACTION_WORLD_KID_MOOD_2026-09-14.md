# 분수 월드: 4학년용 안내와 게임 분위기 보완

## 적용 범위

균열의 탑의 상점, 유물 안내·조합 도감, 모험가, 몬스터, 별의 파동, 상태창을 수정했다. 스튜디오는 후속 작업으로 유지한다. 학생 데이터, DJ코인, Firebase 규칙·랭킹은 변경하지 않는다.

## 학생이 보는 변화

- 유물 40종과 혼합 조합 10종 설명을 쉬운 행동 중심 문장으로 통일했다. 상점·보물·가방·도감에서 같은 설명을 쓴다. 예: 잿불 씨앗은 “한 번 맞힐 때 더 큰 피해를 줘요.”와 실제 공격력 전후 자연수를 함께 표시한다.
- 일반·비밀 상점 모두 그림 목록 → 선택한 물건의 효과·속성·조합·내 능력 변화 → 가격과 남을 결정 → 구매 확정 순서다. 취소·다른 그림 선택·Escape에는 돈이나 장비가 바뀌지 않는다. 이미 산 물건, 돈 부족, 꽉 찬 가방은 구매를 막는다.
- 특수 도구는 “힘을 더하는 숫돌”, “한 번 더! 별 부적”, “다시 일어나는 부적”으로 안내한다. 속성 조합에 포함되지 않는다는 설명도 표시한다. 방문당 하나, 같은 도구 중복 장착 불가 규칙을 유지한다.
- 조합 도감은 속성 대표 그림, 실제 가진 유물 그림, 빈칸, 몇 개 더 필요한지, 완성 효과를 보여 준다. 상점에서는 고른 유물과 관계있는 조합을 미리 보여 준다.
- 처음부터 고를 수 있는 소년 모험가 **카이 · 별바람 모험가**를 추가했다. 기존 루나도 그대로 고를 수 있으며 모습에 따른 능력 차이는 없다.
- 기존 6종 코스튬의 행 경계를 각각 지정하고, SVG 내부 표시 영역을 별도로 잘라 위·아래의 이웃 그림이 비치지 않게 했다. 전투의 네 가지 포즈에도 같은 소스 영역을 적용했다.
- 일반 몬스터 6종·지역 보스 4종을 새로 만든 귀여운 젤리·구름·동물 계열 그림으로 교체했다. 몬스터 행동·체력·공격·속도는 유지한다.
- 별의 파동에 청록·금빛의 6단계 회전 별빛 이미지를 적용했다. 준비 중에는 얇은 별 테두리가 범위를 알린다. 기술 설명도 가까운 적 공격, 날아온 공격 지우기, 다시 쓸 때까지 기다리기로 나누었다. 기존 피해·범위·대기시간은 유지한다.
- 상태창을 모험가 초상, 체력 바, 무기 강화 별, 큰 능력 숫자, 유물과 조합 도감이 있는 모험가 카드로 바꿨다.
- 전투 캐릭터 그림은 이전 81×108에서 54×70 논리 픽셀로 약 35% 축소했다. 발 위치를 중심에 맞추고 실제 맞는 위치에 작은 원을 표시한다. 신체 충돌 반경 13은 이전과 같고 커지지 않았다.

## 결정 강화와 난이도 보호

새 탐험에 `balance: 2`를 저장하며, 지역 진행에 따라 강화 상한을 연다.

| 지역 | 시작 무기 | 유물 하나당 |
| --- | --- | --- |
| 1지역 | +2 | +1 |
| 2지역 | +3 | +2 |
| 3·4지역 | +5 | +3 |

- 무기 +3 이상과 유물 강화는 강화소에서 한다.
- 결정이 아무리 많아도 지역 상한을 넘을 수 없다. 상한에서 버튼을 막고 다음 지역 안내를 표시한다. 도메인에서도 같은 조건을 검사해 결정을 차감하지 않는다.
- 가격과 단계별 공격력 증가량은 유지했다. 따라서 강화하는 재미를 남기면서 초반에 최종 강화를 몰아서 사는 길을 막는다.
- 기존 저장 탐험에는 상한 변경을 소급하지 않는다. 이미 얻은 장비와 성장은 유지한다. 결정과 강화는 새 탐험에서 초기화되는 기존 규칙을 따른다.
- 이 제한은 초반 경제 과성장을 막는 장치다. 모든 후반 조합의 난이도를 학생 대상 장기 플레이로 검증했다는 뜻은 아니다.

## 검증

- `npm run check`: 정적·도메인·애플리케이션·인프라·분수·Firebase 에뮬레이터 규칙·운영 공개 셸 검사 통과. 마지막 그림 위치 및 SVG CSS 보정은 아래 브라우저 검사로 재확인했다.
- `tests/fraction-world/expedition.test.js`: 200개 전체 탐험, 두 길이·두 난이도, 32문제, 무기 12종의 지역 상한, 무제한 결정에도 상한 유지, 유물 강화 상한, 기존 탐험의 최종 강화 보존.
- `scripts/smoke/fraction-world-expedition.js`: 실제 공격 엔진으로 24개 무기 성장 분기, 24방·32문제 진행, 해금·초기화·상점 구매 저장. 전체 경로 검사는 빠른 진행을 위한 전투 fixture를 사용하므로 난이도 측정이 아니다.
- `scripts/smoke/fraction-world-clarity.js`: 별의 파동 실제 피해와 적 탄 제거, 속성 2→3 조합 미리보기, 안내 및 태블릿 표시.
- `scripts/smoke/fraction-world-upgrades.js`: 기존 탐험의 유물 강화, 결정 차감, 체력 증가, 저장 복원, 조합 완성·풀림, 교체와 전투 전환.
- `scripts/smoke/fraction-world-kid-mood.js`: 두 시작 모험가, 7종 코스튬 표시, 상점 선택·취소·확정·재접속, 돈 부족·가방 가득 참·중복 구매 차단, 도구 3종, 속성·그림 조합, 자연수 능력치, 390/600/820/1024/1180 폭, 새 PNG 투명도, 기술 공격과 상태창 일시정지. 스크린샷을 열어 검토했다.
- `scripts/smoke/fraction-world-playability.js`: 적 체력·피해·플레이어 체력을 조작하지 않고 키보드 입력으로 첫 두 전투 완료. 결과: 1방 체력 76.85(화면 77), 2방 54.75(화면 55), 총 19마리 처치. 움직임·회피·기술을 사용했다. 화면 전체 전투, 터치 이동, 상태창 정지·복귀, 전체화면, 유물 확인창, 다섯 화면 크기 검사도 통과.
