# 스터디 타운: 관리자 체험·전체 초기화·이름 변경

## 사용 방법

1. 같은 브라우저에서 퀴즈타운 관리자 계정으로 로그인한다.
2. 스터디 타운 상단 **관리자 → 퀴즈타운 관리자 연결**을 누른다.
3. 열린 퀴즈타운 확인 창에서 **관리자 계정 확인하고 연결**을 누른다.
4. 지역·단계·방 종류·무기·강화·외형·유물 등을 골라 **이 설정으로 체험하기**를 누른다.
5. 전투 중 **다른 스테이지**로 다시 설정하거나 **체험 끝내기**로 학생 저장 상태에 돌아온다.

관리자 확인은 15분 동안 현재 탭의 메모리에서만 유지된다. 새로고침하면 다시 연결한다. 로그인이 없거나 학생 계정이면 체험 메뉴를 열지 않는다. 팝업이 차단되면 이 사이트의 팝업을 허용해야 한다.

## 관리자 체험

- 기본 24개 방/장기 32개 방 전체에서 지역과 단계를 선택한다.
- 전투, 강한 적, 보물, 강화소, 상점, 회복 샘, 사건, 보스를 직접 선택한다. 보스를 고르면 해당 지역의 보스 단계로 이동한다.
- 해금 여부와 관계없이 무기 12종과 외형을 고르고 무기 +0~+5, 강화 분기, 유물 최대 8개, 체험 결정 0~9999를 설정한다.
- 기본/심화, 로그라이크/코인, 몬스터 모습을 선택한다.
- 진입 문제는 건너뛴다. 실제 전투·상점·보상 코드를 사용한다.
- 체험 중 모든 게임 프로필 쓰기는 메모리 전용 프로필에 적용한다. 저장 칸, 학습 통계, 해금, 기록에 반영하지 않는다. 새로고침하면 원래 학생 저장 상태로 돌아온다.

## 계정 연결

퀴즈타운 Hosting의 별도 연결 페이지가 기존 Firebase 로그인 상태를 사용한다. Firestore 서버에서 현재 authUid에 연결된 users 문서만 조회하여 활성 관리자(role=admin 또는 기존 adminLevel 정책)를 확인한다. 익명 계정을 새로 만들거나 계정 연결을 변경하지 않는다. 학생 데이터 쓰기, 로그인 토큰 전달, 비밀번호 저장, 보안 규칙 변경은 없다.

스터디 타운은 신뢰한 퀴즈타운 origin, 실제 열었던 팝업 객체, 192비트 일회용 nonce를 모두 확인한 연결 응답만 수용한다. 관리자 연결 상태를 localStorage나 URL의 admin=true 값으로 저장하지 않는다. 이 메뉴는 로컬 게임 체험 도구이며 서버 운영 데이터의 관리 권한을 제공하지 않는다.

## 전체 초기화

사용자가 승인한 대로 이전 분수 월드의 저장 칸 3개에 있던 탐험, 스튜디오, 학습 통계, 해금, 도감, 트로피와 기록을 새 게임에 가져오지 않는다.

- 기존 키: `dj48.fraction-world.v1`
- 새 키: `dj48.study-town.v1`
- 업데이트 후 각 기기·브라우저가 다음 접속/새로고침할 때 새 저장 공간으로 시작하고 이전 키를 제거한다.
- 새 저장에 실패하면 이전 키를 지우지 않고 오류 안내를 표시한다. 옛 진행을 불러오지는 않는다.
- 이후 새로고침에서는 새 진행을 유지한다. 예전 탭이 옛 키에 기록해도 새 저장 공간을 덮을 수 없다.
- 퀴즈타운 계정, DJ코인, 다른 게임 localStorage는 초기화하지 않는다.
- 아직 업데이트를 열지 않은 기기의 기록을 원격 즉시 삭제하는 방식은 아니다.

## 이름과 주소

화면 제목·브랜드·로비·내려받기 파일명과 퀴즈타운 게임 진입 카드 이름을 **스터디 타운 / STUDY TOWN**으로 변경한다. 기존 북마크를 유지하기 위해 운영 주소는 https://dj48-fraction-world.vercel.app/ 를 계속 사용한다.

## 검증

- `npm run test:fractions`: 통과. 전체 초기화 1회, 다른 저장 키 보존, 저장 실패 시 기존 값 보존, 새 진행 복원, 관리자 체험 저장 차단 추가 검사.
- `npm run check`: 통과, exit 0.
- `scripts/smoke/study-town-admin.js`: 격리된 Firebase 모의 학생/관리자로 권한 거부·승인, 32번째 보스 즉시 입장, 임의 지역 상점, 문제 생략, 체험 종료/재접속 저장 보존, 이름과 390/820/1180 화면 폭 검사 통과.
- 이 테스트는 실제 교사 계정 비밀번호를 사용하지 않는다. 운영 교사 로그인 확인은 교사가 기존 계정으로 연결하여 수행한다.

## 배포 방식

Vercel은 독립 게임 폴더만 배포한다. Firebase Hosting은 현재 live 버전의 파일과 설정을 복제하고 `/study-town-admin.html` 추가 및 `/battle/index.html`의 이름 문자열만 변경한다. 운영 배포와 다른 미완료 로컬 파일은 섞지 않는다. 배포 전에 모든 나머지 파일 해시·설정이 동일한지, 준비 이후 live 버전이 바뀌지 않았는지 검사한다.
