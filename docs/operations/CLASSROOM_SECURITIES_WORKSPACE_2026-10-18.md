# 증권 학생·교사 작업 화면 개선 — 2026-10-18

사용자가 제공한 그라운드 관리자 5개·학생 3개 화면과 퀴즈타운 현재 화면을 기준으로, 큰 안내·그림 위주 구성을 실제 조회와 운영 작업 중심으로 재구성했다. 기존 동화풍 회사 그림은 작은 식별 이미지로 재사용한다.

## 학생 화면

- 시세 / 뉴스 / 회사 지도 / 내 계좌 / 투자일지의 5개 메뉴.
- 계좌 개설 전에는 의미 없는 잔액 0 세 칸 대신 간단한 시작 안내와 개설 버튼만 표시한다. 개설 여부와 관계없이 회사 목록을 볼 수 있다.
- 계좌 개설 후에는 내 DJ코인, 증권 지갑, 보유 주식의 지금 값, 보유 주식 이익·손해를 작게 요약한다. 보유 주식이 없으면 손익률을 계산하지 않는다.
- 회사 목록은 이름·1주 가격·등락률·보유/뉴스 표시를 담은 작은 카드다. 검색, 가격순, 등락순, 회사 크기순, 내 보유, 가격 움직임순을 지원한다. 열 수는 교실 본문 폭에 맞춰 조절한다.
- 회사 선택 시 목록을 상세 화면으로 전환한다. PC는 가격 그래프와 설명·거래 버튼을 나란히, 모바일은 세로로 표시한다. 뒤로 가면 선택했던 회사 버튼으로 초점이 돌아간다.
- 그래프는 저장된 날짜별 가격을 선으로 표시하고 표도 제공한다. 일중 시가·고가·저가를 저장하지 않는 상태에서 캔들 차트를 만들지 않는다.
- 회사 지도는 현재 가격 × 발행 주식 수에 비례하는 면적을 사용한다. 상승·하락·변화 없음을 색, 화살표, 수치로 함께 표시한다. 회사 선택과 표 보기를 지원한다.
- 내 계좌는 보유 주식 목록과 코인 넣기/꺼내기를 분리한 두 열 구성이다. 보유 주식 손익과 누적 전체 손익의 기준을 구분한다.
- 첫 거래 전에는 시작 가격과 거래 전 상태를 표시하며 비교·거래·그래프를 오해하지 않도록 처리한다.

## 교사 화면

- 교사는 기본적으로 시장 / 회사 지도 / 뉴스 / 기록 / 설정 관리 화면에 진입한다. 개인 계좌 개설 안내를 먼저 보이지 않는다. ‘내 계좌 보기’와 ‘교사 관리’로 전환한다.
- 시장: 운영 시간·뉴스 공개 시각, 일시 중지/재개, 기능 켜기/끄기, 시범 수업 후 학생 공개, 회사 조회.
- 뉴스: 뉴스 목록과 작성 폼을 나란히 배치한다. 초안 수정·예약·발행·정정 기능을 유지한다. 탭 이동 시 작성 중인 폼을 유지한다.
- 기록: 계좌·이용료·입출금 요약, 계좌 목록, 선택한 계좌의 거래와 돌아보기·피드백·읽기 전용 원장 검사 결과, 일별 보고.
- 기존 교실 데이터에 학생 이름/번호가 있으면 계좌 식별자로 표시하고, 없으면 계좌 ID를 사용한다. 추가 학생 정보 조회를 만들지 않았다.
- 설정: 거래 횟수, 주문 수량, 한 회사 비율, 이용료, 뉴스/개장/마감 시각, 휴장일을 카드 형태로 배치한다.
- 이용료와 뉴스 영향은 %로 입력하고 기존 서버의 bp 정수로 변환한다. 기존 허용 범위를 유지한다.

## 범위

가격 엔진, 거래 한도, DJ코인 입출금 정책, 학생 공개 설정, Firestore 규칙, Functions를 변경하지 않는다. 그라운드 화면의 공동체 회사, 배당/세금, 기금 이체, 자동 계좌 복구처럼 현재 백엔드에 없는 기능을 동작하지 않는 버튼으로 추가하지 않았다. 원장 검사는 읽기 전용이다.

## 검증 및 배포

최종 전체 검사와 운영 후보 브라우저 검증이 모두 통과했다. 검증 데이터는 Firebase Emulator의 합성 계좌·코인만 사용한다.

- 전체 검사: `npm run check`.
- 증권 전용 통합 검사: `node scripts/smoke/run-securities-emulators.js`.
- 운영본 기반 후보: 교사/연습 거래 브라우저, DJ코인 브라우저를 각각 실행한다.
- 검증 항목: 거래·입출금 두 단계 확인, 응답 유실/재로드 재시도, 코인 보존, 피드백, 뉴스 발행·영향 1.5% → 150bp, 이용료 0.75% → 75bp, 탭 전환 시 초안 보존, 지도 면적, 개설 전 빈 요약 제거, 역할 전환 지연 응답 격리, 개장 전 상태, 390/768/1440px 가로 넘침.
- 배포 후보는 운영 버전 `48ffec193675b08b`를 기준으로 5개 파일만 교체한다. 나머지 3,974개 파일과 앱의 비대상 모듈 76개는 보존한다. 로컬의 다른 작업은 포함하지 않는다.
- 소스: `public/js/features/securities-render.js`, `public/js/features/securities-server-controller.js`, `public/classroom-securities.css`.
- 배포 준비/검증: `scripts/maintenance/prepare-securities-workspace-release.js`, `scripts/maintenance/publish-securities-workspace-release.js`.
