# 스터디 타운 출발 화면 보완

## 변경

- ‘모험을 준비해요’를 ‘오늘은 내가 모험가!’로 변경하고 기존 최적화 배경·선택 캐릭터·선택 무기로 출발 배너를 구성했다.
- 여섯 단계를 ‘모험 길 / 내 무기 / 내 모습 / 몬스터 / 도전 크기 / 출발!’로 표현했다. 단계별 질문과 짧은 안내를 제공한다.
- 카드에 기존 무기·캐릭터·몬스터·결정 그림을 확대해 배치했다. 탐험 길이는 배경 그림과 24/32 숫자로 구분한다.
- 제목 23~48px, 카드 제목 19~22px, 설명 14~17px 범위로 화면 크기에 맞춰 표시하고 굵기·명도 대비를 높였다. 외부 웹폰트는 추가하지 않았다.
- 현재 단계와 선택한 카드는 금색 테두리 및 체크로 구분하며 aria-current/aria-pressed도 유지한다.
- 잠긴 무기와 모습은 접을 수 있는 ‘나중에 열리는 … 구경하기’ 영역으로 분리했다.
- ‘앞에서 다시 고르기’, ‘이걸로 골랐어! 다음’, ‘좋아, 모험 출발!’ 버튼을 제공한다.
- 난이도별 오답 추가 적 수, 무료 코인 부활, 두 탐험의 총 32문제 정보는 유지한다.
- 이번 변경으로 저장 초기화를 추가 실행하지 않는다. 전투·경제·난이도 수치는 변경하지 않았다.

## 성능

기존 WebP 아틀라스 및 로비에서 사용하던 표지 그림을 재사용했다. 새로운 대형 이미지나 외부 폰트 다운로드를 추가하지 않았다.

## 검증

- 여섯 단계 화면을 캡처해 그림, 제목, 설명, 선택 표시와 버튼을 확인했다.
- 390/820/1180px 화면에서 가로 넘침 없이 단계 선택, 뒤로 가기, 다음 및 실제 탐험 시작을 확인했다.
- 기존 journey 브라우저 검사 통과: 모드 선택, 길잡이, 정답 보너스, 직접 공격, 코인 재도전·새로고침, 저장 문제 교체.
- 최종 배포 전 `npm run check` 결과 확인 후 운영 반영한다.
