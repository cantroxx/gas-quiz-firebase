# 기존 시즌 이벤트 통합 — 운영 배포 보고

## 상태
2026-09-21 운영 배포 완료. 운영 시즌 활성화나 학생 실적·보상 데이터의 직접 변경은 하지 않았다.

## 기준
관리자 > 시즌 이벤트 설계의 기존 이벤트(title/desc/icon/quizIds/기간/활성)를 기준으로 달성 조건과 보상을 추가한다. 별도 고정 8종 월간 구성·리롤 화면을 제거했다. 기존 일일·주간 퀘스트는 유지한다.

## 관리자 흐름
1. 다음 달 초안을 조회한다. 매월 1일 한국 시간 자동 작업이 다음 달 초안을 준비하며, 첫 조회 시 없으면 즉시 생성한다.
2. 리롤은 **다음 달 비활성 초안**의 지정 퀴즈·활동·목표를 바꾼다. 동시에 요청하면 revision 검사로 하나만 반영한다.
3. 편집기에 추가한다. 기존 편집 항목을 덮어쓰지 않으며 최대 6개를 초과하면 추가하지 않는다.
4. 제목/설명/아이콘/월간·주간 기간/지정 퀴즈/활동별 목표/XP/DJ코인을 확인하고 활성화·저장한다.

초안은 연습전 또는 오늘의 퀴즈, 랭킹전, 온라인 2종을 포함한 4개 조건으로 제안한다. 관리자 편집기에서는 8개 활동 중 원하는 조합을 선택할 수 있다. 게임은 스터디 타운·퀴즈 서바이버·마블·구름탑·말폭탄이다.

보상 시즌의 `매월 자동 전환`은 허용하지 않는다. 현재 시즌이 다음 달에 무검토 재개되는 대신 다음 달 **초안 자동 생성 → 확인 후 활성화**를 사용한다. 기존 조건 없는 퀴즈 점수형 시즌의 자동 전환은 유지한다.

## 학생 화면 예시 (예시이며 운영에 저장하지 않음)
‘10월 독서와 함께하는 대전 시즌’, 지정 퀴즈 `gmo, time_store`:

| 조건 | 목표 예시 | 보상 예시 |
|---|---:|---:|
| 지정 독서 퀴즈 연습전 정답 | 20 | XP 30 / DJ코인 20 |
| 지정 독서 퀴즈 랭킹전 정상 완료 | 3 | XP 30 / DJ코인 20 |
| 스터디 타운 정답 | 20 | XP 30 / DJ코인 20 |
| 마블 정상 완주 | 2 | XP 30 / DJ코인 20 |

이벤트 광장과 내 상태는 같은 서버 응답의 시즌 제목·기간·목표·진행도·수령 기록을 사용한다. 보상은 각 조건당 시즌 1회이며 기존 주간 XP 한도·최고 레벨 처리를 따른다.

지정 퀴즈 ID는 연습전/오늘의 퀴즈/랭킹전 조건에 적용한다. 비워두면 전체 퀴즈를 대상으로 한다. 온라인 조건은 선택한 게임의 서버 검증 실적을 사용한다. 활성화 이전 실적은 소급 집계하지 않는다.

## 시즌 랭킹
- 보상 조건이 있는 시즌: 서로 다른 게임의 점수를 합산하지 않고 **달성 조건 수**, 동점 공동 순위로 상위 10명 표시.
- 이벤트 광장/내 상태/시즌 랭킹 탭 모두 동일 집계.
- 기존 조건 없는 지정 퀴즈 시즌: 기존 퀴즈 점수형 순위 유지.
- rankingRecords/userRankingSummary/quizKingSummary 데이터나 일반 퀴즈 랭킹 모드 선택은 변경하지 않는다.

## 기존 기록과 전환
- 잘못 추가했던 독립 월간 퀘스트는 **2026년 9월을 마지막 기간**으로 고정한다. 9월 말까지 해당 월 실적을 보존·집계하며 10월부터 새로운 고정 8종 월간 퀘스트를 만들지 않는다.
- 이전 진행도·지급 기록·미수령 보상은 ‘이전 월간’ 토글에 보존한다. 달이 바뀌어도 9월의 완료 보상 수령이 가능하다.
- 지급했던 XP/DJ코인은 회수하지 않는다. 다음 달 독립 월간 리롤 결과는 새 시즌 초안을 자동 활성화하지 않는다.
- 새 보상 시즌은 활성화 시 서버에 조건을 고정한다. 진행 중 목표·대상·보상 수정은 거절한다.
- 삭제/비활성화는 신규 집계를 중단한다. 이미 완료한 미수령 보상은 보존한다. 중단 시즌은 같은 ID로 재개할 수 없고 새 시즌 ID를 사용한다.

## 저장·권한
- 기존 `appSettings/seasonEvents`: 관리자 편집 설정.
- `seasonEventSystem/registry`: 서버 전용 확정 조건 및 전환 월. 클라이언트 기본 거부 규칙 사용.
- `seasonRewardProgress/{seasonKey}/members/{memberId}`: 집계·수령·달성 수.
- `seasonEventDrafts/{month}`: 다음 달 비활성 초안.
- 관리자 저장과 고정 조건/감사 로그를 트랜잭션으로 처리. 관리자 전용 호출에서 초안 생성·리롤.
- 경기/연습 트리거 기존 중복 방지 안에서 같은 활동을 시즌에도 원자적으로 집계.
- 재시도와 동시 수령을 검증. 별도 보안 규칙 변경 없이 서버 경로만 사용.
- 보호된 시즌 조건은 최대 100개까지 보존하며 한도에 도달하면 자동 삭제 대신 추가를 거절한다.
