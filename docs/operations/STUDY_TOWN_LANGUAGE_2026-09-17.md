# 스터디 타운 4학년용 용어·안내 정리

## 적용

- 회피 → 피하기, 유물 → 보물, 속성 → 보물 종류, 결정 → 결정 코인. 코드 ID와 저장 키는 그대로 유지.
- 도움말 6개 탭을 현재 시작 순서(단원 → 모습 → 무기 → 난이도 → 몬스터)에 맞춰 다시 작성. 삭제된 스튜디오·공연·시즌, 로비 단원 선택 등 오래된 안내 제거.
- 보물 받기 확인 버튼은 ‘가방에 넣고 사용하기’, 구매는 ‘사기’. 조합 완성과 사용 중 구분, 실제 조작 위치인 ‘지도 → 보물·조합 상세’ 안내.
- 최대 체력과 현재 체력 구분, ‘한 방’은 ‘전투방 하나’로 구체화. 보호막·정령 설명은 실제 조건과 효과를 풀어서 표시.
- 얼음 보주의 기술명은 실제 감속 효과에 맞춰 ‘얼음 마법’. 고유 보물·기술명은 유지하고 쉬운 효과 설명 병기.
- 강화 화면은 이번 지역 한도와 현재 비용/능력치 비교를 먼저 표시. 전체 규칙은 접기. 무기 성장 갈래는 공격 행동 중심으로 설명, ‘강해진 공격 미리 보기’로 안내.
- 수학의 분자·분모·도형 명칭은 유지. 서술형 안내는 컴퓨터가 맞고 틀림을 바로 정하지 않음을 쉬운 말로 표시.
- 게임 난이도·보상·학생 데이터·랭킹·저장 구조 변경 없음. v24 캐시 갱신.

## 검증

- 분수/탑/저장/균형 도메인 검사 통과.
- 도움말 6개 탭, 시작 순서, 접힌 강화 규칙, 보물 확인창, 수학 용어 보존, 390/820/1024px 설명창 검사 통과.
- 전용 보완 회귀와 90문항 입력·채점·서술·복원 브라우저 검사 통과.
- 전체 검사와 현행 전투/태블릿 검사 후 운영 배포.

최종 검사: `npm run check` 종료 코드 0. 현행 adventure-v2의 세 난이도 조작·부활, 48개 무기/보스 조합, 5개 화면 크기 검증 통과. 844px 가로 화면에서 ‘피하기’와 기술 이름 표시를 이미지로 확인.
