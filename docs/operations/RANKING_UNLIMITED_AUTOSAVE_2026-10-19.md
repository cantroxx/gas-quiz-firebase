# 인기 퀴즈 랭킹전 무제한 출제·이탈 저장 (배포 완료)

- 요청: 랭킹전 문제 수 제한 제거, 중도 이탈 시 기록 저장, 재입장 시 새 판 시작.
- 과목관은 이미 문제 수 제한 없이 정답별 누적 저장 및 재입장 이전 판 종료를 제공한다. 기존 5분·하트 규칙은 유지한다.
- 인기 퀴즈는 20문제 단위로 새 문제 묶음을 공급하며 하트 소진 또는 종료까지 계속한다. 저장 문서의 문제 배열은 20개로 유지한다.
- 서버가 답안을 수락할 때 rankingRecords, userRankingSummary, quizKingSummary에 최고 기록을 갱신한다. 동일 판의 반복 저장으로 판 수가 증가하지 않는다. 기존 최고 기록과 컬렉션 구조는 유지한다.
- 페이지 이탈은 인증 토큰을 사용한 keepalive 종료 요청을 전송한다. 브라우저 강제 종료 등으로 요청이 누락돼도 답안별 기록은 남으며 다음 입장에서 이전 랭킹전을 종료한다.
- 연습전의 20문제 완료·이어풀기는 유지한다. 정답 0개인 판은 기존처럼 랭킹에 게시하지 않는다.
- 문제 묶음 간 재출제 가능. 기존 시간 제한 없음·하트 3개 규칙 유지.
- 운영 데이터 직접 수정, 보안 규칙 변경, 배포, 커밋은 수행하지 않았다. 반영에는 popularQuizAction Functions와 인기 퀴즈 Hosting의 동시 배포가 필요하다.
