# 분수 월드 이미지 최적화

2026-09-15. 사용자 요청: 느린 이미지 로딩 수정, 중복·과중 이미지 정리.

## 변경

- 표시용 PNG/JPEG를 `assets/optimized-v12/`의 WebP로 전환했다. 일반 일러스트는 품질 88, 크기·투명도 유지. 이미지 좌표가 쓰이는 캐릭터와 시트의 원본 치수는 바꾸지 않았다.
- 무기 기술 12종과 활 자세의 실제 렌더러 출력(4프레임)을 작은 시트 13개로 추출했다. 96×96/96×112 프레임의 RGBA 픽셀이 변환 전후 정확히 같다. 약 5.01MiB 원본 효과 시트 대신 실제 파일 합계 약 0.33MiB를 사용한다.
- 첫 화면에서 전투 효과 시트를 선로딩하지 않는다. 작은 효과 시트는 조합 발동 시 빠짐이 없도록 전투 준비 단계에서 함께 준비한다. 첫 기술 발동 시 원본 알파 픽셀 전체를 순회하던 작업을 제거했다.
- 캐릭터·선택 무기·지역 바닥·몬스터와 효과 이미지는 공통 이미지 캐시를 사용하고 디코딩 완료를 기다린다. 분수 충전 문제 단계에서도 미리 준비한다.
- 전투 화면에서 이미지 준비 중에는 시뮬레이션·시간·체력이 진행되지 않고 조작 입력도 대기한다. 20초 이내 준비되지 않거나 오류가 나면 다시 불러오기·로비 복귀를 제공한다.
- 로딩 중 크기가 큰 옛 캐릭터 시트를 추가로 요청하던 대체 경로를 제거했다.
- 원본 이미지 약 43MiB는 Git에 제작 원본으로 보존하되 Vercel 배포에서 제외한다. 실제 배포용 이미지는 약 7.8MiB다. 사용하지 않는 `actors-v1`, `hero-motion-v2`, `boss-combat-v2`, `bosses-v1`과 옛 대형 도트 시트를 별도 배포하지 않는다.
- 새로운 버전 이미지 URL에는 1년 immutable 캐시를 지정한다. 이후 그림을 수정할 때는 버전 디렉터리도 바꿔야 한다. 기존 열린 탭은 새로고침해 새 파일 경로를 적용한다.

## 검증

- 모든 일반 이미지의 치수와 알파 채널 보존 확인.
- 작은 효과 시트 13개의 RGBA 바이트가 기존 렌더러 출력과 정확히 일치.
- `fraction-world-image-loading.js`: 이미지 요청 지연 중 시간·체력·키 입력 정지, 이미지 준비 후 전투, 로딩 실패와 재시도, 첫 로비 효과 시트 미요청, 원본 PNG/JPEG 미요청.
- `fraction-world-tactics.js`: 패링·별방패·독·저장 재개·태블릿 크기 5종·음악 12편곡 통과.
- `fraction-world-pixel-polish.js`: 지도 위치 안내·0 결과 문제 교체·무기 기술 12종·활 자세 통과.
- `fraction-world-expedition.js`: 24개 성장 계열·24방/32문제·강화·상점·재개 통과.
- `npm run check`: 전체 필수 검사 통과.

## 제작 재현

로컬 정적 서버 5478을 실행하고 `node scripts/maintenance/fraction-world-export-pixels.js`로 기존 렌더러 커밋 `ba29d4b`의 프레임을 추출한다. 이후 Pillow가 있는 Python에서 `python3 scripts/maintenance/fraction-world-optimize-images.py`를 실행한다. 도트 시트를 다시 생성하려면 개발용 원본 PNG가 필요하므로 운영 사이트가 아닌 로컬에서 실행한다. `manifest.json`에 파일별 변환 용량을 기록한다.

전투 밸런스와 저장 데이터 구조는 변경하지 않았다.

## 운영 배포 확인

- 구현 커밋 `c47e981`, Vercel `dpl_NoGDPsJjh2oc4z83VCJt71nN3Xer`, 운영 alias 반영 완료.
- 운영 변경 파일 42개가 로컬과 바이트 단위로 일치했다.
- WebP 실제 응답 헤더 `public, max-age=31536000, immutable` 확인. 옛 대체 캐릭터 PNG는 운영에서 404로 제외 확인.
- 운영에서도 이미지 준비 중 전투 정지·키 입력 대기·실패 후 재시도·첫 로비 효과 미요청 검사를 통과했다.
- 동일 5Mbps 조건 운영 실측: 첫 로비 5.46초, 선택 3.81초, 지도 2.78초, 첫 전투 2.86초. 배포 직후 CDN 초기 응답 시간도 포함된 단일 측정이다. 재접속 로비 1.55초, 탑 재진입 0.86초이며 이미지 본문 추가 전송은 없었다.
- 전체 필수 검사는 모든 항목의 통과 로그를 확인했다. 마지막 공용 브라우저 검사 완료 후 Node 정리 프로세스가 종료되지 않아 해당 작업 프로세스만 별도로 종료했다. 이미지 전용 운영 검사는 종료 코드 0을 확인했다.
