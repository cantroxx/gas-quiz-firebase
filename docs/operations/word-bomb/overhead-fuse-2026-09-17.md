# 머리 위 폭탄 전달·도화선 소모

- 폭탄을 머리 위로 이동하고 두 번 튀며 다음 참가자의 머리 위로 전달한다. 높은 궤적이 잘리지 않도록 경기장 상단 공간을 확보했다.
- 이미지 생성으로 기존 폭탄의 도화선을 제거한 몸체를 제작했다: `public/word-bomb/assets/bomb-body-v6.png`. builtin 프롬프트: `docs/product/WORD_BOMB_BODY_V6.json`.
- 도화선은 이미지 위에 별도 SVG 경로로 그린다. 서버 시각에 보정된 실제 남은 차례 시간 비율만큼 경로를 남기고, 불씨를 경로 끝에 배치해 폭탄 쪽으로 타들어오게 한다.
- 다음 차례는 새 도화선으로 초기화. 투표 중에는 타이머와 도화선 길이, 불꽃·연기를 함께 정지한다. 마지막 3초에는 불꽃과 연기가 빨라진다.
- 움직임 줄이기에서는 흔들림·불꽃 반복·연기를 멈추지만 도화선 길이로 남은 시간은 계속 알린다.
- 서버·게임 규칙·학생 데이터 변경 없음. 화면 파일과 새 이미지에 한정한 업데이트.

검증: 8인 Chrome에서 머리 위 배치, 비겹침, 도화선 시간별 감소·차례 초기화, 25키프레임 전달, 모바일 내부 스크롤 확인. 기존 게임 smoke와 온라인 투표 중 도화선 정지 검증 수행. 전체 검사는 `/tmp/word-bomb-v6-check-Hp6o0l`의 동일 소스 복사본에서 포트만 분리하여 실행한다.
