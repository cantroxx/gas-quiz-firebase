# 말폭탄 소품·손 전달 개선

- builtin 이미지 생성으로 무광 짙은 회색의 입체 폭탄 소품을 새로 제작했다. 원본은 `public/word-bomb/assets/bomb-v5.png`, 프롬프트는 `docs/product/WORD_BOMB_PROP_V5.json`.
- 기존 보라색 SVG 폭탄과 큰 카운트 링을 실제 출력에서 제거했다. 사람 캐릭터의 손 위치를 기준으로 폭탄을 배치하고, 얼굴을 가리지 않도록 작은 시간 배지를 옆에 표시한다.
- 실제 캐릭터 이미지의 크기를 기준으로 전달 시작·끝 좌표를 계산한다. 낮은 두 번의 바운스와 착지 압축·복원을 적용했다.
- 마지막 3초에는 작은 흔들림과 불꽃 변화. 폭발은 손 위치에서 짧은 연기·빛으로 표시하고 캐릭터가 가볍게 움찔한다. 움직임 줄이기 설정을 존중한다.
- 규칙·서버·사전·캐릭터·학생 데이터는 변경하지 않았다.

검증: 기존 봇·타임아웃·재시작·모바일·움직임 줄이기 Chrome 검사 통과. 8인 화면에서 손 높이·중앙 정렬·배지 비겹침·링 제거·25키프레임 전달 검사 통과. 전체 `npm run check`는 동일 소스 복사본 `/tmp/word-bomb-v5-check-1mHhrl`에서 포트만 분리하여 통과했다. 로그 `/tmp/word-bomb-v5-full-check.log`.
