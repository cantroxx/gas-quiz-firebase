# 말폭탄 8인·사람 캐릭터 업데이트

후속 상태: 아래 보류 사항은 해소되었다. 16종 캐릭터 확장과 함께 전체 검증을 통과하고 운영 배포 완료. 최신 기록은 `sixteen-characters-2026-09-16.md` 참조.

## 변경

- 방과 도메인 정원을 2~8인으로 확대. 봇 연습도 최대 7명 지원.
- 현실적인 비율의 사람 캐릭터 8종을 builtin 이미지 생성으로 제작. 의자에 앉은 전신을 4×2 투명 PNG 스프라이트로 사용.
- 대기실에서 각 참가자가 캐릭터를 선택한 뒤 준비. 다른 사람이 고른 캐릭터는 선택 불가. 서버 트랜잭션에서 중복·범위·경기 시작 후 변경을 차단. 캐릭터 변경 시 준비 상태 해제.
- 방 생성·입장 시 미선택(null) 상태이므로 8명이 모두 들어온 뒤에도 각자 남은 캐릭터를 고를 수 있다. 연습은 선택한 캐릭터를 중심으로 봇에 나머지 캐릭터를 배정.
- 실제 인원만 한 줄에 표시. PC는 넓은 경기장, 모바일은 경기장 내부 가로 스크롤. 현재 낱말과 입력창은 고정된 페이지 폭 유지. 차례 변경 시 활성 참가자 위치를 표시.
- 폭탄은 25개 키프레임의 두 번 튀는 전달 경로. 마지막 사람부터 첫 사람으로의 순환, 탈락자 건너뛰기 유지. 움직임 줄이기 설정 존중.
- 8인 제안 투표는 제안자 제외 7명 중 4명 동의. 기존 사전·타이머·점수 규칙 유지.
