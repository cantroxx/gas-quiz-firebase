# 말폭탄 시작 모드 정리 (v7)

- 어떻게 놀까요: `친구랑 해요 / 챌린지 / 봇과 대전` 세 가지 진입점.
- 친구랑 해요: 기존 normal 규칙, 폭탄 카운트·시작 하트, 방 만들기·참가·재입장. 캐릭터는 온라인 대기실에서 선택.
- 챌린지: 친구 전용, 폭탄 카운트·전체 경기 시간. 봇 시작 동작도 차단하며 시작 화면에 캐릭터를 표시하지 않음.
- 봇과 대전: normal 규칙만 사용. 폭탄 카운트·시작 하트·봇 1~7명·캐릭터 선택·전용 시작 버튼.
- 서버의 기존 모드 키와 방 데이터 구조는 유지. Functions, 보안 규칙, 학생 데이터 변경 없음.
