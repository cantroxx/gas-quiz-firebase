사용자 선택: 연출·봇 응답만 빠르게, 제한 시간 유지.

- 시작 설정에 1/1.5/2/3배 선택 추가. 기본·기존 방은 1배.
- options.speed는 서버 settings에서 허용된 숫자만 정규화한다. 친구 방에서는 방장이 생성 시 선택한 값을 모두 공유한다. 경기 도중 개인별 배속 변경은 없음.
- 실제 차례 전달 대기는 1000/speed ms로 단축(정수 반올림). 폭탄 비행과 착지, 폭발의 짧은 효과, 봇 생각 시간에 같은 배속 적용.
- 학생 입력 제한 시간, 챌린지 전체 시간, 제안 투표 20초, 시작 전 준비 3초는 유지. 도화선·긴급 카운트 표현도 실제 남은 시간에 맞춤.
- 움직임 줄이기 설정 유지. 기존 10만 단어·한방·투표·8인 규칙 유지.
