# 한방 낱말 허용 옵션 (v9)

- 친구랑 해요/챌린지/봇과 대전 공통으로 한방 단어 제한·허용을 선택한다.
- 정규화된 options.allowOneShot은 boolean true만 허용하며 기본값 및 구버전 방은 false다.
- 허용 시 사전의 산기슭·부엌 등을 정상 인정하고 점수 +10, 차례 전달 및 도착 후 전체 카운트를 보장한다. 남은 낱말이 없으면 기존 새 시작 낱말 절차를 사용한다. 챌린지 전체 종료 시각은 변경하지 않는다.
- 봇의 후보 및 힌트도 같은 옵션을 사용한다. 이미 허용된 사전 단어는 불필요한 제안 대신 제출을 안내한다.
- 서버 사전 외 단어, 중복, 틀린 첫 글자 및 금지 표현 제한은 유지한다.
- 도메인 17개 테스트 통과: 기본 제한, 일반/챌린지 각각 산기슭·부엌 인정, 새 낱말, 차례·하트·점수·시간 검증.

## 약 10만 단어 확장 조사

현재 실제 적용은 10,001개다. 보관 중인 NIKL 기초 어휘 XLSX에서 추출한 두 글자 이상 명사는 26,152개로, 이 자료만으로 10만 개를 채울 수 없다.

공식 우리말샘은 100만 어휘로 출발했으며 신어·방언·전문 용어 등을 포함한다. 명사 중심의 더 큰 사전을 구축할 자료 규모가 있다. 실제 필터링 뒤 고유 표기 수를 세어야 최종 수량을 확정할 수 있다.

- 소개: https://opendict.korean.go.kr/service/helpList
- 저작권: https://opendict.korean.go.kr/service/copyrightPolicy (별도 표시 없는 자료 CC BY-SA 2.0 KR, 출처 및 동일조건 배포 준수)
- 표준국어대사전 API: https://stdict.korean.go.kr/openapi/openApiInfo.do (인증 키 필요, 품사 등 조건 검색 제공)

추천 구현: 공식 내려받기 원본 → 명사·한글 두 글자 이상·중복 제거·교실 부적절 표현 제외 → 출처/라이선스 및 재현 빌드 기록 → 고유 표기 약 10만 개. 뜻풀이·용례·이미지를 복사할 필요 없음. 방언/옛말/북한어·고유명사 포함 기준을 구분하고, 봇·힌트는 기존 쉬운 목록을 우선 사용하도록 분리하는 것이 적합하다. 매 입력에 외부 API를 호출하지 않고 서버/브라우저 동일 버전 목록으로 판정해야 5초 경기의 지연을 피할 수 있다. 10만 개 사전은 이번 변경에 포함하지 않았으며 별도 원본 확보·정제·성능 검증이 필요하다.

검증 결과: npm run smoke:word-bomb 및 check:word-bomb-online 통과. 친구 방 allowOneShot 저장과 대기실 표시 확인. npm run check는 첫 실행 마지막 운영 홈페이지 접속만 시간 초과, 동일 소스 재실행으로 전체 통과(/tmp/word-bomb-v9-full-check-retry.log). 재실행 명령의 자동 승인 검토도 한 차례 시간 초과했으나 허용된 1회 재시도로 실행 완료.
