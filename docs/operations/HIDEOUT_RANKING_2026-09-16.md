# 아지트 랭킹 화면 개편

## 로컬 반영

- 랭킹 광장의 `온라인 대전`을 `아지트 랭킹`으로 변경. 분야 순서는 스터디 타운, 퀴즈 서바이버, 두근두근 마블, 타닥타닥 구름탑이다.
- 낱말 대전·특산물 마블·특산물 대상인의 랭킹 주입 스크립트를 메인 페이지에서 제외했다. 게임 및 기존 저장 기록은 변경하지 않았다.
- `public/js/hideout-ranking-plaza.js`가 네 분야를 구성하고 공통 `DJ48RankingRender`를 사용한다. 상위 3명 카드와 이후 목록에 프로필 이미지, 한마디, 레벨 훈장, 등급, 칭호를 표시한다. 계정 연결이나 프로필이 없는 기록은 저장된 이름과 분야 아이콘으로 표시한다.
- 공개 제외 회원 필터, 공동 순위, 분야별 지연 조회, 새로고침, 오류/빈 기록 안내, 로그아웃 시 캐시·늦은 응답 폐기, 재렌더 시 선택 유지 및 마블 결과의 랭킹 바로가기를 적용했다.

## 읽기 경로

| 분야 | 기존 기록 경로 | 정렬 |
| --- | --- | --- |
| 스터디 타운 | `studyTownAction({action: 'list', tier})` | 서버의 `rank` 유지. 초보/중수/고수별 보스→방→첫 정답률→정답 수 |
| 퀴즈 서바이버 | `mathsurvivorRanking` | `bestScore` 내림차순, 동점 공동 순위 |
| 두근두근 마블 | `townMarbleRanking/town-v1/entries` | `total` 내림차순, 동점 공동 순위 |
| 타닥타닥 구름탑 | `cloudTowerRanking/cloud-120-v1/entries` | 기존 `sortKey` 내림차순, 동일 키 공동 순위 |

스터디 타운 서버/게임 연결은 동시 진행 중인 별도 작업의 구현을 사용한다. `list` 응답의 `memberUserId`로 기존 프로필 로더와 결합한다. UID 기반인 서바이버·구름탑은 `presence/{uid}.memberUserId`를 조회 힌트로만 사용하고 `users/{memberUserId}.authUid` 일치를 확인한 경우에만 프로필을 붙인다. 비공개 `authLinks` 조회나 다른 회원의 `users` 목록 쿼리를 추가하지 않았다. 이 화면 개편에서는 학생 기록·규칙·Functions를 수정하지 않았다.

## 검증

- `npm run check:static` 통과.
- `node scripts/smoke/hideout-ranking-browser.js` 통과: 합성 데이터로 네 분야/난이도, 프로필 카드, UID 연결 검증, 공동 순위, 빠른 난이도 전환, 재렌더, XSS, 오류 재시도, 로그아웃 중 늦은 응답, 1440/390px 화면 확인.
- `node scripts/smoke/profile-performance-browser.js` 통과: 숨긴 분야 조회 없음, 선택한 분야만 조회, 새로고침 및 프로필 화면 회귀 확인.
- `SMOKE_PUBLIC_ONLY=1 npm run smoke:browser` 통과. 운영 공개 화면의 회귀 검사이며 이번 로컬 개편의 배포 확인은 아니다.
- 전체 `npm run check`는 도메인·애플리케이션·인프라·분수·피자 검사까지 통과했으나, 동시 작업 중인 말폭탄 테스트의 오류 문구 기대값 `/한방/` 불일치로 중단됐다. 별도 규칙 검사도 기본 에뮬레이터 포트 사용 중으로 시작하지 못했다. 다른 작업의 프로세스를 종료하거나 해당 게임을 수정하지 않았다.
- 기존 마블 온라인 브라우저 검사의 랭킹 부분도 새 통합 화면을 사용하도록 갱신했다. 그 게임 전체 에뮬레이터 검사는 이번 작업에서 재실행하지 않았다.

초기 로컬 검증 이후 사용자 배포 승인으로 독립 에뮬레이터 포트에서 전체 검사를 통과하고 운영에 반영했다. 최초 배포는 버전 `aef7f1ec15cc53bc`, release `1789541807596000`이며 다른 373개 파일을 보존했다. 커밋·푸시는 하지 않았다.
