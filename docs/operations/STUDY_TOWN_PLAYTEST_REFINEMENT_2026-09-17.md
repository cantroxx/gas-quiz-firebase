# 스터디 타운 직접 플레이 후 보완

## 반영 범위

1. 문제 채점·해설 화면에서 현재 번호 유지. 마지막 답안이 4/3으로 보이던 오류 수정. 저장 후 새로고침한 해설도 같은 번호 유지.
2. 유물의 지금 얻는 힘, 장착 뒤 능력치, 잠긴 속성 조합 효과 분리. 의미 없는 특별한 효과 안내 제거.
3. 조합 지도는 특정 유물 예시 대신 속성 문양, 내 가방 개수, 남은 개수 표시. 가까운 조합 우선, 완성과 사용 중 구분.
4. 길잡이는 짧은 한 줄과 접는 도움말. 지도·보상 상단 여백 축소, 태블릿 보상 카드 정리.
5. 피격 중 캐릭터를 숨기지 않고 밝기·투명도 변화와 짧은 잔상 사용. 내 피해에 하트와 별도 색·위치 적용. 충돌 범위·무적 시간은 그대로.
6. 기술 버튼은 기존 최적화 무기 그림, 기술 이름, 재사용 시간 표시. 이미지 추가 다운로드 없음.
7. 전투 입장 시 실제 정답 보너스가 있는 방에만 +6 안내. 전투 보상과 보물방 무료 유물 안내 구분. 새 유물 등록 알림·최근 발견 우선 진열, 수학 도장 획득 표시·최근 공부한 단원 강조.

- 90문항 브라우저 입력/채점/서술/복원 검사 통과.
- 캠프·도감·수첩·단원 고정·3개 화면 크기 검사 통과.
