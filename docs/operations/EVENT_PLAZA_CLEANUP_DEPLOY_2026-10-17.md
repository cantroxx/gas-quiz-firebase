# 이벤트 광장 정리 운영 배포

2026-10-17, 사용자의 `배포 진행` 요청으로 Firebase Hosting에 반영했다.

## 변경 내용

- 일일·주간 초기화 및 시즌 조건 설명 영역 제거.
- 오늘의 퀘스트를 기본 펼침 상태의 토글 버튼으로 변경. 키보드 조작과 상단 바로가기에서도 펼칠 수 있다.
- 새로고침 옆 `미수령 보상 (건수)` 버튼 추가. 이전 월간 퀘스트 중 `claimable && !claimed`인 항목을 팝업으로 표시하고 기존 수령 호출에 연결한다.
- 팝업의 닫기·Escape·화면 이탈 닫기·초점 복귀, 수령 후 목록 및 건수 갱신, 빈 상태를 처리한다.
- 보상 지급 정책·Firestore 데이터·Rules·Functions·Hosting 설정은 변경하지 않았다.

## 배포 범위

운영본을 복제하고 파일 5개만 갱신했다. 다른 Hosting 파일 3,780개와 설정의 동일성을 검사했다.

- `/index.html`: 퀘스트 제목 부분과 CSS·번들 캐시 버전만 변경.
- `/plaza-views.css`: 이벤트 광장 관련 규칙만 변경. 로컬과 운영본의 랭킹 스타일 순서 차이는 배포에서 제외.
- `/js/features/event-render.js`, `/js/features/event-controller.js`: 이번 UI 변경을 반영.
- `/js/app.bundle.js`: 운영 번들의 위 두 모듈만 교체. 두 모듈을 제외한 내용의 동일성을 검사.

다른 미커밋 변경은 포함하지 않았으며 직전 상점 정리 배포도 보존했다. 전체 로컬 파일과 운영 파일의 동일성을 의미하지 않는다.

## 검증

- `npm run check` 전체 통과.
- 실제 배포 후보에 `EVENT_PUBLIC_DIR`를 지정하여 `season-quest-browser.js`, `event-loading-browser.js` 통과.
- 토글·키보드·바로가기·미수령 건수·수령 버튼 전달·수령 후 갱신·빈 상태·초점 복귀·계정 전환·화면 이탈·1440/390/320px 화면 검사.
- 기존 로딩·캐시·중복 새로고침 병합·실패 후 재시도·이전 계정 응답 차단 검사.
- 배포 후 live 버전, 전체 파일 목록, 변경 파일 5개의 공개 응답 해시 확인.
- 운영 공개 로그인 화면과 직전 상점 제목 보존 확인. 배포된 이벤트 화면에서 표시 전용 합성 데이터로 토글·팝업·닫기·모바일 배치 및 페이지 오류 없음 확인.
- 실제 학생 계정으로 로그인하거나 운영 보상을 수령하지 않았다.
