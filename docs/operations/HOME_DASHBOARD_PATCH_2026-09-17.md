# 내 집 기본 화면 패치

사용자의 “상점보다 내집을 먼저 구현하고 패치부터” 요청에 따라 기존 나의 마을 수첩을 내 집의 기본 화면으로 복원했다.

- 기존 `dj48HomeViewStyle` 값과 관계없이 내 집 입구는 `showHomeView`를 호출한다.
- 내 집의 하보 `우리집 꾸미기` 링크를 제거했다.
- 최신 운영 버전 `7039b0ad888e3e4b`의 index.html 두 부분만 수정했다. 상점 제작 변경은 배포하지 않았으며 다른 406개 파일과 Hosting 설정을 보존했다.
- 배포 버전 `6b89b0ebd8c42955`, 릴리스 `1789617390416000`.
- 전체 `npm run check` 통과. 최초 검사에서 테스트의 고정 포트와 독립 Emulator 포트가 달라 실패해 복사본의 테스트 포트를 맞춘 뒤 다시 전체 통과했다.
- 배포 후보 브라우저에서 닉네임/비밀번호 패널과 모바일 가로 넘침 없음 확인. 기존 room/dashboard/미설정 선호값 모두 새 내 집으로 연결되는 것을 확인했다. 회원 데이터는 합성 fixture를 사용했다.
- 학생 데이터·보유 가구·구매 기록·Functions·보안 규칙은 변경하지 않았다.
