## Codex에서 게임별로 작업하는 방법

각 게임은 해당 폴더를 별도 Codex 프로젝트로 열어 작업하는 것이 안전하다.

예시 요청:

- “`battle-school`에서 직업 시스템을 설계하고 현재 구조와 충돌 여부부터 분석해줘.”
- “`kbo-owner`에서 FM 느낌을 높일 기능을 제안하고 엔진 영향도를 확인해줘.”
- “`math-escape`에서 다음 문제 묶음을 검수하고 정답 검사도 갱신해줘.”
- “퀴즈 서바이버 복구 브랜치와 `main`의 차이를 검토하고 병합 계획만 보고해줘.”

작업 시작 시 Codex는 상위와 프로젝트별 `AGENTS.md`, 이 보고서, 상세 재개 메모를 기준으로 현재 Git과 다시 대조해야 한다.
