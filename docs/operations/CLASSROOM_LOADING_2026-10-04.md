# 교실 로딩 개선

2026년 10월 4일, 별도 교실 작업이 끝난 뒤 상태를 확인하고 로컬 로딩 개선을 진행했다. 기존 내부 탭 개편과 학생 이미지 선택을 유지한다. 최초에는 로컬 수정으로 완료했고, 후속 사용자 요청으로 운영 배포까지 완료했다. 아래 후속 배포 기록을 참고한다.

## 작업 재개 확인

‘내 교실 페이지 종합 검토’ 채팅의 마지막 작업이 완료되고 idle인 것을 확인했다. `CLASSROOM_INTERNAL_TABS_2026-10-04.md`에 기록된 내부 9개 탭 개편과 Hosting 버전 `8a90edde72dd8b1e`가 최신 완료 이력이다. 공개 `classroom-workspace.js`를 읽어 로컬과 바이트 일치도 확인했다.

기존 수정 파일을 `/tmp/classroom-loading-20261004/before/`에 보존한 뒤 기능 단위로 편집했다. 기존 WIP를 되돌리거나 작업 트리 전체를 배포하지 않았다.

## 변경

- 설정·진행도·지갑·학생 목록 등이 준비될 때마다 읽기 전용 홈 미리보기에 전달한다. 포인트·퀘스트·학생 목록은 느린 경제 게시판과 별도로 먼저 표시할 수 있다.
- 아직 조회하지 못한 영역은 0원·활동 없음 대신 ‘불러오는 중’으로 표시한다. 실패한 공급자의 대체값은 부분 표시 대상에 포함하지 않는다.
- 젬 정보는 권한이 확인된 경제 응답의 카탈로그와 병합한 최종 모델에서 표시한다. 앞서 해결한 카탈로그 직접 조회 권한 오류를 다시 만들지 않았다.
- 미리보기는 프레임당 한 번으로 합치고, 캐시로 모든 응답이 빨리 끝나면 취소한다. 모든 데이터가 준비될 때 기존 전체 렌더러를 한 번 실행한다. 새로고침에서는 이전 정상 홈을 유지한다.
- 부분 표시 중에는 기존처럼 조작을 잠그며, 안내 문구와 흐린 버튼으로 상태를 보여준다. 모든 조회가 완료된 뒤의 권한·구매·보상 처리 흐름을 유지한다. 이번 변경은 전체 조회 완료나 버튼 사용 시점을 앞당기는 변경은 아니다.
- 설정 조회에도 진행 요청 공유를 적용한다. 같은 데이터의 강제 동시 조회를 합치고, 화면 갱신 중 연속 새로고침은 후속 갱신 한 번으로 합친다.
- 캐시 무효화 세대와 회원을 확인해 오래된 응답·오류가 새 캐시나 화면을 덮지 못하게 한다. 회원 전환 때 설정 캐시도 비운다. 이전 조회가 끝나기를 기다리지 않고 새 회원 화면을 준비한다.
- CSS·번들 버전을 갱신하고, 새 로딩 검사를 기존 `npm run check` 경로에 포함했다.

서버 함수·보안 규칙·데이터 스키마·운영 학생 기록은 변경하지 않았다. 앞서 수정한 독립 코디 상점 병렬 로딩도 그대로 보존했다.

## 검증

- `npm run check` 전체 통과. 로그: `/tmp/classroom-loading-20261004/check.log`.
- 기존 교실 UI 검사에서 학생/교사 76개 화면 크기·탭 조합, 검색·필터·상품 선택/구매 위임·환전 미리보기·사진/아바타 선택 회귀 검사 통과.
- `tests/classroom/loading.test.js`: 강제 동시 조회 공유, 무효화 후 늦은 응답 차단, 설정 요청 공유, 실패 값의 부분 표시 제외, 설정 대기 중 세션 변경 후 조회 중단.
- `scripts/smoke/classroom-loading-browser.js`: 실제 HTML의 진입 함수와 실제 렌더러로 부분 표시, 미확인 잔액 숨김, 대기 중 조작 잠금, 연속 갱신 병합, 기존 홈 유지, 계정 전환 후 오래된 응답 차단, 조회 실패와 재시도 안내 검증. 외부 네트워크와 서버 동작은 모두 합성 응답으로 대체한다.
- 전체 검사 후 로딩 안내 문구와 대기 버튼 표시를 소폭 보완했고, 정적 검사·로딩 단위/브라우저 검사를 다시 실행했다.
- 모바일 부분 표시 캡처: `/tmp/classroom-loading-20261004/partial-home.png`.

설정 30ms, 일반 조회 30ms, 경제 조회 600ms의 합성 시나리오에서 포인트·퀘스트 데이터가 63ms에 부분 표시 경로로 전달되고 전체 모델은 632ms에 완료됐다. 이는 공급자 지연을 인위적으로 설정한 모델 준비 시간이며 실제 운영 응답 시간이나 브라우저 그리기 시간은 아니다.

## 남은 범위

경제 게시판의 큰 응답·서버 순차 조회, 학생별 레벨 문서 후속 읽기, 최초 폰트·배경 전송량, 독립 게임 이동 시 앱 재초기화는 이번 변경으로 제거되지 않는다. 교실의 전체 사용 가능 시간을 줄이려면 인증된 실제 지연을 측정하고 탭별 데이터 의존성 및 서버 조회를 추가로 분리해야 한다. 데이터·권한 영향이 있는 서버 변경은 별도 영향 검토와 승인 범위에 따른다.
