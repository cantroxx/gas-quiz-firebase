## 검증 명령

```sh
npm run check
npm run test:fractions
npm run smoke:fractions
```

`check`에 분수 도메인·밸런스·저장 검사를 편입했고, 기존 정적 검사에 새 게임 JS를 포함했다. `smoke:fractions`는 임시 로컬 HTTP 서버를 직접 시작하고 종료한다. Chrome 기본 경로는 macOS 설치 경로이며 `SMOKE_CHROME_PATH`로 변경 가능하다.

별도 전투 패턴 검사는 정적 서버가 필요하다.

```sh
python3 -m http.server 5478 --directory public
# 다른 터미널
npm run smoke:fractions:combat
```

다른 서버는 `FRACTION_BASE_URL`로 지정한다. 합성 데이터만 사용하는 로컬 테스트다.

## 검증 근거

- 6유형 × 3,000개 = 18,000문제의 산술·범위·가분수/대분수 정답·잘못된 입력 검사.
- 6무기 각각 24방의 유물 선택·교체·용량·최종 완료 도메인 전이 검사.
- 28일 일정·공연·이벤트 전이, 비용 순서, 중복 구매, 피로에 따른 성장 감소, 단조로운 전략 실패 검사.
- 두 난이도에서 실제 허용 명령만 사용한 28일 성공 경로를 `tests/fraction-world/season-witness.json`으로 보존. 최고 난이도에서도 네 공연 모두 성공할 수 있다. 성공 예시는 자동 탐색으로 찾았으며 일반 학생이 같은 난이도로 느낀다는 의미는 아니다.
- 저장 칸 분리, 게임 복구, 일부 필드 손상, JSON 파손, 저장 용량 오류 검사.
- 브라우저에서 최고 난이도 28일 시즌을 실제 일정·의상·곡 선택 버튼과 184문제 답 입력으로 완료. 중간 계산 닫기/새로고침/재개, 오답·그림 힌트, 기록 확인.
- 브라우저 전투 이동·회피·특수 기술, 일시 정지·새로고침 체크포인트, 실제 브라우저 터치 이벤트의 이동 패드 pointer capture/release.
- 별도 합성 전투에서 네 보스와 돌진 적의 3회 이상 반복 공격, 마지막 보스 소환, 실제 투사체 처치→보상, 최종 클리어 기록 중복 방지, 충돌 패배 확인.
- 1180×820 기본 화면과 820×1180, 1024×768, 600×960 뷰포트에서 가로 넘침 검사. 로비·육성·전투 스크린샷 시각 확인.

실제 학생 플레이·실물 태블릿 검증은 아직 시행하지 않았다. 브라우저 검증은 Chrome의 터치 에뮬레이션이며 iPad Safari 자체 검증이 아니다.

## 운영 변경 범위

초기 구현 단계는 로컬에서 완료했고, 후속 사용자 승인으로 GitHub commit/push와 Vercel 배포를 실행했다. Firebase Hosting 배포, Functions/Rules 변경, 운영 학생 데이터 수정, 랭킹/코인 연동은 수행하지 않았다.

학생에게는 위 Vercel 주소를 제공할 수 있다. Firebase 퀴즈타운 자체에도 반영하려면 Hosting을 별도 배포해야 한다. 동일 작업 트리에 기존 낱말대전 변경이 있으므로 배포 전 포함할 파일을 점검해야 한다. 이번 작업에서는 기존 낱말대전 파일을 수정하지 않았다.

## 알려진 제품 범위

- 세피리아 원작 규모의 상용 콘텐츠를 복제한 게임이 아니라, 자체 그림과 규칙을 가진 24방 수학 액션 캠페인이다.
- 게임 진행은 기기 내 저장이며 Firebase 계정 동기화/교사 집계/멀티플레이는 구현하지 않았다.
- 학습 수첩 내려받기는 기록 보고서이며 저장 복원 파일이 아니다.
- 시설·실력은 시즌 안에서 성장한다. 새 시즌은 초기 예산과 능력으로 시작하고 이전 결과는 별도 기록에 남는다.
- 외부 폰트·이미지·게임 자산을 다운로드하지 않았다. 그림은 SVG/Canvas 코드, 소리는 선택적 합성 효과음이다.

## 학생 플레이 피드백 반영 — 전투·육성 개편

- 균열의 탑: 입장 문제를 3개 방마다 3문제로, 보상 문제를 보스 방에서만 2문제로 변경(신규 완주 32문제). 진행 중이던 이전 문제 묶음은 그대로 복원한다.
- 추격 속도 78 → 158~194, 분열형 58 → 132~168. 일반 방 적 수 5+지역×2+방 → 10+지역×3+방, 출현 간격 1.3 → 0.55초. 돌진형 접근 속도와 공격 빈도, 탄막 속도를 상향하고 첫 보스에도 방사형 탄막을 적용했다.
- 추격형 실루엣·발광 눈, 공격 예고 발광, 피해 숫자·파편·투사체 궤적·환경 입자로 전투 피드백을 보강했다.
- 스튜디오: 하루 분수 6 → 3문제(신규 시즌 총 100문제). 집중 멤버 선택, 경험치/레벨 1~10, 레벨 3·5·8 특기 +2, 성장 알림을 추가했다. 기존 저장에 경험치가 없으면 0부터 시작한다.
- 팬 100·200·300명에 무대 배경이 바뀌고 성장 등급을 표시한다. 공연은 16박자 3레인 터치/A·S·D 연주 후 평가한다. 정확도에 따라 무대 점수 0~5 보너스, 무분별한 입력은 정확도를 낮춘다. 컨디션·팬·팀워크 조건은 유지한다.
- 화면을 숨기면 연주를 중단하고 재시작을 제공한다. 결과는 공연 완료 시 한 번만 저장한다. 기존 학습·수집·시즌 기록과 Firebase 데이터 구조는 유지한다.
- 검증: 전체 `npm run check`, 18,000문항/성장·판정 단위 검사, 100문항과 네 공연을 포함한 28일 전문가 시즌, 네 보스 반복 공격 및 승패/보상 흐름 통과. 라이브 터치 검사는 `scripts/smoke/fraction-world-live.js`로 분리했다.
- 재미와 최종 난이도는 학생 플레이로 추가 조정할 항목이다. 무입력 공연도 기본 준비 조건을 모두 달성하면 성공할 수 있으며, 연주 보너스로 부족한 무대 점수를 일부 보완할 수 있다.

## 기본·심화 난이도와 결정 공방

- 균열의 탑 난이도 UI를 기본/심화로 정리했다. 저장 ID `hard`/`expert`는 유지하며 기존 `hard` 탐험은 기본 설정으로 이어진다. 스튜디오 난이도는 변경하지 않았다.
- 기본은 직전 일반 전투 대비 적 수 약 20%, 적 체력 10%, 이동·돌진·탄속 15%, 피해 15% 감소. 심화는 직전 expert 설정 유지. 기본 출현 간격 0.75초, 심화 0.55초.
- 방 사이 결정 공방에서 소지 유물 +1~+3 강화(20/35/50개, 실패 없음). 불꽃: 단계당 공격 보너스 +6%p, 서리: 피해 배율 ×0.97, 폭풍: 공격속도 보너스 +4%p, 숲: 최대HP +8과 동량 회복, 별: 기술 위력 보너스 +8%p. 원래 유물 효과에 추가 적용한다.
- 강화는 현재 탐험에 귀속된다. 장착한 유물만 효과가 적용되며 교체해도 해당 유물의 강화 기록은 남는다. 전투·보상 단계에서는 강화 불가, 부족한 결정/미소지/최대 단계는 차감하지 않는다.
- 공방에 결정 획득·사용처, 강화 전후 수치 표시. 장비 능력치 13항목과 속성 수집 개수/활성 상태 표시. 보상에서 교체 대상을 반영한 전후 수치 및 조합 활성·해제 표시.
- 기존 저장은 빈 강화 맵으로 복구하며 알 수 없는 유물/잘못된 강화 단계는 필터링한다. 저장 HP 한도를 강화로 가능한 범위를 포함하도록 확장했다.
- 검증: 강화 차감/최대 단계/전투 중 금지/장착 효과/난이도 차이 단위 검사, 저장 호환·오류 필터링, `scripts/smoke/fraction-world-upgrades.js`의 실제 터치 구매/재접속/조합 교체/태블릿 폭 검사.

## 게임 설명 탭

상단 물음표를 ‘게임 설명’으로 변경하고 시작하기/난이도와 길/탑 조작·진행/무기/결정·유물/스튜디오/분수 입력의 7개 설명 탭을 추가했다. 기본과 심화의 같은 방·같은 길 기준 수치를 비교하고, 분수 범위/전체 난이도/무기/방 경로의 적용 범위를 구별한다. 샘터에서도 전투를 한다는 점, 유물 조합과 강화의 차이, 저장 범위를 명시했다. 무기 시작 수치는 콘텐츠 데이터에서 생성한다. 설명 창을 열 때 라이브 공연의 시간을 정지하도록 보완했고, 기존 전투는 모달 일시정지를 유지한다. 라이브 스모크 검사에 7개 탭·태블릿 표·설명 도중 3초 정지와 복귀 후 16박자 만점 검증을 추가했다.
