# 분수 월드 성능 보완 — 2026-09-15

사용자가 전투·음악 업데이트 직후 무거워졌다고 보고해 최근 추가 코드의 반복 처리를 점검했다.

- 받아치기 버튼의 HTML·클래스·접근성 문구와 전투 안내문을 매 전투 갱신마다 덮어쓰던 처리를 실제 표시가 바뀔 때만 수행하도록 수정했다.
- 음악 설정 버튼도 같은 문구를 반복해서 쓰지 않게 했다.
- 한 음을 여러 발진기와 개별 게인 노드로 합성하던 방식을 캐시한 배음 파형과 단일 발진기로 바꿨다. 곡·편곡·템포·음량 설정은 유지한다.
- 전투 속도·적 수·난이도·패링 판정은 변경하지 않았다.

## 재현 비교

`scripts/smoke/fraction-world-performance.js`에서 동일한 최종 보스 전투를 120회 갱신하고 음악 상태를 40회 갱신했다. 감시 대상은 새 받아치기 버튼·전투 안내문·음악 버튼이다.

| 측정 | 수정 전 | 수정 후 |
| --- | ---: | ---: |
| 대상 DOM 변경 기록 | 400 | 4 |
| 최종 지역 보스 반주 8초의 생성 발진기 수 | 187 | 82 |
| 오프라인 음악 피크 | 0.191619 | 0.191623 |

DOM 변경 99%, 발진기 생성 약 56% 감소다. 전체 게임 CPU 사용량이나 FPS 개선율을 의미하지 않는다. 실제 학생 태블릿에서 원인이 모두 해결됐는지는 추가 관찰이 필요하다.

전투·음악 브라우저 회귀 검사(패링, 별방패, 독, 재개, 화면 크기 5종, 반주 12종) 통과. 운영 배포 전 `npm run check`를 실행한다. 배포 후 운영 파일 일치와 동일 성능 검사를 확인한다.
