# 배틀 스쿨·KBO 구단주 최소수집 플레이테스트

작성일: 2026-09-03

## 목적과 안전 경계

게임의 재미·난이도·설명 이해도를 확인하되 학생 이름, 학교, 학년·반·번호, 계정, 기기 식별자, 화면 녹화와 자유서술 개인정보는 수집하지 않는다. 이 문서는 테스트 절차만 준비한 것이며 실제 학생 대상 실행과 결과 수집은 사용자 승인 후 진행한다.

각 참여자는 당일에만 쓰는 무작위 코드 `P01`, `P02`처럼 기록한다. 원본 메모에는 점수 대신 아래 선택형 항목만 남기고, 개인을 알아볼 수 있는 발언은 옮겨 적지 않는다.

## 배틀 스쿨

권장 시간: 15분

1. 서로 다른 직업 2개로 새 게임을 시작한다.
2. 약점 과목 몬스터와 일반 몬스터를 각각 상대한다.
3. 스킬을 바로 쓰는 경우와 모아서 쓰는 경우를 비교한다.
4. 같은 가격대 장비 중 하나를 선택하고 이유를 말로 설명한다.

기록 항목:

- 직업 차이를 이해했다: 예 / 일부 / 아니오
- 약점 표시를 보고 전략을 바꿨다: 예 / 아니오
- 스킬을 스스로 사용했다: 예 / 도움 필요
- 장비 선택 이유를 설명했다: 예 / 일부 / 아니오
- 난이도: 너무 쉬움 / 적당 / 너무 어려움
- 다시 하고 싶다: 예 / 보통 / 아니오

## KBO 구단주

권장 시간: 20분

1. 한 주를 진행하고 수입·연봉·팬 만족도를 확인한다.
2. 계약 1년 선수를 찾아 3년 재계약 비용을 확인한다.
3. 재계약하지 않았을 때 다음 시즌의 1년 보류 계약과 20% 높은 연봉 안내를 확인한다.
4. 트레이드 제안과 신인 드래프트를 한 번씩 시도한다.
5. 다음 시즌의 새 구단 기대치를 찾아 이전 시즌과 비교한다.

기록 항목:

- 돈이 늘고 줄어드는 이유를 이해했다: 예 / 일부 / 아니오
- 3년 재계약과 1년 보류 계약 차이를 설명했다: 예 / 일부 / 아니오
- 트레이드 거절 이유를 이해했다: 예 / 일부 / 아니오
- 신인 잠재력의 의미를 이해했다: 예 / 일부 / 아니오
- 구단 기대치가 바뀔 수 있음을 이해했다: 예 / 일부 / 아니오
- 화면 정보량: 적음 / 적당 / 많음
- 다시 하고 싶다: 예 / 보통 / 아니오

## 판정 기준

- 참여자 2명 이상이 핵심 이해 항목에서 `아니오` 또는 `도움 필요`를 고르면 설명 UI를 먼저 보완한다.
- 난이도·재미 평가는 개인별 원문 대신 선택 수의 합계만 기록한다.
- 온라인 랭킹·Firebase 기능은 테스트 결과에서 필요성이 확인돼도 즉시 만들지 않고 최소수집 구조와 Rules 설계를 별도 승인받는다.
- 실제 결과표는 학생 식별정보 없이 별도 로컬 파일로 작성하고, 원격 저장소나 운영 데이터베이스에 올리기 전 사용자에게 확인받는다.
