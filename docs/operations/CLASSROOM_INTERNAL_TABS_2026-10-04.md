# 교실 내부 탭 개편 — 2026-10-04

## 범위

메인 화면의 아이보리·그린 디자인을 내부 9개 탭으로 확장했다. 실제 목록·상태·보상·기존 버튼 처리를 유지하며, 화면 구성을 `classroom-workspace.js`로 분리했다.

| 탭 | 변경 |
| --- | --- |
| 학생 | 이미지 중심 카드, 이름·번호 검색, 번호·이름 정렬 |
| 퀘스트 | 상태별 필터·건수, 보상과 실행 버튼을 분리한 목록, 진행 요약 |
| 성장루틴 | 진행률·오늘 체크 항목·새 루틴 진입, 교사는 학생별 진행/검토 보드 |
| 젬스톤 | 단계와 남은 경험치 강조, 성장 중/최고 단계/시작 전 필터 |
| 직업 | 내 직업 안내, 모집/내 지원 필터, 월급과 정원 표시 |
| 마켓 | 상품 목록과 선택 상세, 구매 전 잔액 계산, 기존 구매·수정 동작 연결 |
| 은행 | 환전 방향 선택, 입력 금액·수령액·남은 잔액 미리보기, 적금과 최근 포인트 기록 |
| 학급미션 | 책나무 이미지와 누적 포인트, 목표별 보상 카드 |
| 교사 검토 | 활동·쿠폰·직업 요청 바로가기, 학생/활동 검색과 검토 필터 |

학생 이미지는 이전 작업의 본인 사진/마켓 저장 아바타 선택을 그대로 사용한다. 교사 관리 폼은 각 탭 아래에 접어 두고 상단 관리 버튼에서 바로 열 수 있다.

## 동작 및 접근성

- 기존 구매 버튼 DOM을 상세 패널로 이동해 이벤트를 보존한다. 상품 선택은 구매를 호출하지 않는다.
- 환전은 양의 정수, 최대 1,000,000, 잔액 및 방향별 활성 여부를 확인한다. 최종 검증과 지급은 기존 서버를 사용한다.
- 직업의 ‘내 지원’은 현재 회원의 지원만 집계한다.
- 검색 결과·금액 미리보기 상태 안내, 키보드 탭 이동, 필터 선택 상태, 모바일 검토 표의 항목명을 제공한다.
- 새 학생 데이터 스키마, 서버 함수, 보안 규칙 변경은 없다.

## 검증 및 배포

- 운영 학생 데이터가 아닌 합성 데이터로 브라우저 검증한다.
- `scripts/smoke/classroom-ui-browser.js`: 학생/교사 전체 탭 × 1440/768/390/320px 총 76개 화면 조합, 학생·퀘스트·직업·검토 검색/필터, 교사 루틴 학생 전환, 구매 위임 1회 실행, 상품 선택과 구매 분리, 환전 입력 오류/잔액 부족/소수 환율 미리보기, 기존 홈·이미지 선택 회귀 검사.
- 운영본과 로컬에는 다른 작업의 차이가 있다. `publish-classroom-tabs.js`가 현재 Hosting 버전을 복제하고 교실 CSS·렌더러·새 화면 모듈·해당 번들·HTML 캐시 버전 5개 파일만 바꾼다. 나머지 파일 및 Hosting 설정을 해시로 대조한다.
