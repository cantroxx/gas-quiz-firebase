# 상점 안내 정리 운영 배포

2026-10-17, 사용자의 `배포 진행` 요청으로 Firebase Hosting에 반영했다.

## 반영 내용

- 바깥 화면 제목을 `상점`으로 변경하고 영문 문구, 설명, 고정 쿠폰 20장·염색·메이플 코디 홍보 문구를 제거했다.
- 상단 제목 영역을 축소했다.
- 상점 내부 보유 코인·구매 버튼 영역으로 쿠폰 표시를 이동했다. 서버 응답의 `purchaseCoupons`를 `남은 구매 쿠폰 N장 · 아이템 1개당 1장`으로 표시한다.
- 구매·지급 정책, 학생 데이터, Functions, Rules, Hosting 설정은 변경하지 않았다.

## 배포 범위와 운영본 차이

운영본을 복제하여 아래 5개 파일만 반영하고 다른 Hosting 파일 3,780개와 설정의 동일성을 검사했다.

- `/index.html`: 상점 섹션의 제목·안내 제거와 스타일 링크만 변경.
- `/town-shop.css`: 운영에 없었던 상점 전용 스타일을 추가.
- `/coordi-shop/index.html`: 쿠폰 위치와 연결 스크립트 캐시 버전 변경.
- `/coordi-shop/dressing-room.js`: 쿠폰 표시 한 줄만 변경.
- `/coordi-shop/town-bridge.js`: 코디 스크립트 캐시 버전 변경.

로컬에는 별도 작업의 로딩 상태 개선, 오류 처리, 메인 화면 진입 상태 요소 등이 있다. 이 변경들은 운영본에 섞어 배포하지 않았다. 따라서 전체 로컬 파일과 운영 파일의 일치를 의미하지 않는다. 공개 파일은 이번 배포 후보의 해시와 일치한다.

## 검증

- `npm run check` 전체 통과. 최초 실행은 샌드박스의 로컬 포트 차단(`EPERM`)으로 중단됐으며, 허용된 환경에서 재실행해 통과했다.
- 운영본 기준 후보에 기존 `coordi-starter-browser.js`의 합성 계정을 연결하여 쿠폰 20→19장 갱신, 코인 결제와 쿠폰 결제, 쿠폰 부족 시 거래 차단, 무료 드레스룸, 모바일 검증 통과.
- 후보의 운영 스타일·진입 모듈을 사용한 상점 제목과 불필요한 문구 제거, 1440/390/320px 배치·가로 넘침 검사 통과.
- 배포 후 live 버전, 전체 파일 목록, 변경한 5개 공개 파일의 해시를 확인했다.
- 비로그인 운영 로그인 화면 로딩, 상점 제목과 스타일 참조, 홍보 문구 제거, 페이지 오류 없음 확인.
- 실제 학생 계정의 운영 구매·장착은 실행하지 않았다.
