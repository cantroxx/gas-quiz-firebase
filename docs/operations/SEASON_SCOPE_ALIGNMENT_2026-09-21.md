## 수정
- 우하단은 ‘내 상태’ 버튼 하나. 창 안에서 기존 퀘스트 기간 필터·수령 기능 이용. 외부 학습 사이트용 로컬 숏컷 복사본도 동일하게 수정.
- 월간 보상 퀘스트를 연습전 새 정답 100, 오늘의 퀴즈 새 정답 50, 랭킹전 정상 완료 10과 기존 온라인 5종을 합한 8종으로 확대. 10월 이후 기본 목표의 80/100/120% 월별 구성 적용.
- 기존 온라인 5종의 ID·목표 산식·진행도·수령 기록 유지. 추가 3종은 이미 서버에 집계된 해당 월 기록으로 판정하며, 기록되지 않은 과거 플레이를 추정해서 추가하지 않는다.
- 추가 3종도 각각 XP 50·DJ코인 40 월 1회. 기본 월간 보상 총합은 XP 400·DJ코인 320으로 증가(실제 XP는 기존 한도, 레벨업 코인은 별도).
- 상태창 수령 개수의 고정값 5 제거. 서버의 한도·퀘스트 목록 사용.
- 이벤트 광장과 상태창 모두 ‘관리자 지정 시즌 이벤트’와 ‘이번 달 공통 보상 퀘스트’로 구분. 같은 `getEventProgress` 응답의 `seasonEvents`와 `quests`를 표시한다. 공지형 지정 이벤트를 자동 보상 퀘스트로 임의 변환하지 않는다.
- 관리자에 ‘이번 달 적용 중’과 ‘다음 달 예정 · 리롤 대상’을 함께 표시. 두 화면의 목표는 같은 season-plan 모듈에서 계산.
