# 상태창·학교·게임 아지트 보완

## UI
- 내 상태 카드: 배경 그림을 16% 불투명도의 장식층으로 분리. 카드 안팎·본문·접기 영역·진행 막대·각주에 여백 추가.
- 학교 인기 퀴즈 아래 접근 안내 박스 생성 제거. 퀴즈 접근 권한/제한 자체는 변경하지 않음.
- 학교 게임 아지트 및 독립 `/battle/` 목록의 스터디 타운을 균열의 탑으로 표기. 아이돌 육성 설명을 빼고 생존 액션 게임으로 소개.
- 서바이버·구름탑·말폭탄·마블·독립 아지트에서 공통 상태 스크립트 로드 제거. 마블은 소스 HTML 수정 후 정상 빌드.
- 오래된 HTML/외부 프로야구 구단주가 공통 스크립트를 로드해도 게임 주소에서는 공통 상태 아이콘을 생성하지 않음. 삼국지·과일종·숨빛 진입점도 점검.
- 별도 Vercel 균열의 탑은 현재 운영 소스 67파일 중 index.html의 공통 상태 스크립트 한 줄만 제거. 게임의 전투 능력 확인 UI는 유지.

## 서바이버 원인과 수정
- 랭킹 행 문자열에 닫는 `</div>`가 없어 순위들이 중첩되는 문제 재현/수정. 이름을 안전한 텍스트로 출력하고 독립 grid 행으로 정리. 320/390/1440px에서 점수왕/정답률왕 모두 가로 넘침·중첩 없음 검사.
- 역사 분기보다 오답노트 복습이 먼저 실행되어 수학 오답이 선택될 수 있었음. 역사 출제 분기를 가장 먼저 처리하여 다른 과목이 끼지 않도록 수정.
- 공부 모드는 역사 분기를 제외하던 조건을 제거하여 역사 선택 시 공부 모드도 역사 문제 출제.
- 기본 HTML의 각도 라벨을 중립 로딩 문구로 바꾸고 서버 요청 전에 선택한 문제/시대 라벨을 표시. 고조선 요청 대기 중 잘못된 각도 라벨이 남지 않음.
- 실제 사용자의 해당 판 기록을 추정한 것은 아니며, 코드를 통해 혼입 가능한 경로와 로딩 표시 문제를 확인하고 합성 오답노트/서버 응답으로 검증함.
