# 스터디 타운 4학년 2학기 수학 확장

## 반영

- 6단원: 분수의 덧셈과 뺄셈, 삼각형, 소수의 덧셈과 뺄셈, 사각형, 꺾은선그래프, 다각형.
- 단원당 15개, 총 90개의 독립 출제 틀. 84개 즉시 채점 틀과 6개 자유 서술 틀. 수·조건·그래프 값을 검증된 범위에서 생성하며 개념 확인 문제에는 고정된 성질 문제도 포함.
- 9가지 형식: 직접 답, 빈칸, 하나 선택, 복수 선택, 그림/조건 선택, 순서, 분류, 단계형 이유/과정, 자유 서술.
- 객관 채점 출제 비중은 개념20/응용50/추론30. 게임 난이도와 독립. 선택 단원을 번갈아 출제하고 최근 출제 틀의 반복을 줄임.
- 기존 사용자 학습 단원 기본값은 분수. 로비에서 1~6개 선택. 기존 분수 범위 선택기는 스튜디오용으로 유지.
- 도형·그래프는 SVG. 삼각형 표시 각도와 실제 꼭짓점, 평행/직각 모양, 그래프 좌표·눈금을 계산. 그래프 표 보기와 선택 버튼을 함께 제공. 대각선·그래프 점/구간은 그림에서도 선택 가능.
- 분수 결과가 자연수 또는 0만 되는 계산은 새 출제 틀에서도 제외. 분수 동치 표현, 소수 끝 0, 수치 입력을 유리수로 비교.

## 게임과 서술

- 탑 입장 3문제, 보스 보물 2문제의 기존 보상·오답 규칙 유지. 초보 오답 추가 적 없음. 수학 문제 중 전투 정지.
- 보스 보물 2문제 뒤 자유 서술은 선택 도전. 자유 서술 제출 여부는 기존 2문제 보상에 영향을 주지 않음.
- 자유 서술은 최대600자, 자동 정답·오답 판정 없음. 답안과 예시, 3개 자기 점검 항목 제공. 수정은 같은 답안을 갱신하고 통계를 중복 가산하지 않음.
- 교사는 기존 퀴즈타운 관리자 연결 후 현재 기기·현재 저장 칸의 서술을 검토. 3개 근거별 수준과 피드백을 저장. 검토 시 연결 만료·저장 칸 변경 확인. 교사 결과는 게임 보상과 자동 정답률에 반영하지 않음.
- 검토된 서술을 다시 수정하면 이전 검토는 과거 검토로 남기고 현재 답안은 재검토 대상. 자기 점검과 교사 검토는 구분 표시.
- 학급 전체의 원격 답안 수집이나 AI 채점은 추가하지 않음. 현재 기기 기록 검토와 JSON 내보내기 지원. Firebase 학생 데이터·보안 규칙 변경 없음.

## 저장·수첩

- 저장 키 `dj48.study-town.v1` 그대로. 학생 전체 초기화 없음.
- 기존 분수/스튜디오/모험 기록 유지. 새 `studyStats`, `studyAnswers`, `settings.studyUnits` 추가.
- 기존 진행 중 분수 묶음은 기존 엔진으로 끝까지 이어지고, 다음 묶음부터 새 엔진 사용.
- 새 묶음은 문제 틀 ID와 시드를 저장해 동일 문제 재구성. 단원 목록을 묶음별로 고정. 입력 초안·선택·풀이 확인·서술 수정 상태 복원.
- 단원별/형식별 자동 정답률, 단계별 결과, 자유 서술 제출 수. 이전 분수 기록 별도 열람. 틀린 유형 다시 도전.
- 최근 답안120개 저장, 누적 통계 유지. 답안·문항·예시·교사 검토를 JSON으로 내려받기 가능.

## 검증

- `tests/fraction-world/study.test.js`: 90틀×200시드 = 18,000 생성, 정답/오답 판정, 동치 분수, 선택지 유효성, 별도 산술 검산, 출제 비율, 저장 복원과 칸 격리. 기존 분수 테스트에 포함.
- `scripts/smoke/fraction-world-study.js`: 90개 실제 브라우저 입력, 모든 형식, 단원 설정, 서술 중립 채점, 초안/정오 풀이/수정 새로고침, 보스 추가 서술, 교사 검토 및 만료, 4개 화면 크기.
- `scripts/smoke/fraction-world-adventure-v2.js`: 새 문제 엔진으로 입장 정답 보상 및 기존 전투/부활/상태창/48 무기·보스 조건 검사.
- 기본 전체 검사에서 다른 작업의 에뮬레이터 포트 점유 확인. 다른 작업을 중단하지 않고 `/tmp/study-validation-20260916` 검사 복사본에서 동일 검사를 수행. 복사본 설정과 rules 테스트의 로컬 포트만 8283/9398/4468/4568로 조정. 운영 설정은 변경하지 않음. 해당 복사본의 `npm run check`는 종료 코드 0으로 통과. 수학 브라우저 최종 검사와 기존 모험 검사는 모두 통과.
