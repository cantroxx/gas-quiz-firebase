# 분수 월드 확장 구현 — 2026-09-14

## 실행 범위

사용자가 승인한 종합 계획과 네 가지 선택을 반영했다. 기본 탐험(지역당 5단계+보스)과 장기 탐험(7단계+보스)을 별도 모드로 제공한다. 기본/심화 전투 난이도와 분수 범위는 독립적이다. 강화·결정은 탐험마다 초기화하고, 도감·학습·클리어·해금 기록은 저장 칸에 보존한다. 스튜디오 기능 확장은 포함하지 않는다.

## 구현 내용

- 네 지역의 생성 지도 배경 위에 실제 스테이지 버튼과 SVG 연결 경로를 배치했다. 각 일반 단계에서 다음 방 3개를 미리 보고 확인 후 이동한다. 보스 앞에서 합류한다. 완료·선택 가능·닫힌 경로를 구분하고 태블릿 스크롤·화면 회전을 지원한다.
- 기본 경로는 24방, 장기 경로는 32방 방문이다. 일부는 비전투 방이다. 지역별 첫 번째/세 번째 전투에 3문제씩, 보스 보물에 2문제를 출제하여 두 모드 모두 32문제다.
- 일반·정예·속성 보물·대장간·일반 상점·샘터·사건·보스와 조건부 비밀 상점을 연결했다. 비밀 상점은 단계 소모 없는 추가 방문이며 지역당 한 번이다.
- 무기 +1~+5 비용은 15/25/40/60/85개다. +1·+2는 지도 정비, +3 이상은 대장간에서 진행한다. +3 두 계열과 +5 각성을 실제 공격에 적용하고 전후 수치·공격 로직 기반 시연을 제공한다.
- 기존 6무기와 신규 쌍검·창·망치·사슬낫·방패·소환서로 12종을 구성했다. 근접 범위·관통·귀환·추적·공전·소환·방어 등 전투 방식을 구분한다.
- 유물은 40종(5속성 각 8종), 집중 조합 5종과 혼합 조합 10종이다. 혼합 효과는 재발동 간격, 추가 피해의 재귀 방지, 보호막 상한 방식으로 제어한다.
- 상점은 속성 유물 40개, 무기 또는 기술 개조 55개, 구조 부적 45개를 세 상품으로 제시한다. 방문당 한 상품이다. 비밀 상점은 10개 할인한다. 동일 개조 중복 구매를 막는다.
- 샘터는 결정 25개로 체력 최대 40 회복 또는 무료 다음 전투 보호막 15 중 하나다. 사건은 열쇠 1개·결정 18개·체력 20 회복 중 하나다.
- 새 탐험은 오답 재입력 대신 정답·그림 풀이 확인 후 진행한다. 기본은 오답당 추가 적 1마리, 심화는 2마리(3문제 기준 최대 3/6). 다음 실제 전투 한 번에 적용하며 보스에서는 최대 1/2로 제한한다. 별도 결정 보상은 없다.
- 보스 보물은 정답당 추가 결정 3개다. 풀이 확인 화면은 새로고침해도 보존하며, 이미 기록된 응답·오답·추가 보상을 중복 반영하지 않는다.
- 기존 진행은 기존 일렬 경로와 재입력 규칙으로 이어진다. 새 탐험부터 지도 방식과 새 학습 규칙을 적용한다. 기존 진행을 삭제하거나 새 지도로 강제 변환하지 않는다.
