# 퀘스트·개인 상태창·코디 상점 일괄 작업 보고

작성: 2026-09-20. **로컬 구현과 검증 완료, 운영 배포 전 보고.**

후속: 퀘스트·성장·숏컷은 운영에 반영했다. 상점 거래/하보 분리의 별도 로컬 변경은 이번 배포에 포함하지 않았다. 현재 배포 상태는 [운영 반영 보고](GROWTH_QUEST_LAUNCH_2026-09-20.md)를 따른다.

운영 Firestore·Storage의 학생 데이터, 잔액, 기존 보유품, 관리자 설정은 변경하지 않았다. 이번 작업으로 배포·커밋·푸시는 하지 않았다. 다른 작업의 미배포 변경이 많은 저장소이므로, 후속 배포는 운영본과 대조한 범위 제한 배포가 필요하다.

## 1. 모든 활동을 같은 성장 퀘스트로 연결

기존 연습전 보상은 유지하고 온라인 게임의 서버 승인 활동을 새 일일·주간 퀘스트에 연결했다. 모든 항목의 진행도를 함께 기록하며, 사용자가 완료한 항목 중 **일일 최대 3개, 주간 최대 3개**의 보상을 받는다. 게임을 시작하기 전에 퀘스트를 선택할 필요가 없다.

| 분야 | 인정 활동 | 일일 목표 | 주간 목표 |
|---|---|---:|---:|
| 연습전 | 기존 서버에서 새 정답으로 인정한 문제 | 10 | 40 |
| 오늘의 퀴즈 | 오늘의 퀴즈에 해당하는 새 정답 | 5 | — |
| 일반 랭킹전 | 시작 기록이 있는 정상 완료 | 1 | 3 |
| 스터디 타운 | 서버 채점 정답 | 8 | 30 |
| 퀴즈 서바이버 | 서버 발급 문제의 최초 정답 | 8 | 30 |
| 두근두근 마블 | 3분 이상 경기, 직접 주사위 3회 이상, 종료 시 연결 상태인 비포기 참가자 | 1 | 3 |
| 타닥타닥 구름탑 | 서버가 승인한 문장 완성 | 20 | 80 |
| 말폭탄 | 서버 사전이 인정한 낱말 제출 | 8 | 30 |
| 꾸준히 참여 | 서로 다른 날짜에 일일 보상 수령 | — | 3일 |
| 여러 분야 참여 | 연습전·랭킹전·아지트 중 서로 다른 분야의 일일 보상 수령 | — | 2분야 |

- 일일 퀘스트 1개: **XP 15 + DJ코인 10**. 주간 1개: **XP 30 + DJ코인 20**.
- 일일 보상 최대 XP 45/코인 30, 주간 추가 보상 최대 XP 90/코인 60. 매일 일일 3개를 받으면 한 주 퀘스트 보상은 명목상 XP 405/코인 270이다.
- 기존 **주간 한도 적용 XP 500**, 최고 레벨 50, 레벨업 계산을 그대로 사용한다. 다른 보상과 한도를 공유하므로 실제 XP 지급은 줄어들 수 있다. 퀘스트 코인은 기존 연습 정답 코인 한도와 별도다.
- 한국 시각 자정에 일일 구분, 월요일에 주간 구분을 새로 한다. 기존 기록을 삭제하는 초기화 방식이 아니다.
- 구형 퀘스트 진행·수령 내역은 보존한다. 활성 퀘스트 목록과 수령 API는 새 목록으로 전환하며, 과거 플레이 실적을 새 퀘스트에 소급 적립하지 않는다.

## 2. 게임별 판정 및 중복 방지

- 연습전: 기존 `practice_correct` 보상 기록이 생성될 때 집계한다. 같은 새 정답 기록의 재처리는 중복 집계하지 않는다.
- 일반 랭킹전: 서버가 발급한 시작 세션과 저장된 본인 경기 기록을 대조한다. 10초 이상·2시간 이내, 양수 점수, 같은 퀴즈, 세션당 한 번만 인정한다. 기존 랭킹전의 클라이언트 채점 구조 전체를 서버 채점으로 바꾼 것은 아니다.
- 스터디 타운: 기존 서버 채점의 최초 정답만 집계한다.
- 서바이버: 기존 문제 생성기를 서버에도 포함하고 문제 발급·최초 채점을 추가했다. 브라우저에서 정답 여부만 보내 보상을 만드는 방식은 사용하지 않는다. 객관식, 숫자 주관식, 족보 힌트를 연결했다. 연결 실패 시 로컬 플레이는 가능하지만 해당 문제는 퀘스트에 반영하지 않으며 안내한다. 오답 노트 복습도 새 보상 대상이 아니다.
- 마블: 포기, 짧은 경기, 종료 시 연결이 끊긴 참가자, 직접 주사위 3회 미만은 제외한다. 기존 승패·랭킹 계산은 유지한다.
- 구름탑: 기존 서버의 입력 순서·시간·문장 검사를 통과한 제출만 집계한다.
- 말폭탄: 기존 사전 판정을 통과한 낱말만 집계한다. 참가자 투표로 임시 승인한 낱말은 제외한다.
- 보상 수령은 트랜잭션으로 일일/주간 3개 제한, 중복 지급, 동시 요청을 처리한다. 활동 이벤트의 재전달도 원본 식별자로 중복 제거한다.
- 활동 반영은 Firestore 트리거를 거치므로 잠깐 지연될 수 있다. 상태창 새로고침으로 확인한다.

## 3. 공통 개인 상태창

화면 우측 하단 `내 상태` 버튼에서 다음을 확인하고 보상까지 받을 수 있다.

- 보유 DJ코인, 레벨, 누적 XP, 다음 레벨까지 진행도
- 오늘 연습 정답 코인 / 오늘의 퀴즈 XP / 이번 주 한도 적용 XP
- 일일·주간 퀘스트 전체 진행도와 보상 수령 버튼, 일일·주간 수령 횟수
- 오늘 퀘스트로 받은 실제 XP·코인(연계 레벨업 코인 포함)

획득 현황은 출처별 한도와 퀘스트 지급액을 보여준다. 모든 보상 출처의 하루 수입을 합친 단일 합계는 아니다.

적용: 메인 연습전·랭킹전, 게임 아지트, 스터디 타운/분수 월드, 서바이버, 구름탑, 마블, 말폭탄, 기존 낱말대전, 우주 탐험, 코디 상점. 별도 KBO 사이트에도 공통 버튼 연결을 추가했다. 버튼 연결 범위와 신규 보상 대상은 다르며 KBO 등에 새 퀘스트 보상을 추가한 것은 아니다.

같은 사이트에서는 모달, 외부 배포 게임에서는 퀴즈타운 상태 페이지를 새 창으로 연다. 토큰을 외부 게임에 전달하지 않는다. 창을 열 때만 조회하고 닫으면 iframe을 제거한다. 상시 조회를 하지 않으며, 경기 자체를 일시정지하지 않는다. 관리하지 않는 외부 사이트에는 자동 삽입하지 않는다.

## 4. 코디 상점 실제 거래

- 기존 DJ코인 잔액으로 서버 카탈로그의 상품을 구매한다. 브라우저가 보낸 가격은 사용하지 않는다.
- **고유 캐시 아이템 721개**를 판매 목록으로 사용한다. 성별 중복 포함 목록은 1,127개다. 비캐시 아이템과 피부 상품은 제외했고 기본 피부/스킨 프리즘은 유지했다.
- 헤어 150, 성형 120, 모자·상의 100, 한벌옷 180, 하의 80, 신발 70, 장갑·귀걸이 50, 얼굴·눈 장식 60, 망토 150, 무기 200, 방패 100 DJ코인.
- 무료 입어보기 → 선택 상품 가격 확인 → 구매 → 보유 아이템 장착 저장. `보유 아이템만 보기`를 추가했다.
- 미보유 상품의 저장, 성별 불일치, 한벌옷과 상·하의 동시 저장은 서버에서 차단한다.
- 컬러 프리즘/스킨 프리즘 미리보기는 무료. 변경 적용은 50 DJ코인, 동일 상태 재적용과 원색 복원은 무료다. 헤어·성형은 의상 프리즘 대상이 아니다.
- 구매·염색은 잔액 부족 시 전체 취소한다. 요청별 영수증을 남겨 응답 재시도로 중복 차감하지 않는다.
- 보유품·장착·염색은 서버 프로필에 저장하고 다시 열면 복원한다. 상점의 코디 저장 기능까지 구현했으며, 움직이는 캐릭터나 하우징 표시로 연결하지 않았다.
- 기존 `shopEnabled` 설정을 준수한다. 닫힌 상점은 학생 거래·미리보기를 서버에서도 차단하고 관리자 점검만 허용한다. **운영 설정을 열거나 변경하지 않았다.**
- 비캐시 제외는 인기도 편향 보정과 별개다. 캐시로 분류된 이벤트 지급 아이템은 이번 필터에도 남아 있다.

## 5. 하보 연결 분리

메인 내 집에서 하보 광장 진입 링크와 자동 쿠폰 청구 호출을 제거했다. 상점의 학생 화면은 새 코디 상점 중심으로 연결했다. 하보 코드, 직접 URL, 기존 가구·방 데이터, 보유품, 관리자 관리 기능은 보존한다. 하보 서비스 자체 폐쇄나 자료 삭제는 하지 않았다.

## 7. 배포 인계

주요 서버 변경: `functions/growth/`, `functions/coordi-shop/commerce.js`, `catalog.json`, 게임별 service, `functions/index.js`.
주요 화면 변경: 공통 상태창, 메인 셸/상점, quiz repository, 서바이버, 코디 상점, 각 게임의 숏컷 진입점과 마블 빌드 산출물.

서버 배포 대상은 최소 다음과 같다.

- 신규: `startRankingQuestSession`, `ingestGrowthActivity`, `ingestPracticeGrowth`, `survivorQuestQuiz`, `coordiShopAction`
- 갱신: `getEventProgress`, `claimEventQuestReward`, `grantRankingCompleteXp`, `grantPracticeReward`, `studyTownAction`, `cloudTowerAction`, `townMarbleAction`, `wordBombAction`, `renderCoordiShopPreview`

새 컬렉션은 기존 최종 거부 규칙을 사용하므로 이 기능을 위한 보안 규칙·인덱스 배포는 필요하지 않다. 저장소의 기존 rules/indexes 수정은 다른 작업과 구분해야 한다.

후속 순서: 운영본 대비 변경 묶음 확정 → 관련 서버 함수 및 Hosting 배포 → 상점을 닫아 둔 상태로 관리자 점검 → 외부 게임의 연결 스크립트 배포 → 사용자 지시에 따른 상점 공개. 서버를 먼저 반영한 뒤 새 클라이언트를 배포해야 하며, 구형 클라이언트의 일반 랭킹전은 시작 세션이 없어 새 퀘스트 적립이 거절될 수 있으므로 같은 배포 작업에서 이어서 반영한다.

## 8. 추가 요청: 온라인 게임 월간 시즌 퀘스트

일일·주간과 별개로 월간 시즌 퀘스트 5개를 추가했다. 기존 관리자가 작성한 독서/역사 등 시즌 이벤트 안내는 유지하고, 이벤트 광장의 시즌 영역과 개인 상태창에 새 진행도·보상 버튼을 표시한다.

| 게임 | 한 달 누적 목표 | 보상 |
|---|---:|---|
| 스터디 타운 | 서버 채점 정답 100개 | XP 50 + DJ코인 40 |
| 퀴즈 서바이버 | 서버 발급 문제 정답 100개 | XP 50 + DJ코인 40 |
| 두근두근 마블 | 정상 완주 5회 | XP 50 + DJ코인 40 |
| 타닥타닥 구름탑 | 서버 승인 문장 200개 | XP 50 + DJ코인 40 |
| 말폭탄 | 사전 인정 낱말 100개 | XP 50 + DJ코인 40 |

- 게임별 월 1회, 5개 모두 수령 가능. 일일/주간 3개 제한을 소비하지 않는다.
- 모두 달성하면 월간 추가 보상은 명목상 XP 250 + DJ코인 200. 기존 주간 XP 500 한도와 최고 레벨은 계속 적용한다.
- 한국 시각 매월 1일 00:00부터 새 월의 진행도를 사용한다. 직전 월 기록과 영수증은 보존하고 이월·소급 지급은 하지 않는다.
- 같은 승인 활동으로 일일·주간·월간 진행도를 함께 올린다. 온라인 연동 게임의 기존 인정 활동 기준을 사용하며, 상대방 수에 따른 별도의 대전 전용 조건은 추가하지 않았다.
- 여기서 포인트는 기존 DJ코인이다. 시즌 보상으로 레벨이 오르면 기존 레벨업 코인도 함께 지급한다. 경기마다 즉시 지급하는 보상은 추가하지 않았으며, 완료한 퀘스트에서 보상을 수령한다.
- `growthQuestProgress`의 `season` 기간 문서만 추가 사용한다. 운영 설정·학생 데이터·보안 규칙은 변경하지 않았다. 이전 변경과 함께 미배포 상태다.
- 검사: 시즌 5개 수령, 동시 중복 수령, 일일/주간 제한과 독립, 한국 시각 월 경계, 지난달 이벤트 재전달, 새 달 재달성, 이벤트 광장 버튼 연결 및 기존 시즌 카드 보존 검사를 통과했다. 전체 `npm run check`, 상태창 브라우저 검사, 데모 Firestore의 월간 XP·코인 및 연계 레벨업 보상·동시 중복 수령 검사도 통과했다.
