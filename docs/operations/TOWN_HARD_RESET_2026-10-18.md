## 배포 중 실행 설정 대조

Firebase 배포 뒤, 이전 메타데이터에 최대 인스턴스 수가 생략되어 있던 10개 대상 함수에 `20`이 지정되는 것을 발견했다. `0`으로 초기화해도 현재 API가 다시 `20`을 지정했다. 배포 전 Cloud Run 리비전을 직접 조회해 revision scaling 설정이 없음을 확인했고, [Cloud Run의 미지정 최대 인스턴스 기본값 100](https://docs.cloud.google.com/run/docs/reference/rest/v2/RevisionScaling)에 맞춰 이 10개 함수의 실효 한도를 명시적인 `100`으로 복원한다. 원래 명시된 10/20 한도는 유지한다.

따라서 저장된 메타데이터 표현은 ‘생략’에서 `100`으로 바뀌지만 기존 리비전의 실효 상한을 유지하는 보정이다. 메모리·CPU·동시 요청·제한 시간·실행 계정·ingress도 배포 전 값과 대조한다. 향후 이 함수들을 CLI로 재배포할 때 실행 설정을 다시 확인해야 한다.
