# 분수 월드: 직접 공격·코인 모드·길잡이 업데이트

## 적용 범위

균열의 탑의 신규 탐험과 공통 분수 출제. 스튜디오 게임 구조와 Firebase 학생 데이터·랭킹·경제는 변경하지 않는다. 기존 탐험은 기존 자동 공격 규칙을 유지하며, 새 탐험부터 새 조작과 모드를 선택한다. 저장된 문제의 교정은 기존 탐험에도 적용한다.

## 최종 동작

1. **직접 공격**: 공격 버튼, 전투장 클릭/탭, J키를 한 번씩 누른다. 연타 속도는 무기별 공격 대기시간으로 제한된다. 보조 자동 공격은 최소 3.5초 간격이며 무기별 기존 간격의 7배를 적용한다. 직접 공격은 기존 간격의 1.35배, 최소 0.32초다. 정령/책 계열의 자동 사출도 직접 공격 직후에만 활성화된다. 기존 지역별 강화 한도·강화소 횟수·추가탄 감쇠·회복 제한을 유지한다.
2. **정답 보너스**: 입장 3문제를 모두 맞히면 결정 6개. 해당 방에서 한 번만 지급하며 코인 재도전이나 새로고침으로 반복 지급하지 않는다. 계산 속도는 영향을 주지 않는다.
3. **분수 문제**: 두 피연산자 모두 분수 부분이 있어야 하고 결과가 0 또는 자연수가 되는 문제는 제외한다. 예: `2/4+2/4`, `2와 0/3` 형태를 출제하지 않는다. 저장된 미응답 문제는 교체한다. 이미 채점된 잘못된 문제의 풀이 화면은 넘기되 학습 점수·문제 진행을 중복 계산하지 않는다.
4. **부활 모드**:
   - 로그라이크: 체력이 0이 되면 탐험 종료. 기존 1회 부활 부적 효과는 유지한다.
   - 코인: 체력이 0이 되면 같은 방을 다시 시작할 수 있다. 실패 1회마다 기본 공격력과 기술 위력 **+25%**, 최대 **+500%**. 체력은 채워지고 적은 방 시작 상태로 다시 등장한다. 결정 비용은 없다. 무기·유물은 보존한다.
   - 보너스는 해당 방을 통과하면 초기화된다. 실패한 시도의 처치 수는 되돌려 중복 누적을 막는다. 실패 시도 자체를 최종 탐험 기록으로 확정하지 않는다.
   - 코인 모드에서는 심화 보스도 일반 공격으로 방패를 깰 수 있다. 받아치기는 더 빠르게 방패를 깨는 방법이다.
   - 전투 난이도(기본/심화), 탐험 길이(기본/장기), 부활 모드는 별개 선택이다.
5. **길잡이**: 시작할 때 켜고 끌 수 있고 탐험 중에도 전환 가능. 현재 할 일 한 가지, 체력·결정에 맞는 길 추천, 유물 속성 조합/무기 적합성 안내, 첫 전투·보스·시설 설명을 제공한다. 첫 설명 동안 전투는 멈춘다. 조작 체험에서 이동·공격·회피·받아치기를 연습하며 실제 체력과 기록은 소모하지 않는다. 실패 화면에는 실제 피격 원인에 따른 안내를 보여준다.
6. **시작 화면**: 탐험 길이 → 시작 무기 → 모험가 모습 → 몬스터 모습 → 전투 난이도 → 부활 모드와 길잡이. 하나를 정하면 다음 단계가 열린다. 기본값으로 다음 이동 가능하며 앞 단계로 돌아가 수정할 수 있다.

## 표시와 호환성

- 직접 공격을 포함한 전투 버튼 4개를 2×2 배치한다.
- 능력치에는 직접 공격 대기시간을 반영한 ‘10초 동안 최대 공격’ 자연수 표시를 사용한다.
- 지도 추천 이유는 안내문에 표시하고 버튼에는 작은 추천 배지만 붙인다. 현재 층 테두리와 위치 표시를 침범하지 않는다.
- 기존 저장 탐험의 조작 규칙을 중간에 변경하지 않도록 `controlVersion`을 신규 탐험에만 기록한다.
- 이미지 신규 대용량 파일은 추가하지 않는다. 기존 WebP·지연 로딩·공유 디코딩·캐시 정책을 유지한다.

## 검증

- `npm run test:fractions`: 통과. 6가지 문제 유형 × 경계 난수/일반 난수의 총 18,000개 추가 출제 검사 포함.
- `npm run check`: 필수 전체 검사 통과(최종 배포 전 재실행 로그 별도 확인).
- `fraction-world-journey.js`: 순차 선택, 길 추천, 정답 6개 지급, 직접/자동 공격 차이, 코인 실패·새로고침·재도전·방 통과 초기화, 로그라이크 종료, 조작 체험, 저장 문제 교체와 기존 채점 보존, 화면 폭 검사.
- 고정 표적에 대한 실제 전투 컨트롤러 10초 검사: 기다릴 때 2회 / 반복 직접 공격 13회. 이는 조작 빈도 검증이며 학생의 후반 클리어율 측정은 아니다.
- `fraction-world-tactics.js`: 받아치기, 보스 방패, 독, 저장 복원, 5가지 화면에서 이동 패드/4개 전투 버튼/보조 버튼 비겹침, 음악 12개 편곡 검사.
- `fraction-world-pixel-polish.js`: 지도 24가지 배치에서 현재 위치와 버튼 비겹침, 12종 기술 효과·실제 피해, 활 자세 검사.
- `fraction-world-expedition.js`: 강화 분기 24가지, 24개 방/32문제 완주 흐름, 해금·강화·비밀 상점·재접속 검사. 완주 흐름 검사에서는 마지막 적의 체력을 낮춘 픽스처를 사용하므로 난이도/승률의 근거로 사용하지 않는다.
- `fraction-world-image-loading.js`: 로비 지연 로딩, 이미지 준비 중 전투 정지, 키 입력 차단, 원본 이미지 미요청, 실패 후 재시도 검사.

## 수업 후 관찰할 점

직접 공격이 태블릿에서 피로하지 않은지, 코인 모드에서 몇 회 재도전 후 통과하는지, 10번째 방 이후 조합이 실제 승률에 미치는 영향을 학생 플레이로 확인한다. 이번 자동 검사를 학생 난이도 검증으로 대신하지 않는다.
