# 코디 상점 연결 — 2026-09-18

최신 상태: [2026-09-29 학생 상점·무료 드레스룸 배포](COORDI_DRESSROOM_DEPLOY_2026-09-29.md). 아래 내용은 9월 18일의 관리자 체험 단계 기록이다.

## 구현 범위
- 상점의 `renderAvatarMarket`에서 관리자에게 코디 상점 진입 버튼을 제공한다.
- `/coordi-shop/`은 기존 로컬 코디룸의 가격, 검증 썸네일, 프리즘 자동 미리보기를 유지한다.
- 부모 퀴즈타운의 로그인 세션으로 `renderCoordiShopPreview` callable을 호출한다. 서버가 활성 관리자임을 확인한 뒤 렌더하며, 인증은 캐시 조회 전에도 확인한다.
- 사용자별 브라우저 저장 키를 분리한다. 실제 DJ코인 차감, 상품 등록, 보유 아이템/학생 데이터 변경은 없다.
- 상점의 기존 `shopEnabled:false` 정책은 학생 입장·구매 차단, 관리자 예외이다. 새 코디 체험은 현재 관리자 전용이다.

## 운영 상태
운영 코드 배포 완료. 아래 초기 검증 기록 이후 전체 검사와 분리 배포를 완료했다. 사용자 관리자 로그인 후 기능 관리의 `상점 열기`를 해제해 저장했고, `불러오기`로 재조회하여 체크 해제(`shopEnabled:false`) 유지와 완료 메시지를 확인했다. 다른 기능의 체크 상태는 바꾸지 않았다.

공유 작업 폴더에는 다른 미배포 변경이 많이 있으므로 전체 Hosting/Functions 배포 금지. 배포 시 라이브 기반으로 이번 상점 모듈과 새 경로, 새 callable만 분리해야 한다.

- 최종 Hosting 버전 `e0b2e610beed98ce`, release `1789716081966000`. 최초 기준 운영 버전 `d7322468856d59f3`.
