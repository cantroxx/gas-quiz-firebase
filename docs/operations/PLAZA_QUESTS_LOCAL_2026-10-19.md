# 랭킹 광장·퀘스트 개선 — 로컬 구현 (2026-10-19)

후속: 사용자 배포 승인에 따른 운영 반영은 [배포 보고서](PLAZA_QUESTS_DEPLOYMENT_2026-10-19.md)에 기록했다. 아래의 미배포 설명은 로컬 구현 완료 시점의 기록이다.

## 범위와 승인
사용자가 승인한 로컬 UI·서버 코드·테스트 작업이다. 배포, 커밋, Push, 운영 Firestore/Storage 수정은 하지 않았다. 시작 당시 존재한 대규모 미커밋 변경을 유지하고 요청 관련 경로만 수정했다.

사용자 확인:
- 3일 연속 조건은 하루에 일일퀘스트 1개 이상 달성하면 인정한다.
- 이벤트 광장의 왼쪽 게시판은 오늘의 퀘스트, 오른쪽 토끼 보물상자는 특별한 보상이다. 랭킹 광장에도 연결 버튼을 둔다.
- 서버 집계·지급 코드 및 관리자 특별 보상을 로컬 구현/검증한다.

## 구현
- 명예의 전당: 국어·사회·수학·과학·포켓몬·티니핑·국기왕을 읽고 표시한다. 아지트왕은 한국 날짜의 일수에 따라 게임을 하루에 하나씩 순환한다.
- 순위 게시판: 총점 퀴즈왕, 네 과목, 포켓몬, 티니핑, 아지트. 인기 통합 탭·모드 필터는 제거했다. 새로고침은 대화상자 오른쪽 위 닫기 옆에 있다.
- 아지트: 기존 게임별 순위를 유지하고 말폭탄 낱말의 온라인 우승 횟수 순위를 추가했다. 신규 기능 적용 이후의 우승부터 쌓이며 과거 경기 일괄 소급은 하지 않는다.
- 퀘스트: 일일/주간 토글, 간결한 조건과 진행도, 좁은 화면용 카드 간격.
- 일일: 과목 연습 정답 10 / 랭킹 한 판 20점 이상 완료 / 구름탑 문장 정답 10 / 서바이버 한 판 1,000점 / 말폭탄 1승. 각각 XP 10 + DJ코인 5, 5종 모두 수령 가능.
- 주간: 연습 정답 40(하루 최대 10), 랭킹 일일조건 3일, 구름탑 일일조건 3일, 서바이버 한 판 10,000점, 말폭탄 3승. 기본 보상 최대 3종, 각각 XP 30 + DJ코인 20.
- 주간 기본 3종을 완료한 뒤 열리는 추가 2종: 기본 주간퀘스트 서로 다른 2종 달성 / 주간 내 3일 연속 일일퀘스트 달성. 보상 수령 버튼을 누르지 않아도 달성일은 기록된다. 추가 2종은 기본 3종 수령 한도와 별도이다.
- 과목 외 연습전 XP·DJ코인 지급을 중단했다. 퀘스트 XP는 연습전 일일/주간 지급 한도와 별도로 처리한다. 기존 최대 레벨 정책은 유지한다.
- 특별 보상: 관리자 대시보드의 ‘특별한 보상 설정’에서 개인 미션 또는 협동 참여 미션을 게시/종료한다. 학생이 설명을 읽고 수행 확인 후 참여하며, 협동은 서로 다른 참여 인원이 목표에 도달하면 수령한다. 학생별 1회, 서버 트랜잭션과 보상 로그로 중복을 막는다. 게시된 금액은 수정하지 않고 종료 후 새 보상을 만들도록 했다.
- 인기퀴즈: 과목 퀴즈와 같은 따뜻한 배경·녹색 팔레트·버튼 형태, 과목 전용 보상 안내.
- 내 방 프로필: 상점에서 소유하고 장착한 메이플 코디를 표시한다. 기존 코디 렌더러와 계정 전환/로그아웃 보호를 재사용한다.

## 데이터와 운영 적용 시 주의
- 기존 v2 진행도/수령 기록은 보존한다. 새 조건은 growthQuestProgress의 __v3_daily__/__v3_weekly__ 문서를 사용한다. 따라서 운영 적용 시 새 조건의 진행도는 새로 시작한다. 주간은 한국 시간 월요일 기준이다.
- 새 설정은 appSettings/specialRewards, 특별 보상 참여는 growthQuestProgress, 지급 기록은 rewardLogs에 저장한다. 말폭탄 순위는 wordBombRanking에 저장하고 인증된 callable로 조회한다. 이번 작업에서 보안 규칙은 수정하지 않았다.
- 서바이버의 기존 점수 계산은 클라이언트에 있다. 새 연결은 서버 발급 게임 세션, 인증, 시간/점수 범위, 중복 종료를 검사하지만 전투를 서버에서 재계산하지는 않는다. 조작 방지 수준을 올리려면 별도 서버 게임 검증 설계가 필요하다. 운영 배포 전에 이 제한을 검토해야 한다.
- 보상 수령 시 기존 레벨 상승 보상은 별도로 발생할 수 있다.

## 검증
- 성장/특별 보상 단위 테스트: 일일 5개, 일 10개 누적 한도, 주간 기본 3개 + 추가 2개, 비연속 날짜, 재전송, 동시 수령, 계정 소유권, 관리자 권한, 협동 인원, 종료 보상 차단.
- 합성 데이터 브라우저: 일일/주간 전환, 수령 이벤트, 랭킹→이벤트 연결, 특별 미션 참여/수령, 390px/1440px 화면.
- 메이플 코디 브라우저: 소유 아이템·프리즘, 캐시, 계정 전환, 늦은 응답, 로그아웃, 실패/재시도.
- 실제 Functions + Firestore Emulator: 관리자 권한과 특별 보상 동시 수령, 서바이버 세션 재전송, 일일 보상, 인기 보상 미지급, 과목 보상 유지, 기존 진행도 보존 회귀.
- `npm run check` 전체 통과. 과목 퀴즈 49단원·834문항 유형을 3가지 화면 폭(2,502 화면)에서 확인했다.
- 추가 Emulator 검사 통과: 과목 보상/기존 진행도 보존, 말폭탄 온라인/투표, 인기퀴즈 실제 callable+브라우저.
- 최종 합성 브라우저 검사 통과: 명예의 전당 8개 카드, 인기 탭/모드 필터 제거, 아지트 탭, 우측 상단 새로고침, 내 방 코디 이미지 캐시 재사용.
