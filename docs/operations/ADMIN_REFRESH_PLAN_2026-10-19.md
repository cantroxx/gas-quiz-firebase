# 관리자 센터 최신화 실행 계획

## 확정 범위

2026-10-19 사용자 승인: 앞선 관리자 개선 제안을 순차 구현한다. **증권 지갑·평가액·증권 바로가기는 관리자 학생 상세에 추가하지 않는다.** 증권은 교실 배정 학생(현재 4-8)의 교실 화면 안에서만 보완한다. 이번 작업에서 증권 기능 변경은 없다.

목표는 현행 과목·인기 퀴즈, 타이틀, 퀘스트 정책을 관리자 조회에 정확히 반영하는 것이다. 기존 학생 데이터·보상 정책·반 관리자 권한 범위를 유지한다.

## 실행 규칙

- 단계 순서를 지킨다. 각 단계의 구현·검증 결과와 미완료 항목을 아래 기록에 남긴 뒤 다음 단계로 이동한다.
- 기존 미커밋 변경이 많으므로 HEAD로 되돌리거나 전체 운영본으로 덮어쓰지 않는다. 시작 시 관련 파일을 임시 디렉터리에 보존한다.
- 학생 조회는 서버 권한 확인 후 수행한다. 실패·미배포·조회 상한을 0건으로 표시하지 않는다.
- 읽기 기능은 학생 문서에 쓰지 않는다. 특별 보상 관리의 이력 보존만 기존 게시/종료 트랜잭션에 추가하며 학생 지급·금액·수령 조건은 유지한다.
- 검증은 합성 데이터와 로컬 Emulator/브라우저로 한다. 운영 학생 계정 사용·실제 지급·Firestore/Storage 직접 변경 없음.
- 배포·규칙 변경·데이터 마이그레이션·Git commit/push는 이 계획 실행에 포함하지 않는다. 배포 시 최신 운영 소스와 차이를 별도 대조해야 한다.

## 배포 전 인계

아래는 로컬 구현 대상이며 운영 반영 완료 목록이 아니다.

- Functions callable: `adminGetMemberDetail`, `adminGetDashboard`, `adminGetOperationalAudit`, `adminSpecialRewardAction`. 공용 특별 보상 모듈을 사용하는 `specialRewardAction`도 학생 응답의 작업자 메타데이터 제외 변경을 함께 반영한다.
- 서버 파일: `functions/index.js`, 신규 `functions/admin-insights.js`, `functions/growth/special-rewards.js`. 새 helper가 참조하는 achievements/catalog, subject-quiz/curriculum, popular-quiz/domain의 운영 버전 일치 확인 필요.
- Hosting: `public/index.html`, `public/styles.css`, `public/js/features/admin-render.js`, `public/js/features/admin-controller.js`, `public/js/infrastructure/admin-repository.js`, `public/js/special-rewards.js`, 생성 `public/js/app.bundle.js`.
- 새 이력 경로: `appSettings/specialRewards/history/{rewardId}`. 서버 관리자 작업만 사용. 기본 거부 규칙과 Admin SDK를 사용하므로 Rules/인덱스 변경 없음. 배포 자체로 문서를 생성하지 않으며 이후 게시/종료 때 기록한다.
- 기존 settings에서 이미 사라진 종료 항목과 게시자 정보는 복원·추정하지 않는다. 없는 작업자는 ‘기록 없음’ 표시.
- 현재 점검: 각 랭킹 출처 최대 1,000건, 회원 기준 최대 2,000건. 대시보드 출처 최대 1,000건. 상한 초과는 일부 조회 표시. 전체 페이지 탐색/집계 서비스는 이번 범위에 포함하지 않음.
- 과거 상세 자료는 기존 읽기 상한 유지. 기존 사용자·타이틀·뱃지·재화 문서 변경/소급 없음. 증권 지갑·증권 바로가기 추가 없음.
- 배포 시 최신 운영본/각 함수 소스의 출처를 먼저 대조하고 이 변경만 합친 후보로 검사한다. 미커밋 작업 트리 전체 배포 금지. 배포·commit·push는 별도 요청 필요.
