## 배포 범위

- Functions `popularQuizAction`, `auditPopularQuizSources` 2개를 `asia-northeast3`, Node.js 22로 추가했다. 두 함수 모두 `ACTIVE`이며 기존 함수 128개의 수정 시각은 유지됐다.

- 연습 정답 XP 2·코인 1과 다른 연습전과 공유하는 하루 XP 20·코인 50 한도를 그대로 사용한다. 정답·보상 중복 방지와 한도 경계는 실제 배포 후보의 에뮬레이터 검증을 통과했다.
- 매월 1일 04:00 `Asia/Seoul`의 출처 점검 예약이 `ENABLED`임을 확인했다. 새 이미지 자동 공개가 아니라 기존 공식 이미지·페이지의 변경 후보를 기록한다. 예약 함수를 수동 실행하지 않았다.
- 보안 규칙·인덱스 배포, 기존 학생 데이터 직접 수정·삭제·마이그레이션, Git 커밋·푸시는 하지 않았다.

- 학생 계정에 운영 정답·랭킹·XP·코인을 쓰는 플레이 테스트는 하지 않았다. 인증된 전체 플레이·저장·보상 검증은 합성 계정과 에뮬레이터에서 수행했다.
