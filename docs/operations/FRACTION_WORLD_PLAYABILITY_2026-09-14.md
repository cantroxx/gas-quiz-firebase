# 균열의 탑 — 화면·선택·성장 가독성 보완

## 반영 내용

- 전투 진입 시 상단 사이트 메뉴와 외부 장비 목록을 접고 기기 뷰포트를 사용하는 전투 화면으로 전환한다. 로비 버튼으로 체크포인트를 저장하고 복귀한다.
- 가로 화면은 전투장을 한눈에 보여 준다. 세로 화면은 캐릭터를 따라 좌우로 비추고, 전체 지도에 자신·적·현재 시야를 표시한다. 월드의 충돌 좌표와 적 밸런스는 유지한다.
- 캐릭터 원화와 회피 잔상을 35% 확대하고 손에 든 무기도 확대했다. 피격 판정은 확대하지 않았다.
- `ⓘ 내 상태` 또는 I로 체력·보호막·결정·무기 강화 단계·성장 방향·공격력·기술·유물·조합을 확인한다. 읽는 동안 멈추고 닫으면 열기 전의 진행/일시정지 상태로 돌아간다.
- 전체 화면은 문서 전체를 대상으로 한다. 상태창·퀴즈·유물 확인창도 전체 화면 안에 표시된다.
- 방 버튼 자체에 이득을 표시한다. 전투: 결정 18개+유물, 강한 적: 결정 30개+유물, 보물: 싸움 없이 유물, 선물 발견: 공짜 선물. 선택 미리보기에는 위험과 비용·회복량을 쉬운 문장으로 설명한다.
- 강화 재화는 마름모 글자 대신 금속 테두리와 초록 보석을 넣은 결정 동전 SVG를 사용한다. 기존 결정 잔액과 경제는 유지한다.
- 능력치 화면은 자연수로 표시한다. 예: 공격력 38.08→42.65는 `38 → 43 (+5)`. 공격 간격은 `10초 동안 공격 N번`, 피해 배율은 백분율로 바꾼다. 내부 전투 계산 정밀도는 유지하며 화면에 반올림 안내를 둔다.
- 유물을 누르면 장착 확인창을 표시한다. 이름·그림·능력치 변화·교체 대상 확인 후 확정한다. 취소·Escape는 장비와 재화를 변경하지 않는다. 유물 대신 결정 받기도 확인한다. 보스의 문제 풀이 중 복원은 기존 진행을 유지한다.
- 게임 설명에 새 버튼·카메라·유물 확인 흐름을 반영한다. 기존 저장 칸을 초기화할 필요가 없다.

## 검증

- `npm run check`: 정적 검사, 기존 도메인·응용·저장소, 분수 18,000문제, 확장 200개 경로, Firestore/Storage 로컬 규칙과 운영 셸 검사.
- `scripts/smoke/fraction-world-playability.js`: 새 저장 상태에서 기본 난이도 두 방을 실제 시간과 키보드 조작으로 클리어. 적·체력·무기 위력을 테스트용으로 바꾸지 않는다. 관찰과 방향 선택 시 잠깐 멈추므로 학생의 연속 플레이 난이도를 재현한 것은 아니다.
- 같은 스크립트의 별도 상태 fixture: 상태창 일시정지·복귀·Escape, 전체 화면 안의 상태창, 가로/세로 5크기(1180×820, 1024×768, 820×1180, 600×960, 844×390), 세로 터치 이동, 강화 복원, 자연수 변화량, 유물 취소·교체·결정 대체 확인.
- `scripts/smoke/fraction-world-expedition.js`: 12무기×2강화 계열 공격·기술, 24방/32문제 경로, 보스 해금, 강화소, 비밀 상점과 저장 복원 통과. 이 전체 경로 검사는 낮은 체력의 합성 적을 사용한다.
- `npm run smoke:fractions`: 기존 탐험 이동·회피·기술·체크포인트·터치, 스튜디오 심화 28일/100문제, 저장 칸 독립 등 브라우저 검증 통과. 이번 실행에서는 검증 메시지 출력 뒤 Chrome 종료 대기가 길어져 종료만 중단했다.
- 최종 실제 조작 실행에서 첫 두 방의 적 19마리를 물리쳤고 체력은 약 66 남았다. 각 방의 조작 진행 구간은 약 15초·14초였다.
- 기존 강화·가독성 브라우저 검사도 통과했다: 결정 차감, 체력 증가, 강화 복원, 조합 활성/해제, 보상 수량, 별의 파동 피해와 탄 제거.
- 스크린샷으로 가로 전투장, 세로 카메라와 전체 지도, 상태창, 방 선택 설명을 확인했다.

학생들이 쓰는 실물 태블릿의 프레임 속도와 장시간 플레이 피로도는 별도 수업 관찰이 필요하다. 온라인 학생 데이터·랭킹·DJ코인·보안 규칙 변경은 없다.
