# 퀴즈 역할 정리 1단계 배포

2026-10-17. 사용자의 “1번 진행 후 배포해서 보고” 요청에 따라 현재 퀴즈를 유지·보완·보관 후보로 분류하고, 학생 화면에 세 메뉴의 역할과 활동 성격을 반영했다.

## 반영 내용

- 과목 퀴즈: 연습 교실이라는 보조 이름, 과목별 목적 안내, 기초 연습·독서·어휘·확장 읽기·확장 탐구·생활 탐구·단원 평가 표시.
- 학습 퀴즈: 학습 탐험이라는 보조 이름, 별도 사이트의 새 탭에서 활동한다는 안내, 활동별 입장·기록 저장 방식 확인 안내.
- 인기 퀴즈: 동아리방 역할, 인물·캐릭터·그림 관찰·추리·말놀이 표시, 연습 후 랭킹 도전과 기존 이용 시간 안내.
- 분류 결과: [퀴즈 분류와 메뉴 역할 정리](../product/QUIZ_ROLE_CLASSIFICATION_2026-10-17.md).

계산 연습은 준비 중이고 기존 계산 퀴즈와 역할이 겹쳐 보관 후보로 기록했지만 이번에 숨기지 않았다. 삼각형·우주탐사대의 기존 과목 목록 비노출을 유지했다. 학생에게 관리용 판정을 표시하지 않았다.

## 운영본과 로컬 차이

로컬 작업 폴더에는 교실 등 다른 작업의 변경이 섞여 있다. 현재 live 버전 `6f63ba8e46e241a5`를 복제해 아래 3개 파일만 반영했다.

- `/js/school-rooms.js`
- `/school-rooms.css`
- `/index.html`: 위 두 파일의 캐시 버전만 변경

퀴즈 카탈로그, 앱 번들, 나머지 Hosting 파일 3,782개와 Hosting 설정을 보존했다. 로컬의 삼각형 건축왕 메타데이터를 운영에 추가하지 않았다.

학생·회원·문항 데이터, DJ코인, 랭킹, 기능 플래그, Functions, Firestore·Storage 규칙은 변경하지 않았다. `appSettings/externalQuizzes`와 `appSettings/featureFlags`만 읽어 현재 등록 목록을 확인했다. 학생 계정으로 로그인하거나 문제를 제출하지 않았다.

## 검증

- `npm run check` 전체 통과. 최초 실행은 로컬 테스트 서버의 포트 제한 `EPERM`으로 중단되어 허용된 환경에서 전체 재실행했다.
- 운영본 기반 최종 후보에 `scripts/smoke/quiz-roles-browser.js` 통과. 과목별 카드 수, 활동 표시, 연습·랭킹·독서 허브 호출, 기존 제외 항목, 기능 비활성화·인기 접근 차단, 외부 링크 필터·새 탭, 컨셉 유지, 390px 모바일 가로 넘침, 브라우저 오류를 확인했다.
- 후보에서 로그인·백엔드 요청을 차단하고 합성 계정·설정으로 화면을 검증했다. 학습활동 스크린샷의 예시 링크와 이용 시간은 검증용이다.
- 데스크톱·모바일 캡처를 육안 확인했다.
- 최종 학교 JS 구문 검사와 로컬 소스/후보 해시 대조 통과.
- 배포 후 live 버전, 전체 Hosting 파일 매니페스트, 변경한 공개 파일 3개의 SHA-256이 후보와 일치함을 확인했다.
- 전체 작업 폴더의 `git diff --check`는 기존 관리자 렌더러와 그 번들의 공백 경고를 보고했다. 이번 수정 범위 밖이므로 변경하지 않았다.
