## 반영 내용
- **퀘스트 창**: 오늘의 퀘스트 접기 토글 제거, 입장 즉시 카드 표시. 반복 과녁 장식과 바깥 중복 프레임을 정리했다. 오늘의 퀘스트·보상 수령은 유지한다.
- **유사 중복**: 명예의 전당의 창 내부 중복 제목, 수집 화면의 영문 장식 제목, PC에서 맵 사물과 중복되는 하단 빠른 선택 버튼을 숨겼다. 모바일에서는 번호와 대응하는 목적지 이름 메뉴를 유지했다. 맵 사람 버튼이 표시될 때 하단 친구 버튼도 숨긴다.
- **보유 아이템/내 방 꾸미기**: 내 집의 사물 버튼·하단 진입·보유 아이템 탭을 제거하고 아이템 패널을 숨겼다. 기존 housing 기능과 관련 운영 파일·데이터는 그대로 보존했다.
- **맵 상단/하단 정리**: 맵 위 제목·설명, 별도의 알림판/이용안내 버튼, 아래 이동 안내·빠른 이동 제목을 표시하지 않는다. 지도 이동의 보조기기용 상태 안내와 이름은 유지했다.
- **좌측 상단**: 새 사람 아이콘에 기존 접속 인원/쪽지 배지와 친구창 동작 연결. 확성기 아이콘은 기존 서버 freshness 판정의 새 정보 상태에만 테두리와 빛 효과. 누르면 최신 정보를 갱신하고 마을 소식을 연다. 동작 줄이기 설정에서는 점멸 없이 강조한다.
- **우측 상단**: 손드는 작은 토끼로 기존 내 상태 대화상자/iframe을 연다. 다른 화면과 독립 게임의 기존 상태 바로가기는 유지한다.

## 노란 점 확인과 보완
사용자가 열어 둔 Safari의 해당 계정 상점에서 **보유 아이템 1개, “아직 착용한 아이템이 없어요.”**를 확인했다. 상점 초기화가 서버 `profile.look.equipped`를 반영하는 코드도 대조했다. 해당 화면은 저장된 장착 코디가 없어 노란 위치 표시를 쓰는 상태다. 구매한 아이템과 장착한 코디는 별개이며, 상점에서 선택 후 **내 코디로 장착**하면 마을에 반영된다.

이전 코드는 미장착/로딩 실패 모두 같은 점만 보여 원인을 알기 어려웠다. 이제 로딩·미장착·오류·표시 완료를 구분하고 내 상태 창에 미장착 안내/상점 이동 또는 실패 안내/재시도를 제공한다. 구매·장착·염색을 대신 실행하지 않았으며, 조회 후 타운으로 복귀했다.
