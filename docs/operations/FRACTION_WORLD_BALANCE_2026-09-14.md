# 분수 월드 후반 난이도 보완 보고서

작성: 2026-09-14 · 범위: 균열의 탑 · 새 탐험 규칙 `balance: 3`

## 적용 내용

- 무기 강화 비용: **30 / 60 / 110 / 170 / 250**, 총 **620** 결정(기존 225).
- 유물 강화 비용: **45 / 90 / 150**, 하나당 총 **285** 결정(기존 105).
- 지역별 무기 한도: **+2 / +3 / +4 / +5**. +5는 3지역 보스 처치도 필요.
- 지역별 유물 한도: **+1 / +1 / +2 / +3**.
- 강화소마다 무기와 유물을 합쳐 **2회**. 남은 횟수 표시, 재접속 유지. 실패 확률 없음. 무기 +1·+2는 기존처럼 지도에서도 구매 가능.
- 혼합 조합은 최대 **2개** 활성화. 지도 ‘유물·조합 상세’에서 켜기/끄기, 전투 중 교체 금지. 같은 속성 3개 효과는 별도로 유지. 코스튬 조건은 한 탐험에서 혼합 조합 3종 **발견**으로 변경.
- 추가 발사체는 본래 탄의 **45% 위력**. 근접 무기도 추가 발사체 유물 효과를 같은 비율로 환산. 본래 여러 발을 쏘는 무기의 기본 탄은 유지.
- 공격 속도 최대 기본의 1.65배, 피해 감소 최대 50%, 기술 재사용 최소 6초. 소환수 추가 시 총위력을 완만하게 늘리고 구슬 폭발·연쇄 번개의 반복 발동 간격을 제한. 혜성탄의 관통마다 중복 폭발하던 효과는 탄당 한 번으로 제한.
- 후반 적 체력·피해 증가 및 여러 방향의 무리 출현. 일반 몬스터 기본 체력 배율은 지역별 1 / 1.7 / 2.8 / 4.3이며 지역 내 진행과 강한 적 방 보정이 추가됨. 피해 지역 배율은 1 / 1.2 / 1.45 / 1.75.
- 기본 난이도는 등장·공격 예고 0.95초, 심화는 0.7초. 적 출현 지점에 노란 예고를 표시하고 플레이어와 너무 가까운 출현 지점은 반대편으로 이동. 동시 출현 수 상한 적용.
- 분열된 작은 적과 보스 소환 적도 지역 체력 적용. 일반 적 밀어내기 간격 제한, 보스는 일반 타격으로 밀리지 않음.
- 보스 빙결은 0.25초, 재빙결 저항 5초. 둔화는 최대 20%. 3·4지역 보스는 체력 65% / 30%에서 공격 단계 전환.
- 처치 회복은 방당 최대 8, 방 완료 회복 합계 최대 12. 조합 보호막은 10초 간격, 남은 보호막이 없을 때 재생. 보호막 최대 30, 반사 방패 재사용 1.2초.
- 기술의 적 탄 제거 범위: 방패 250 / 지팡이 180 / 다른 무기 100. 가까운 위기 탈출 효과를 유지하면서 무기 차이를 강화.
- 상점·유물 선택·가방·조합창·강화소·게임 설명에 실제 새 규칙 반영. 추가탄 위력은 자연수로 표시.

## 탐험 길이에 따른 결정 수입

| 항목 | 기본 탐험 24방 | 장기 탐험 32방 |
|---|---:|---:|
| 일반 전투 | 18 | 11 |
| 강한 적 전투 | 30 | 18 |
| 보스 | 45 | 45 |
| 나침반 추가 보상 | 8 | 5 |
| 유물 대신 결정 | 12 | 8 |

일반 전투를 고르는 경로의 전투 기본 수입은 396 / 400, 강한 적 경로는 두 모드 모두 540이다. 보물 대신 결정·나침반·사건·문제 정답 보너스 등 선택에 따른 추가 수입은 별도다. 정답 보상과 분수 연습량(완주 32문제)은 유지했다.

## 검증

- `npm run check`: 정적 검사, 전체 도메인/응용/인프라, 분수, Firebase 합성 데이터 Emulator 규칙, 공개 화면 검사 통과.
- `npm run test:fractions`: 기존 18,000문항과 저장 호환, 새 탐험 200개 경로 및 32문제 진행 검사 통과.
- 12무기 × 2길이 × 2난이도 = 48개 강화 경로: 정확한 비용, 공방 공통 횟수, 저장 복구, 보스 해금, 조합 선택/발견 검증.
- 보스 반복 빙결 저항, 보호막 재생 간격, 구슬 폭발 제한, 추가 화살 위력, 등장 예고 중 무적, 처치 회복 한도 복원 검사.
- `fraction-world-pixel-polish.js`: 화면 폭/탐험 길이별 현재 위치 겹침, 저장된 0 뺄셈 교체, 12종 도트 기술 동작 유지.
- `fraction-world-balance-v3.js`: 공방 구매·재접속, 6개 조합 중 2개 선택·재접속, 390/600/820/1180px 화면 검사. 실제 엔진 전투 **864건**.

## 실제 전투 비교 방법과 결과

12종 무기 × 2길이 × 2난이도 × 공격/생존 우선 유물 선택 × 4지역 × 일반방/보스 = **768건**. 별도로 마지막 지역의 강한 합법 장비로 정지 공격 **96건**을 확인했다.

유물은 고정 시드로 실제 제시되는 후보에서 고르고, 결정은 전투·유물 포기 보상으로 벌어 실제 강화 명령으로 소비했다. 마지막 보스는 마지막 공방 구매까지 포함하며 +5 사례가 48건 있다. 준비 경로의 전투 승리는 가정하고, 비교하는 각 방은 최대 체력의 실제 적과 원래 전투 엔진을 사용한다. 각 방 시작 시 캐릭터 체력은 가득 채우고 이동·회피·기술을 사용하는 단순 자동 조작으로 최대 90초간 검사한다. 무적 치트와 적 체력 축소는 사용하지 않았다.

**학생의 완주율이나 전체 탐험 난이도를 측정한 값이 아니다.** 고정 후보와 단순 자동 조작의 회귀 진단이며, 장기간 누적 체력 손실과 사람의 조작·전략 다양성은 학생 플레이에서 추가 확인해야 한다.

| 지역 | 일반방 승리 사례 평균 시간 | 일반방+보스 적 공격 평균 횟수 | 일반방+보스 승리 / 시도 |
|---|---:|---:|---:|
| 1 | 18.8초 | 9회 | 177 / 192 |
| 2 | 20.3초 | 16회 | 181 / 192 |
| 3 | 23.6초 | 26회 | 161 / 192 |
| 4 | 25.4초 | 33회 | 92 / 192 |

후반 일반방 전투 시간이 2지역 대비 급락하지 않았고, 적의 공격 기회가 증가했다. 정지 공격으로 마지막 보스는 **0/48** 클리어, 마지막 일반방은 **10/48** 클리어했다. 좋은 장비로 일부 일반방을 빨리 정리하는 성장 효과는 남아 있다. 특히 최종 보스는 심화에서 상당히 어려우므로 실제 학생의 첫 도전 결과를 보고 조정할 필요가 있다.

## 저장·배포 범위

새 규칙은 **새 탐험부터** 적용한다. 이미 진행하던 탐험은 기존 강화 가격·효과·한도를 유지하며 지도에 이전 규칙 안내가 표시된다. 새 규칙을 바로 쓰려면 기존 탐험에서 ‘그만두기’ 후 ‘새 탐험 시작’을 선택한다. 이미 얻은 외형·무기 해금과 학습 기록은 보존된다.

게임 코드·관련 테스트·이 보고서만 작업 범위다. 스튜디오, 학생 운영 데이터, Firebase 규칙·Functions는 이 작업에서 배포하지 않는다. Vercel의 기존 분수 월드 프로젝트에 정적 게임만 게시한다.
