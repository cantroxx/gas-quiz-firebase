# 분수 월드 탐험 포기와 저장 칸 초기화

- 지도·전투 하단·로비에 **이번 탐험 그만두기**를 추가했다. 탐험과 해당 탐험의 미완료 문제만 비우고 새 탐험 준비 화면을 연다. 해금, 발견 도감, 학습·과거 기록, 스튜디오는 보존한다.
- 로비 저장 칸 선택 아래 **이 저장 칸 처음부터**를 추가했다. 선택한 칸의 두 게임 진행, 학습 기록, 해금·도감·트로피·설정을 초기 상태로 바꾼다. 다른 두 칸은 보존한다.
- 확인창에 칸 번호와 지워지는 범위를 보여 준다. 취소 버튼을 기본 포커스로 두고, Escape도 취소한다. 저장에 실패하면 메모리 기록을 되돌리고 실패를 알린다.
- 전투 중 포기 확정 시 기존 엔진을 중지한다. 미완료 문제의 콜백도 정리해 새 탐험에 섞이지 않게 했다. 초기화 후 다시 잠긴 무기가 선택되어 있으면 기본 무기로 돌아간다.
- `npm run check` 통과. 마지막 선택 무기 보정은 브라우저 회귀 검사로 추가 검증했다.
- `tests/fraction-world/store.test.js`: 선택 칸 격리, 잘못된 대상 거부, 탐험만 초기화할 때 보존, 새로고침 복원, 저장 실패 시 원복 통과.
- `scripts/smoke/fraction-world-reset.js`: 지도·전투 중 포기, 취소·Escape, 수동 일시정지 보존, 종료된 엔진 정지, 미완료 문제 정리, 전체 초기화, 다른 칸 보존, 4개 화면 너비, 해금 초기화 뒤 기본 무기 선택 검증.
- 모든 브라우저 테스트는 독립된 임시 브라우저 저장공간에서 실행한다. 운영 학생 데이터, Firebase 보안 규칙, DJ코인 변경 없음.
