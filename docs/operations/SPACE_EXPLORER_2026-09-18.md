## 평가 해석

[4과13-01~03] 기반의 관찰·조사 활동이다. 정답 암기 시험이 아닌 자료를 관찰하고 근거를 활용하는 활동으로 조사 자료는 평가 중에도 열려 있다. 사진 수집은 활동 증거의 일부이며 클릭 수만으로 탐구 태도나 이해를 점수화하지 않는다. 조종 속도는 채점하지 않는다.

목성 서술은 특징 두 가지가 타당한지 교사가 확인한다. 자동 9개 정답 수와 교사 확인 항목을 분리해 표시하며 서술을 자동 정답으로 처리하지 않는다. 실제 학급 평가 전에 사용하는 검정 교과서의 용어·별자리 구성과 성취수준 기준을 교사가 확인해야 한다.

브라우저 저장값과 클라이언트 정답은 개발자 도구로 수정·열람할 수 있다. 학생 인증·서버 확정·학급 교사 대시보드가 없는 로컬 체험 평가이며 공식 성적 보안 체계로 사용하지 않는다. 이 제한은 앱 출처 안내와 결과 화면에도 표시한다.

## 실행·검증

```sh
python3 -m http.server 5328 --bind 127.0.0.1 --directory public
# http://127.0.0.1:5328/space-explorer/
npm run test:space
npm run smoke:space
```

브라우저 smoke는 임시 loopback 서버에서 합성 기록만 사용한다. Chrome 경로는 기본 macOS Chrome이며 `CHROME_PATH`로 변경 가능하다. 화면 캡처는 기본 `/tmp/dj48-space-explorer/`이며 `SPACE_SCREENSHOTS`로 변경 가능하다.

## 실제 사진 적용 후속 작업

사용자의 “위키피디아라던가 우주 관련 사이트에서 쓸 수 있는 실제 사진 자료를 적극 활용” 요청을 반영했다.

- Wikimedia Commons의 파일별 정보와 이용 조건을 확인해 NASA 계열 10장(Public domain), ESO 은하수 파노라마 1장(CC BY 4.0), Till Credner의 실제 별자리 사진 2장(CC BY-SA 3.0)을 내려받았다.
- 외부 링크를 매번 이미지로 호출하지 않고 로컬 정적 자산으로 제공한다. 런타임에 외부 CDN/CORS에 의존하지 않는다. Commons가 제공한 축소본을 그대로 저장했으며 사진 내용·색 변경은 없다.
- 시작 화면은 실제 Cassini 토성 사진, 항해 화면은 실제 관측 사진을 사용한다. 실제 사진에는 가짜 고리나 표면 무늬를 그리지 않는다.
- 우리은하 화면은 지구에서 본 실제 밤하늘 파노라마이다. 우리은하 밖에서 찍은 사진으로 설명하지 않는다.
- 사진마다 실제 촬영/다중 사진 모자이크/색 필터 합성/색 강조/극자외선 색상화 여부를 학생에게 설명한다.
- CC BY-SA 별자리 2장은 변경 없이 독립 사진으로 제공하며 학습 지도 위에 겹치거나 저장 캔버스에 합성하지 않는다. 각 사진에 저작자·출처·라이선스 링크가 있다. 해당 사진의 CC BY-SA 3.0 조건을 유지한다.
- 사진 크게 보기, 학습 모형과 실제 사진 비교, 전체 사진 출처 갤러리, 도감의 사진별 출처를 제공한다. 보고서 JSON에도 수집 사진의 출처·라이선스를 포함한다.
- 이전 모형 사진은 삭제하지 않는다. `captureVersion`/`mediaId` 없는 기록에는 이전 모형 안내를 표시하고, 다시 촬영할 때 해당 사진만 갱신한다. 답안과 평가 잠금은 유지한다.
- 사진 로딩 실패 시 사진 찍기를 비활성화하고 다시 불러오기 버튼을 제공한다. 빈 화면을 관측 증거로 저장하지 않는다.
- 사진 파일의 JPEG 시그니처·13개 수량·SHA-256·저작권 메타데이터와 복원 시 출처 일치를 자동 검사한다.

실제 사진 적용 후 `npm run check` 전체 통과(JS 280개, 우주탐사 테스트 7개 포함). 확장한 브라우저 smoke도 통과: 사진 13장 로딩, 저작자·이용 조건 링크 26개, 사진 실패 상태의 촬영 제한/재시도, 도감 복원 후 출처 유지, 기존 10개 평가 임무 및 모바일 검증. 별자리 사진에 원래부터 포함된 선·이름도 설명에 명시했다.

## 3D 비행 및 평가 힌트 제거 (사용자 피드백 반영)

- `scene.js`를 로컬 Three.js 0.180.0 기반으로 교체. 달·태양·8행성은 전구 지도를 구체에 투영하며 토성 고리도 3D 평면으로 렌더링한다. 달은 NASA SVS의 LRO 2025 지도로 앞/뒷면을 다르게 관측한다. 목적지마다 국소 비행 공간을 사용하며 전체 태양계 연속 항법은 아니다.
- 드래그/방향키/Q·E 공전, A·D 좌우 평행 이동, W·S/휠/터치 핀치 접근·후진, 모바일 방향/접근 버튼, 반대편 이동, 자동 공전, 비행 화면 확대. 도착 이후에도 조종 가능. 전진/후진은 카메라 월드 좌표를 바꾸므로 깊이가 다른 별들의 시차와 크기가 바뀐다. 별 배치 및 이동 배율은 체험용 모형이라고 화면에 명시한다.
- 기존 달 날짜/별자리 교육 모형과 은하수 실제 사진 화면은 `observation.js`로 분리. 은하 내부 3D 항법 또는 정확한 천체력 계산으로 주장하지 않는다.
- 조사 자료 패널과 천체 facts 자동 표시, 사진의 답안성 설명 제거. 평가 중 행성 나열은 가나다순이며 크기·거리 표도 감춰 순서 답 노출을 줄였다. 북극성 위치를 바로 알려 주던 임무 문구도 제거. 해설은 기존 제출 후 피드백/최종 결과 흐름을 따른다.
- 3D 촬영은 `captureVersion:3` / 검증된 `textureId`로 저장·복원. 원본 사진의 `mediaId`와 혼동하지 않으며 보고서에서도 `renderedSources`와 `photoSources`로 구분. 기존 로컬 답안/사진 보존.
- `textures/manifest.json`에 11개 지도/고리 원본 URL·SHA-256·크기 기록. 이용 조건과 가공/미관측 보완 범위는 `TEXTURE_CREDITS.md`. 실제 관측 사진 13장 및 각 출처도 계속 열람 가능. 동봉 엔진은 MIT 라이선스.
- 검증 확장: 반대편 공전 후 다른 렌더링, 도착 후 이동, 접근 시 카메라 및 별 투영 변화, 드래그, 자동 공전, 모바일 버튼, 그래픽 미지원 안내/촬영 차단, 지도 로딩 실패/재시도, 10개 평가 임무 및 저장·복원·보고서 흐름. 로컬 미리보기는 기존 5328 서버에서 제공.
- 최종 검증 결과: `npm run check` 통과 (정적 JS 283개, 도메인/앱/인프라 및 Firebase 에뮬레이터, 운영 public shell 읽기 전용 smoke). `npm run smoke:space` 통과 (터치 탭·실제 touch 이벤트 드래그/핀치 및 WebGL 미지원 포함). 학생 실데이터 변경·배포 없음.

- 후속 조작 개선: Q/E는 거리를 유지하며 천체 주위를 돌고, A/D는 카메라의 좌우 접선 방향으로 이동한다. 화면을 다시 클릭하지 않아도 비행 중 키를 받으며, 답안 입력창·모달·조합 입력·브라우저 단축키에서는 조종하지 않는다. 수동 조종을 시작하면 자동 공전이 해제된다.

## Q/E 행성 돌려보기 수정

- Q/E는 선택한 천체와의 거리를 유지하며 천체 중심을 바라보는 좌우 궤도 이동으로 변경했다. 따라서 앞면·옆면·뒷면의 표면 지도가 자연스럽게 달라진다. 자유 비행 모드를 강제로 고정하지 않으며 W/S 접근·후진과 A/D 이동은 유지한다. 방향키와 드래그의 시선 조작은 유지한다.
- 브라우저 회귀 검사에서 Q/E의 반대 방향 궤도 이동과 거리 유지, WASD와 한글 IME 이동을 확인한다.

## 탐사선 외형 개선

- 비행 화면의 단순 원뿔/날개 모형을 금속 장비 본체, 금빛 단열재, 분할 태양전지판, 접시형 통신 안테나, 자세 제어 노즐과 후방 엔진을 갖춘 자체 제작 3D 탐사선으로 교체했다. 실제 특정 우주선의 사진이나 복제품은 아니다.
- 기존 색상 선택, 1/3인칭 전환과 추진 효과를 유지했다. 천체를 가리지 않도록 크기를 조정했다. 구문 검사와 실제 Chrome 렌더링 확인 완료.

## Z/X 수직 이동

- Z 상승 / X 하강: 월드 Y축으로 우주선과 카메라 위치를 이동한다. 자유 비행 시 시선 각도는 유지한다. 관측 고정 상태에서는 고정을 해제하고 현재 시선을 유지한 채 수직 이동한다. 한글 물리 키 입력과 답안 입력 격리를 유지한다.

## 삭제한 학급 재개설 오류 수정

- 총괄 관리자가 삭제한 회차의 개설 토큰이 브라우저 pending 저장소에 남으면 create는 보호 목적의 `{deleted:true}`를 반환한다. classroom.js가 room.status를 무조건 읽어 TypeError가 발생하던 경로를 수정했다.
- 삭제됨 응답이면 새 토큰을 저장한 뒤 새 회차를 개설한다. 성공한 요청의 중복 재시도는 계속 동일한 회차를 반환한다. 불완전한 개설/입장 응답은 TypeError 대신 안내 메시지로 처리한다.
- `scripts/smoke/space-recreate-browser.js`: demo 에뮬레이터 회차 삭제 → 기존 pending 토큰으로 화면에서 재개설 → 새 25문항 회차 확인 → 새로고침 후 같은 요청 재시도에서 중복 회차 없이 복원 검증 통과. 실제 운영 학급을 삭제하거나 답안을 변경하지 않았다.
- 기존 25문항 학생 제출·교사 채점 브라우저 검사 및 필수 전체 검사 통과(기존 에뮬레이터 포트 충돌은 별도 포트에서 동일 검사 완료). Hosting `82c68344fd2e0750` 공개, index.html/classroom.js 두 파일만 변경하고 다른 1,978개 파일·설정 보존. 영수증 `/tmp/space-create-retry-release/receipt.json`.
