# 과목 퀴즈 평가 목록 정리 배포

2026-10-17, 사용자의 `배포진행` 요청으로 Firebase Hosting에 반영했다.

## 변경 범위

- 과학 과목 목록에서 `1단원 평가 · 우주탐사대`를 제거했다.
- 수학 삼각형 항목은 로컬에서 `삼각형 건축왕`으로 등록되어 있었으나 배포 직전 운영 카탈로그와 번들에는 이미 없었다. 로컬 목록에서 제거하고 운영에서도 부재를 확인했다.
- 수학 안내 문구를 현재 목록에 맞추고 앱 번들 캐시 버전을 갱신했다.
- 분수 평가와 다른 퀴즈는 유지했다. 독립 게임 파일, 학생 기록, Functions, Rules는 변경하지 않았다.

## 운영본과 로컬 차이

기존 로컬에는 별도 작업의 미배포 변경이 있어 전체 public 디렉터리를 배포하지 않았다. 현재 live 버전을 복제하고 아래 3개 파일에 이번 변경만 적용했다.

- `/js/data/quiz-catalog.js`: 과학 목록과 수학 안내 문구.
- `/js/app.bundle.js`: 동일한 카탈로그 수정.
- `/index.html`: 번들 참조를 `subject-removal-20261017`로 갱신.

나머지 Hosting 파일 3,782개와 Hosting 설정의 동일성을 확인했다.

## 검증

- `npm run check` 전체 통과. 최초 실행은 샌드박스의 로컬 포트 차단(`EPERM`)으로 중단되어 허용된 환경에서 재실행했다.
- 운영본 기준 후보의 실제 렌더러를 독립 브라우저에서 실행하여 과학은 `과학 상식`, 수학은 `곱셈과 나눗셈`, `분수`, `분수 평가`, `계산 연습`으로 표시됨을 확인했다. 브라우저 오류 없음.
- 운영 페이지에 후보 파일을 연결한 별도 검사는 `networkidle` 대기 시간 초과로 완료되지 않았다. 위 독립 렌더링 검사는 통과했다.
- 배포 후 live 버전, 전체 파일 매니페스트, 변경한 공개 파일 3개의 SHA-256 해시를 검증했다.
- 실제 학생 계정으로 로그인하거나 운영 데이터를 수정하지 않았다.
