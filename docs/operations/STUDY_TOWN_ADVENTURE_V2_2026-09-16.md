# 스터디 타운: 세 난이도와 간단한 모험가 카드

## 반영 범위

1. 시작은 **내 모습 → 무기 → 초보/중수/고수** 세 단계. 그림 선택과 단계 되돌아가기 유지. 몬스터 모습·길잡이는 마지막 단계의 설정 안에서 변경.
2. 장기 탐험 선택 삭제. 모두 4지역 × 6단계 = 24개 방.
3. 초보는 누르고 있기 공격·자동 공격·무료 반복 부활. 중수는 개별 공격·자동 공격·탐험 전체 기본 부활 2번. 고수는 개별 수동 공격·부활 없음. 구조 부적의 일회성 구조 효과는 별도.
4. A 공격, 방향키 이동, Space 회피, S 기술, I 상태. 태블릿은 이동 패드와 공격·회피·기술 버튼, 전투장 터치. 수동·자동 공격의 공통 대기시간으로 중복 공격 방지.
5. 모든 현행 탐험에서 받아치기 비활성화. 버튼·길잡이·도움말 제거. 보스 체력 40% 하한 폐지. 옛 규칙 코드는 이전 데이터 호환 검사에만 보존.
6. 새 난이도의 적 체력/피해/속도는 이전 기본 대비 초보 65/50/75%, 중수 85/75/90%, 고수 110/110/100%. 지역별 동시 적 상한 3/4/5/6, 4/5/6/8, 5/7/9/11. 후반 증가 곡선과 강화소 횟수·지역별 강화 상한 유지.
7. 노란 갑옷 게이지를 일반 공격·기술로 파괴. 무기 기본 공격량 기준 초보 약 2초, 중수 3초, 고수 4초 분량에서 지역 보정. 실제 시간은 명중률·장비에 따라 달라짐. 파괴 후 1.2초 멈춤, 3초 공격 기회. 갑옷 재생 없음.
8. 초보는 위험 공격 준비가 겹치지 않도록 제한, 회전탄 방향 수·장판 수 축소, 더 긴 예고. 큰 공격 뒤 짧은 빈틈 추가. 몬스터 분열과 보스 소환도 동시 적 상한 적용.
9. 내 상태 기본 정보는 모습·체력·무기 강화·한 번 맞히는 힘·결정. 네 접이식 패널: 무기와 기술 / 추천 유물 / 유물과 조합 / 자세한 능력치. 처음 닫힘, 한 번에 하나만 열림, 같은 페이지에서 마지막 선택 기억. 상태창 중 전투 정지와 기존 일시정지 상태 복원.
10. 무기·현재 체력·가진 속성에 따른 추천 유물 최대 3개, 보물·상점·강화 설명. 수치 비교는 주요 3개 먼저, 나머지는 접기.
11. 화면에는 체력·방·결정·내 상태·쉬기와 공격/회피/기술. 음악·전체화면·로비·조합·길잡이·연습은 메뉴. 메뉴가 열리면 전투 정지. 보스 체력·갑옷 UI 통합.
12. 부활 시 체력 전부 회복, 4초 보호, 적 출현 지연. 초보는 같은 방 실패마다 공격/기술 +15%(최대60%), 받는 피해 5% 감소(최대20%). 방 완료 시 도움 초기화. 중수 부활 횟수는 방 완료로 초기화되지 않음. 초보 오답 추가 적 없음. 입장 3문제 전부 정답 결정6개, 학습 범위·보스 보물 정답 보상·해금 유지.

## 저장 호환

- 저장 키는 `dj48.study-town.v1` 유지. 이번 작업은 전체 사용자 초기화를 하지 않음.
- 기존 코인 모드 → 초보, 기존 일반 로그라이크 → 중수, 심화 로그라이크 → 고수로 처음 이어하기 시 한 번 변환.
- 기존 장기 진행은 같은 지역의 24방 지도 위치로 변환. 장비·결정·해금·학습 기록 유지, 현재 방은 지도에서 다시 선택. 이전 전투 스냅샷은 새 규칙과 섞지 않고 해당 방에서 새로 전투.
- 기록 도감의 과거 32방 완료 기록은 그대로 표시.
- 관리자 체험도 24방/세 난이도 사용. 퀴즈타운 관리자 연결 및 실제 저장과 분리된 체험 구조 유지.
- Firebase 데이터·보안 규칙·게임 광장 변경 없음. 스튜디오는 수정 범위에서 제외.

## 검증

- `node tests/fraction-world/adventure-v2.test.js`: 세 묶음, 부활 횟수, 방 완료 초기화, 지역 증가, 옛 32개 위치 변환과 재변환 방지.
- `npm run test:fractions`: 기존 분수 생성·저장·장비·전투 검사. 새 도메인 검사도 expedition 테스트에서 실행.
- `node scripts/smoke/fraction-world-adventure-v2.js`: Chrome 실제 3단계 시작·분수 정답 보너스, 자동/누르고 있기/수동 공격 분리, 공통 대기시간, 실제 A키와 이동 충돌 없음, 상태창 토글·복원, 중수 부활 소진, 48가지 무기/지역 보스 갑옷과 처치 조건.
- 390×844, 820×1180, 1180×820, 1024×768, 844×390 화면에서 시작·전투·상태창 및 버튼 경계/겹침 검사와 화면 이미지 확인.
- 배포 전 `npm run check` 전체 검사. 학생 실제 완주율은 후속 수업 관찰이 필요하며 자동 검사 결과로 추정하지 않음.
