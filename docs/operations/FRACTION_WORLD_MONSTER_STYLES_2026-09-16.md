# 몬스터 외형 선택과 전투 안내 표현

2026-09-16. 새 탐험 시작 화면에 귀여운 몬스터 / 전투형 몬스터 선택과 미리보기를 추가했다. 외형은 탐험의 `monsterStyle`에 저장한다. 기존 기록은 귀여운 버전으로 표시하며 전투 난이도·보상·피격 판정은 외형과 무관하다.

전투형 10종은 새로 생성한 오리지널 갑옷·기계·돌 수호자 이미지다. 일반 몬스터 6종과 지역 보스 4종을 포함한다. 원본은 Git에 보존하고 배포는 약 541KiB의 새 WebP만 사용한다. 현재 선택한 전투용 시트만 공통 디코딩 준비 목록에 포함한다. 시작 화면 미리보기는 두 외형을 모두 보여 준다. 전투 준비 중 시뮬레이션 정지와 재시도는 기존 로딩 규칙을 유지한다.

표현 변경:

- 몬스터 주변의 빨간 진행 원을 제거했다. 몸을 낮추는 준비 동작과 작은 빛 입자로 준비 상태를 보여 준다.
- 돌진 방향은 바닥의 화살표 형태, 내려찍기는 바닥의 범위로 보여 준다. 바닥 위험·독 웅덩이 안내는 유지한다.
- 큰 별탄의 사각형을 없애고 금빛 잔상과 밝은 중심을 추가했다. 받아치기 판정은 그대로다.
- 캐릭터 발밑의 피격 기준 원을 작은 그림자로 바꿨다. 받아치기 순간 효과는 유지한다.
- 보스의 실제 별방패를 뜻하는 금빛 테두리와 방패 개수 안내는 남긴다. 무기 기술의 준비 범위도 별도 의미가 있어 유지한다.

검증:

- `npm run check`: 전체 필수 검사 통과.
- `fraction-world-monster-styles.js`: 외형 선택, 새로고침 후 저장, 두 외형의 같은 전투 능력치, 두 버전 전투 렌더링, 390px 시작 화면 통과.
- `fraction-world-tactics.js`: 패링·별방패·독·재개·터치 화면 5종·음악 12편곡 회귀 통과.
- 전투형 실제 화면과 캐릭터·별탄·돌진 예고의 배치를 확인했다.

적 수·속도·공격력·패링 허용 시간은 변경하지 않았다. 새로고침 후 새 탐험에서 외형을 선택할 수 있다.
