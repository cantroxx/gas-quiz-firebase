# 증권소 그림·목록/상세 재구성 — 2026-10-18

## 변경 목적

사용자가 비교한 증권 카드와 기존 배치 아이템 상점의 차이를 반영했다. 작은 평면 아이콘 중심의 카드에서 큰 입체 그림 중심의 카드로 바꾸고, 상세 정보는 별도 패널에 모았다.

## 반영 사항

- 회사 12곳과 증권소에 따뜻한 미니어처·동화풍 래스터 그림 13종을 적용했다.
- 그림 → 회사 이름 → 소개 한 줄 → 1주 가격 → 상세 보기 순서로 목록을 단순화했다. 등락·가격 움직임·보유 주식·거래 버튼은 상세 패널에 표시한다.
- PC는 두 열의 회사 카드와 옆 상세 패널로 구성한다. 선택한 카드에는 초록 테두리와 `aria-pressed` 상태를 표시한다.
- 1,000px 이하에서는 목록과 상세를 전환한다. 상세 제목으로 초점을 옮기고 `목록으로`를 누르면 선택했던 회사 버튼으로 돌아간다.
- 첫 시세가 없는 상태는 `시작 가격 · 아직 거래 전이에요`로 표시한다. 이전 가격과의 비교 문구와 그래프를 숨기며 사기·팔기를 비활성화한다.
- 증권 화면에서 `내 상태` 바로가기는 문서의 일반 배치로 전환해 카드·거래 버튼을 덮지 않는다. 다른 화면의 고정 바로가기는 유지한다.
- 기존 가격 계산·거래 한도·코인 이동·교사 시범 공개 설정은 변경하지 않았다.
