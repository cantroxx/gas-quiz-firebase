# 이벤트 광장 목록 전환 버튼 배포

2026-10-17, 사용자의 `배포 진행` 요청으로 Firebase Hosting에 반영했다.

## 변경

- 오늘의 퀘스트와 시즌 이벤트를 같은 줄의 버튼으로 배치했다.
- 기본으로 오늘의 퀘스트를 표시하고, 다른 버튼을 누르면 선택한 목록만 표시한다. 열린 버튼을 다시 누르면 접힌다.
- 두 상단 바로가기는 해당 목록을 펼치며, 새로고침은 선택·접힘 상태를 유지한다.
- 선택된 버튼의 색상을 구분하고 320px 모바일에서도 두 버튼이 나란히 표시되도록 했다.
- 보상 정책·학생 데이터·Rules·Functions는 변경하지 않았다.

## 배포 범위와 보존

배포 전 운영본의 번들 버전은 `subject-removal-20261017`이었다. 이 최신 운영본을 기준으로 작업하여 다른 작업의 변경을 보존했다.

파일 4개만 변경하고 나머지 Hosting 파일 3,781개와 설정의 동일성을 확인했다.

- `/index.html`: 이벤트 목록 영역과 CSS·번들 캐시 버전.
- `/plaza-views.css`: 버튼 배치·선택 상태·목록 숨김 관련 규칙만 변경. 랭킹 스타일 순서는 운영본 유지.
- `/js/features/event-controller.js`: 두 버튼 및 상단 바로가기의 목록 전환 처리.
- `/js/app.bundle.js`: 운영 번들의 위 컨트롤러 모듈만 교체. 나머지 내용의 동일성을 검사.

## 검증

- `npm run check` 전체 통과.
- 실제 후보에 `EVENT_PUBLIC_DIR`를 지정한 `season-quest-browser.js`, `event-loading-browser.js` 통과.
- 1440/390/320px 버튼 한 줄 배치, 목록 전환·키보드·바로가기, 새로고침 상태 유지, 미수령 보상 팝업·수령 연결·갱신·빈 상태, 계정 전환 및 로딩 회귀 검사 통과.
- 배포 후 live 버전·전체 파일 목록과 변경 파일 4개의 공개 응답 해시 확인.
- 운영 브라우저에서 비로그인 공개 화면 로딩, 320px 버튼 배치, 양쪽 목록 전환·바로가기·보상 팝업·페이지 오류 없음을 표시 전용 합성 데이터로 확인. 실제 운영 보상 수령은 하지 않았다.
