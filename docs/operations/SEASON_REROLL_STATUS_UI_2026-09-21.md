## 월간 온라인 퀘스트
- 관리자 > 시즌 이벤트 > 월간 온라인 퀘스트 자동 구성에서 다음 달 구성 조회·리롤.
- 기존 공지형 시즌 이벤트 편집과 별도로 온라인 게임 5종 목표를 관리한다.
- 스터디 타운, 퀴즈 서바이버, 두근두근 마블, 구름탑, 말폭탄 유지. 기본 목표는 100/100/5/200/100이며 80%, 100%, 120% 범위에서 월별 구성.
- 게임별 월 1회 XP 50·DJ코인 40 유지. 기존 주간 XP 한도·최고 레벨 처리 적용.
- 2026년 9월 진행 중인 목표는 보존. 10월부터 한국 시간 매달 1일 새 월 키로 자동 선택한다. 월 키로 결정적으로 계산하므로 스케줄러 작업 없이도 조회·보상 판정에 같은 목표 적용.
- 다음 달 리롤은 `growthSeasonPlans/YYYY-MM`의 revision에 기록. 관리자 변경 로그는 같은 트랜잭션으로 저장한다.
- 서버가 다음 달만 허용하고 월·revision 일치 검사. 중복 요청·오래된 화면·동시 리롤은 재조회하도록 차단. 전권 관리자만 호출 가능.
- 현재 월/과거 월 실적, 퀘스트 ID, 지급 기록은 리롤하지 않는다. 별도 보안 규칙 변경 없음(클라이언트 직접 접근 금지 유지).
