# 낱말 대전 사전 데이터 출처·라이선스 점검

점검일: 2026-09-02

## 대상

- `words-data.js`: 한글 1~4글자 80,774개를 담은 자동 생성 데이터
- `words.js`: 사전 판정과 아동용 차단어 필터

## 기록된 출처

1. 국립국어원 「한국어 학습용 어휘 목록」(2003)
   - 공식 배포 페이지: <https://www.korean.go.kr/front_eng/down/down_02V.do?etc_seq=71&pageIndex=1>
   - 공식 페이지가 안내하는 조건: 공공누리 제1유형(출처 표시)
2. `spellcheck-ko/hunspell-dict-ko`
   - 저장소: <https://github.com/spellcheck-ko/hunspell-dict-ko>
   - 현재 상류 설명은 전체 결과물을 GPL-3.0으로, 국립국어원 기반 대부분 단어 데이터를 CC BY-SA 4.0으로 안내한다. 개별 파일별 조건은 상류 `LICENSE.md`를 우선한다.

## 현재 보류 사유

현재 저장소에는 `words-data.js`를 만든 생성 스크립트, 입력 파일, `hunspell-dict-ko` 커밋/릴리스 버전이 없다. 데이터 파일 머리말에는 `CC BY-SA 2.0 KR`이라고 적혀 있지만, 현재 상류 안내는 주된 단어 데이터에 `CC BY-SA 4.0`을 명시한다. 어느 시점의 어느 파일을 사용했는지 증명할 자료가 없으므로 한 버전으로 임의 단정하거나 재라이선스하지 않는다.

따라서 다음 조치 전까지 이 데이터는 **현재 게임의 검토용 기존 자산**으로만 취급하고, 다른 저장소·게임·사전 패키지로 복사하거나 별도 배포하지 않는다.

## 공개 재배포 전 복구 절차

1. 입력 자료의 정확한 다운로드 URL·파일 해시·상류 커밋을 고정한다.
2. 생성 스크립트와 욕설 필터·길이 제한 등 변환 과정을 저장소에 보존한다.
3. 각 입력 파일의 라이선스를 확인하고, 파생 데이터에 적용되는 동일조건변경허락 버전을 확정한다.
4. 국립국어원과 `hunspell-dict-ko` 저작자·기여자를 표시하고 해당 라이선스 전문 또는 공식 링크를 함께 제공한다.
5. 재현 빌드로 단어 수와 해시를 확인한 뒤 `words-data.js` 머리말을 실제 provenance와 일치시킨다.

이 문서는 법률 자문이 아니라, 현재 저장소에서 확인 가능한 증거와 배포 금지선을 기록한 운영 메모다.
